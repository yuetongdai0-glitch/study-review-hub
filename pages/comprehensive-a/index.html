导学：综应A到底考什么

先把"游戏规则"弄明白，后面的方法才有落点
🎯 本课目标：用最短的时间搞清楚三件事——① 这门考试和申论有什么本质区别；② 2026大纲改了什么；③ 六类题型各自长什么样。看完这一课，你再看题目就不会"抓瞎"。

0.1 科目定位：这门考试为什么存在

事业单位公开招聘分类考试中，A类（综合管理类）适用于以行政性、事务性和业务管理为主的岗位。笔试考两科：

科目时长满分性质
《职业能力倾向测验》90分钟150分客观题（常识、言语、数量、判断、资料分析）
《综合应用能力(A类)》120分钟150分主观题（本页讲解对象）
一句话本质：综应A不考"文采"，考的是"办事"——给你一个事业单位的真实工作场景，让你代入某个具体岗位（"市图书馆工作人员""街道办办公室主任助理"），完成概括、分析、对策、沟通、办会、写公文等真实工作任务。

0.2 试卷结构：一份卷子长什么样（2026版已调整）

2026大纲重要变化：试卷结构由旧版的"注意事项 + 背景材料 + 试题"三部分，调整为"由背景材料和任务组成"（删除"注意事项"表述），命题语言从"试题"改为"任务"——这一字之差，体现的是"这是你岗位上要完成的一项工作"的命题取向。
组成具体内容备考要点
背景材料一般 2~5 则，总量 6000~8000 字；以案例型材料为主，场景化叙事、人物对话多，口语化表达多、规范词少材料是"答案的唯一来源"——这是全卷最重要的规律
任务一般 4 道题，每道 30~50 分；围绕同一场景、同一工作主线层层推进先通读材料把握全局，再逐题作答；把每道题当成"岗位上的一件事"来办
近年趋势：材料字数在增长，且呈现方式更多元——展板内容、组织架构图、项目介绍、会议发言、群众访谈等载体都出现过。速读 + 详读结合是刚需。

0.3 大纲五大能力：命题的底层逻辑（必背）

考试大纲规定，综应A主要测查五方面能力。所有题目都是从这个能力框架里"长"出来的，先吃透它，等于拿到了整个考试的说明书：

能力大纲原文（规范表述）人话解读主要对应题型
① 管理角色意识对管理岗位的职责权限有清晰认识，能够从管理者的角度理解、思考和解决问题，具有服务意识时刻问自己："我是谁？我的权限到哪？"既不能越权，也不能失职所有题目（贯穿全卷）
② 分析判断能力面对工作情境，能够发现和界定问题，分析问题原因及影响因素，做出恰当的评估和判断能从材料里"看穿"问题：有什么问题、什么原因、影响多大、谁的责任归纳概括、综合分析
③ 计划与控制能力能够根据岗位职责和工作要求，利用可支配的资源，设想可以解决问题的方式方法，使工作按预想的进程和方向发展能把事情"办成"：定目标、排步骤、调资源、控进度、防意外提出对策、应急处理、组织协调
④ 沟通协调能力能够在管理工作中向有关人员征询意见，传递信息，施加影响，获得支持与配合会"说话"：能说服别人、化解矛盾、协调各方，把事情往前推沟通协调
⑤ 文字表达能力能够根据管理工作需要撰写文稿，准确和清晰地进行书面表达能"写"：格式规范、内容完整、语言得体公文写作
记忆方法：一句话串起来——"我是谁（角色）→ 看出问题（分析）→ 办成事情（计划）→ 说服别人（沟通）→ 写好东西（表达）"。考的就是一个合格事业单位管理人员的完整工作链路。

0.4 综应A ≠ 申论（最容易搞混，必须分清）

申论（公务员）

  • 话题宏观：政策、治理、文化等大主题
  • 最后大题是议论文，重论证、讲文采
  • 身份较虚，重"观点表达"
  • 答案可适当升华、拔高立意

综应A（事业单位）

  • 话题微观：一个单位的具体事务（图书馆预约、街道市集、大喇叭扰民）
  • 最后大题是应用文/事务文书，重办事、重格式
  • 身份是具体岗位工作人员，权限清晰
  • 答案务实落地，措施要"能执行"，忌空话
口诀：申论是"议"，综应是"办"；申论重"理"，综应重"事"。用申论文笔答综应＝严重跑偏。

0.5 2026年新考情：三大变化（务必先看）

2026版考试大纲与近年命题已出现明显转向。命题不再是"考你背没背模板"，而是"考你像不像一个真正在岗位上办事的人"——这恰恰是袁东体系"机关视角、去模板化"的价值所在。

变化维度旧印象2026新趋势应对策略
主体定位·小而精动辄"某市/某局"的宏观单位越来越多出现职工服务中心、社区驿站、未保中心等"微单元"，身份更具体、权限更精细审题时把"我是谁、我的权限边界"抠到极致，别越权、别失职
材料场景·活而实单一线性的叙述材料立体化、对话体、多视角：网页留言、会议记录、访谈、图表混排，信息分散且口语化练"多载体速读"：会从对话/留言里抓问题、从图表里读数据
任务嵌入·深而融各题相对独立角色驱动、全链履职：4道题串成"一件事"的完整流程（调研→决策→沟通→落实）先读懂"这条工作线"，答案前后呼应、逻辑自洽
2026大纲要点速览：
① 试卷结构：由"注意事项+背景材料+试题"→ "由背景材料和任务组成"；
② 典型任务表述中删除"会务安排"，保留"观点归纳、资料分类、草拟信函、应急处理、联络通知等"；
③ 常识判断新增"历史"测查；言语理解明确"词语填空、句子填空、语句排序、主旨概括、标题拟定"等题型；
④ 整体导向："突出政治素质和能力导向"。
备考三转变：从"背模板"转向"练实务对策"；从"只读文字材料"转向"读懂多载体信息"；从"单题作答"转向"整卷当成一件事办"。原"会务安排"已按新大纲调整为"组织协调与活动方案"，考法不变、名称更新（见第6课）。

底层方法：答案是怎么"长"出来的

这是全书的"总开关"——所有题型共用同一套底层动作
🎯 本课目标：把"做题"这件事拆成四个可复制的动作：审题 → 析点 → 加工 → 书写。学完这一课，你拿到任何一道题，都知道第一步该干什么、第二步该干什么，而不是"看着材料发呆"。
先看"答案思路"：综应A的答案不是想出来的，是"从材料里拆出来再拼回去"的

很多同学做综应A的方式是：读一遍材料 → 凭感觉写几句 → 抄几句原文。这是最典型的低分打法。袁东体系给你的是相反的路径：

材料（散乱的信息） → 审题（问的是什么） → 析点（逐条拆出小要点） → 加工（合并同类项、提炼总括词） → 书写（总括词 + 分述）

关键认知：答案的"骨架"是题干给的，"血肉"是材料给的，你的工作只有一件事——把材料的散点，按题干的骨架重新排列组合。所以"材料为王"不是口号，是操作手册。

1.1 万能四步：审题 → 析点 → 加工 → 书写

1
审题（约30秒，但决定成败）

逐字划出题干五要素：身份、范围、对象、问数、字数。审题错，全盘皆输——把"概括做法"答成"概括意义"，这一题就是0分。

2
析点（找点，宁多勿漏）

带着"题干要什么"回材料，一个自然段一个自然段地拆。用符号边读边标（△问题 ○做法 ☆原因 □影响）。能直接摘的摘，不能摘的用自己的话提炼。这一阶段不必考虑文采和顺序。

3
加工（这一步决定档次）

把散乱的小点合并同类项（意思相近的合成一类），再给每一类提炼一个总括词（段旨句），最后按逻辑排序。加工得好，答案就"有层次"；不加工，答案就是"一堆话"。

4
书写（让阅卷人一眼看到分）

分条列项（一、二、三 / 1.2.3.），每条"总括词 + 具体展开"；关键词尽量用材料原词；字迹工整、卷面干净；字数贴近上限但不超格。

1.2 审题五要素：把这五样圈出来，题就不会答偏

要素看什么答偏的典型表现
身份"你是谁"（街道办助理 / 图书馆工作人员 / 文化馆职员）——决定你的权限和口吻社区工作人员却写"建议修改《××法》"（越权）
范围"根据材料2"就只在材料2找；"结合给定材料"就全卷找把材料3、4的内容写进"根据材料2"的题，白写还扣分
对象到底让你概括什么/解决什么：问题、原因、影响、做法、变化、意见……要"做法"答成"意义"；要"问题"答成"对策"
问数一问还是两问？出现"和/及/并"或"概括准确""问题明确"多为两问两问只答一问，直接丢一半分
字数上限是多少？反推要写几个点（一般每点 40~60 字）250字写8个点，每点一句半，全部展不开
审题口诀："我是谁、看哪几则、答什么、几问、多少字"——五个问题各用笔圈一个字，30秒内必须完成。

1.3 材料阅读的底层思维：粗读三维 + 精读二维

袁东体系读材料讲究"先粗后精"。粗读是为了找话题、找总括词、划文段；精读是为了把点抠细、对着题目组答案。

阶段维度具体看什么
粗读三维首尾句段落的开头句和结尾句，往往是一段的"总起"或"总结"，可直接作为总括词的来源
关联词 / 关键词 / 高频词转折词（但是/然而/却）后面常是"问题"；并列词（同时/此外/一方面）前后都是要点；反复出现的词≈得分词
主体内容这一段到底在讲"谁、干了什么、结果如何"，据此判断文段划分
精读二维化大为小以句号为单位把长段落切开，一句一句看，避免"一大段只提炼出一句废话"
目标导向始终盯着题干要的"对象"去找，跟题目无关的内容果断跳过（材料里一定有干扰信息）

1.4 边读边标：一套符号走完全卷

标四大要素，四种符号
  • △ 问题：缺、少、难、差、慢、乱、不到位、没人管……（负面词）
  • ☆ 原因：因为、由于、根源在于、归因于……
  • □ 影响：有利于、推动了、促进了 / 不利于、导致、危害了……
  • ○ 做法（对策）：动词打头——出台、设立、建立、开展、联合、优化……

为什么必须标：材料一大堆信息，不改造成"结构化"的，加工那一步就会乱成一锅粥。标注的本质，是把"读"变成"拆"。

1.5 加工的核心：合并同类项 + 提炼总括词

技巧一：合并同类项——同义合并、同主体合并、同层面合并
  1. 同义法：意思相近或语意色彩相近的要点合并（"停车难""还车难"都属"体验感差"）。
  2. 同主体法：谁的问题归谁——政府 / 单位 / 工作人员 / 群众 / 社会 / 媒体。
  3. 同层面法：思想观念 / 制度机制 / 监督管理 / 设施设备 / 队伍人才 / 技术手段 / 资金保障 / 宣传服务。
  4. 时间线法：事前—事中—事后（适用于流程类、变化类、应急类）。
技巧二：总括词三招——"选大哥 / 选词组合 / 造大哥"
  1. 选大哥：一类要点里，挑一个最能涵盖其余各点的词当总括词（如"维护不到位""规划不合理"）。能用就用它，最省事也最稳。
  2. 选词组合：没有现成的"大哥"时，把两个高频词拼起来（如"处罚监督不到位"＝"处罚不到位"＋"监督不到位"）。
  3. 造大哥：实在没有现成词，自己概括一个规范的（如把"坐着挤、排队久、办证慢"概括为"服务效能低"）。这是最后手段，尽量少用，因为容易脱离材料原词。

小提示：并列关系的句子，往往可以用"选词组合"或"造大哥"来收口；问题反推时，问题的反面常常就是现成的总括词。

技巧三：答案的逻辑骨架只有五种
  1. 总分：先总括一句，再分条展开（概括题最常用）。
  2. 分总：先分条，最后收一句总结（公文结尾常用）。
  3. 总分总：总起—分述—收束（讲话稿、宣传稿常用）。
  4. 并列：几个层面平铺（如"使用 / 管理"两大类）。
  5. 递进：由浅入深、由急到缓（应急题、对策题常用）。
加工的标准是"三不"：不交叉、不重合、不遗漏。两条要点说的是同一件事，就要合并；合并后剩下的，才是"互相独立"的要点。阅卷是按"点"给分的，独立的点越多，越容易踩中。

1.6 书写的三条铁律

铁律一 · 答案源于材料

90%以上的要点在材料里。抛弃"我认为/我觉得"，忠于原文、不主观臆断、不过度推断。材料没提的（罚款、上法院），不要自己加戏。

铁律二 · 时刻代入身份

审清"你是谁"。街道办助理 vs 政府工作人员，权限完全不同。权限不足就先"请示汇报、协调上级"，再谈"落实"。

铁律三 · 总括词前置

每条以"总括词"打头，再展开具体内容。阅卷人30秒一题，第一眼看到的就是每条开头那四个字。

本课小结：审题（五要素）→ 析点（粗读三维/精读二维/四符号）→ 加工（合并同类项 + 总括词三招 + 五种骨架）→ 书写（总括词前置 + 分条列项）。后面每一类题型，都是这套动作的"参数化变体"。

第2课 归纳概括（要素提炼）

必考题型 · 几乎每场都是第1题 · 方法最统一、也最容易丢冤枉分
🎯 本课目标：学完能准确判断"概括对象"（问题 / 原因 / 影响成绩 / 变化 / 对策经验 / 意见），并用同一套动作把散乱材料整理成"总括词 + 分述"的答案。这是全卷性价比最高的一题，务必拿满分。

2.0 题型识别与"答案思路"总纲

概括……问题归纳……原因总结……成绩/成效 说明……变化归纳……经验做法分类整理……意见 提炼……要点分析……特点
归纳概括的"答案思路"只有一句话：按题干的对象，把材料"拆—并—收"

不管让你概括问题、原因、影响还是变化，动作是完全一样的，变的只是"你要抓的是哪种要素"。所以做概括题永远先问自己三个问题：

① 我要抓的是哪种要素？（问题△ / 原因☆ / 影响□ / 做法○ / 变化↗ / 意见💬）
② 材料里哪些是"点"？（逐条拆出来，宁多勿漏）
③ 这些点能并成几类？（合并同类项 → 每类一个总括词）

最容易丢分的不是"找不到"，而是"不分类"和"不提炼总括词"。阅卷是按"类 + 点"双轨踩分的：有总括词，先得一个概括分；下面展开的具体表现，再得若干细节分。

归纳概括的通用四步（本课所有例题都按它走）
  1. 审题定对象：圈出"概括×××"，明确是问题、原因、影响、做法还是变化。
  2. 逐条拆点：按句号切分材料，一句一句拆，能摘就摘、不能摘就提炼，宁多勿漏。

2.1 概括问题：从"网友的抱怨"到"管理的问题"

答案思路：问题的答案，是"把口语抱怨翻译成管理问题"

技巧：先"打标签"，再"合并"
  1. 逐条翻译：把每条抱怨压成一个规范短语（"站点没车"→ 借车难；"还不上车"→ 还车难）。

2.5 概括对策 / 经验：动词打头，把"他们怎么做的"摘出来

答案思路：经验做法＝"谁 + 做了什么 + 取得什么效果"，核心是动词短语

"经验做法"这类题，答案的每一条都应该是一个动宾短语（出台文件、设立机构、联合整治……）。材料里的做法往往散在各段，你要按"阶段"或"层面"把它们串成一条线。

逐段找动作 → 把动作压成动宾短语 → 按阶段/层面排序 → 每步一个总括词
技巧：经验题的"三步走"
  1. 找动词：出台、印发、成立、设立、召开、联合、出台、规范、公示、整合、拓展……动词就是要点。
  2. 补对象：动词后面接的"名词"就是内容（出台《……办法》、设立停车办公室）。
  3. 加总括词：把同一阶段的动作归到一起，用"选大哥"给个名（高度重视、强化公共属性、回头看整改、规范管理、融合式管理）。

对象口诀

问题找负面词(缺/少/难/差)；原因找因果链；影响找有利于/导致；做法找动词；变化找前后差异；意见先分立场。

分类三刀

同义合并 / 同主体合并（政府·单位·群众）/ 同层面合并（思想·制度·监管·技术·资金·人才）。

总括词三招

选大哥（首选）→ 选词组合 → 造大哥（最后手段）。总括词要短、准、能罩住下面的话。

书写模式

第3课 提出对策（解决问题）

高频 · 常驻第2题 · 最容易提分，也最容易写空
🎯 本课目标：学会"判问数 → 定身份 → 三来源找全 → 十层面兜底 → 四要素写实"，让每条对策都具体可执行，杜绝"加强管理"式空话。

3.1 题型识别与"答案思路"

提出解决措施/建议针对……问题提出改进建议先概括问题，再提出对策
答案思路：对策＝"问题／原因的反面 + 经验借鉴"，不是凭空想

很多同学提对策时"头脑风暴"，结果全是空话。正确做法是把材料里的每一个问题或原因拿来"翻一个面"：材料说"缺人手"，对策就是"加强队伍建设"；材料说"因为宣传不够"，对策就是"加大宣传力度"。问题找全了，对策就自然齐了。

直接对策（材料里的"应当/建议/已采取措施"）＋ 问题反推 ＋ 原因反推 ＋ 经验借鉴 → 对策
技巧一：先判"一问还是两问"
  1. 一问：题干只说"提出对策/建议"，问题已在材料中明确 → 直接写对策。
  2. 两问：题干出现"概括准确""问题明确"，或"先概括问题再提出对策" → 先简写问题（占 1/4~1/3），再重点写对策（占 2/3 以上）。
  3. 判断口诀："只谈措施是一问，要求概括才两问。"
技巧二：身份决定对策的"天花板"
  1. 政府机关：可提制度、立法、监管、专项整治、跨部门联合。
  2. 单位普通工作人员：从岗位职能出发——加强宣传、完善设施、优化流程、组织志愿者、请示汇报上级、协调相关部门。
  3. 越权是重灾区：社区工作人员写"修订《民法典》"＝直接扣分。正确写法："建议向上级反映，推动相关法规政策完善"。
技巧三：对策四要素——从空话变可执行
  1. 主体（谁来做）＋ 手段（用什么方式）＋ 内容（具体做什么）＋ 目的（达到什么效果）。
  2. 自查标准：把对策念给同事听，对方能直接照着做 → 合格；对方问"怎么做？" → 空话。

3.2 单一对策：把"每个人的抱怨"变成"一整套措施"

答案思路：材料的"抱怨"就是"问题"，把抱怨归类，再逐类给措施

这类题的材料是座谈会发言，每个人抱怨一件事。你要先把抱怨翻译成问题，再把问题按类合并，最后针对每一类问题给出对策。常见的四类：关怀（待遇/环境）、培训（能力）、管理（考核/分工）、教育（思想认识）。

3.3 复合对策：问题与对策"一一对应"

答案思路：先把问题归类，再"一个问题配一条对策"，像开药方一样对齐

题干要求"概括问题 + 提供建议"时，最忌讳"问题写一堆、对策写一堆、两边对不上"。正确做法：先把问题合并成几类，再逐类配对策，一一对应，答案自洽。

第4课 应急处理

中高频 · 考验"轻重缓急"的办事智慧 · 框架最固定，最该拿满分
🎯 本课目标：背熟"控场 → 调研 → 短对 → 长对"四步框架，并能把它套进投诉纠纷、舆情危机、安全事故、活动中断四类场景。

4.1 题型识别与"答案思路"

面对突发事件如何处理现场发生冲突/投诉，你怎么办 列出处理步骤网络舆情发酵，如何应对
答案思路：先稳住局面，再搞清事实，然后分"眼前"和"长远"两步解决

应急题的材料里往往有一个主要矛盾 + 两三个次要矛盾。你要做的是：把所有矛盾勾出来 → 按轻重缓急排序 → 逐一给对策。排序原则：先群众后单位、先紧急后重要、先现场后机制。

控场（稳情绪/控现场/上报）→ 调研（摸清事实与各方诉求）→ 短对（解决眼前矛盾）→ 长对（建长效机制）
技巧一：四步框架（背到形成肌肉记忆）
  1. 控场：第一时间到场/回应——安抚情绪、疏散人群、控制现场、向领导报告。这是开场动作，漏了直接丢档次分。
  2. 调研：走访当事人、调取记录、听取多方说法，把事实和各方诉求摸清楚。
  3. 短对：针对眼前的每个矛盾逐一出方案——能当场解决的当场解决，不能解决的说明原因、明确时限。
  4. 长对：跟踪回访、反馈结果；举一反三排查同类隐患；建章立制、完善长效机制。
技巧二：三条处理原则
  1. 生命与安全永远第一：涉及人身安全的先救人、先疏散。
  2. 轻重缓急：紧急的（伤人、冲突、舆情爆发）先办，重要的（制度完善）后办；先"灭火"再"防火"。
  3. 先控制局面，再处理问题：情绪不稳的先安抚，现场混乱的先稳住。

第5课 沟通协调

近年高频 · 常驻第3题 · 考的是"会说话、能说服人"
🎯 本课目标：背熟"动之以情 → 晓之以理 → 导之以行"三步沟通法，能针对领导 / 同事 / 群众 / 下属不同对象调整策略。

5.1 题型识别与"答案思路"

与××沟通，列出沟通思路劝说××，争取理解支持 如何说服××配合工作列出解释沟通的内容要点
答案思路：沟通＝先让对方"愿意听"，再让对方"听得进"，最后让对方"动起来"

沟通题不是"吵架"，目的是化解矛盾、达成共识、推进工作。所以答案永远遵循同一条情绪曲线：情 → 理 → 行。

动之以情（肯定/共情，卸下对立）→ 晓之以理（摆事实讲政策算利害，打消顾虑）→ 导之以行（给路径、给支持、提要求，让对方动起来）
技巧一：三步沟通法
  1. 动之以情：先肯定对方的付出/优势，理解对方的处境和顾虑，感谢支持——让对方放下对立情绪。切忌一开口就讲大道理。
  2. 晓之以理：摆背景意义、讲政策要求、算清利害得失；针对对方的核心顾虑，一条一条回应。
  3. 导之以行：给出下一步怎么做、给什么支持、谁来跟进；最后诚挚提出请求或期望。
对象对方心理关键打法
对领导看重大局、效率、责任先汇报事实与方案，讲清利弊得失，请示决策；尊重权威，不越级
对同事 / 平级怕多干活、怕担责换位思考、明确分工、讲大局讲协作，必要时请领导协调
对群众情绪化、诉求具体耐心倾听、稳定情绪，政策讲透讲细，能办则办、给时限、给路径
对下属怕批评、需认可先肯定付出，再指出问题，一起想办法，明确改进要求
对专家 / 专业方重专业判断、怕被外行指挥尊重专业意见，讲清需求背景，争取技术支持和可行性建议

8.2 卷面与答题技巧

卷面

字迹工整不求书法；分条列项；段首不空格（顶格写）；修改用单线划掉，不用涂黑。

字数

贴近上限不超格；按"每点字数＝总字数÷要点数"倒推；写不满时优先补"怎么做"的细节。

关键词

核心词用材料原词；每条首句放总括词；阅卷人30秒一题，第一眼看到的就是分数。

心态

不会的题按框架写满不空；公文格式拿不准就写最保险的"标题+称谓+正文+落款"。
