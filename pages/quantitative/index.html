一、倍数特性
首选武器 ▼
1. 整除型
  • 口诀法（3/4/5/9常用）
    3/9 → 看各位数字之和能否被3/9整除
    2/5 → 看末一位能否被2/5整除
    4/25 → 看末两位能否被4/25整除
  • 拆分法（7/13等无口诀数）
    一个数 = 接近的倍数 ± 零头，只看零头能否整除
    例：623÷7 → 拆成630-7，只看7能否被7整除
  • 因式分解（6/12/18/24等复杂倍数）
    分解为两个互质的数，同时满足
    例：24=3×8，需同时被3和8整除
2. 余数型
若 总数 = ax + b，则 (总数 - b) 能被 a 整除
若 总数 = ax - b，则 (总数 + b) 能被 a 整除
特征：均分、多几个、少几个
3. 比例型【考得最多】
若 a∶b = m∶n（m,n互质），则 a 是 m 的倍数，b 是 n 的倍数
若 a = m/n × b，则 a+b 是 (m+n) 的倍数
题干特征：分数、比例、百分数、倍数；对象特征：不可分割整体（人、年龄等整数）
4. 余数问题三则运算
口诀：余同加余，和同加和，差同减差，公倍数做周期
  • 余同加余：除以7余1，除以6余1，除以5余1 → 210n+1
  • 和同加和：除以7余1(和8)，除以6余2(和8)，除以5余3(和8) → 210n+8
  • 差同减差：除以7余3(差4)，除以6余2(差4)，除以5余1(差4) → 210n-4
210 = 5×6×7 的最小公倍数，作为周期
5. 倍数特性之增长率型
  • 充分利用资料分析的思维解决数量问题
  • 分析关系：基期、现期
  • 结合选项，做猜结合
6. A = B × C 型
用资料分析的思维解决问题，看到 A=B×C 的结构，若 B、C 有比例关系，直接用倍数特性看选项
📝 例题1 · 比例型倍数特性
某高校本年度毕业学生3060名，比上年度增长2%。其中本科生毕业数量比上年度减少2%，研究生数量比上年度增加10%。这所高校本年度本科生毕业数量是：
A.1900　B.1990　C.1960　D.1930
解析：本科生比上年度减少2% → 今年本科 = 98%×去年 = (49/50)×去年
→ 今年本科毕业生人数是 49的倍数
选项中只有 1960÷49=40，整除。
答案：C
📝 例题2 · 余数型倍数特性
车间领到一批电影票和球票，电影票是球票的2倍。如果每个工人发3张球票，则富余2张；如果每个工人发7张电影票，则缺6张。问车间领到多少张球票？
A.32　B.30　C.64　D.60
解析：球票总数 = 3×工人数 + 2 → (球票-2) 能被3整除
选项代入：(32-2)=30✓÷3=10，(30-2)=28÷3✗
答案：A

二、方程法
兜底手段 ▼
1. 普通方程（一个未知数x）
  • 设小不设大：高照是你(x)的两倍 → 设"你"为x
  • 出现比例设份数：高照∶上岸 = 3∶2 → 设3x、2x
  • 设中间量：ta →(+10)高(-20)←你
2. 普通方程组（多个未知数）
  • 设XYZ，抓住问题消元求解
  • 只用留下要的，消好消的
A与非A技巧：问谁非谁。A = (非B + 非C - 非A) / 2
3. 不定方程
ax + by = c（a,b,c已知，x,y为正整数）
  • 奇偶性：3x(奇)+4y(偶)=25 → x必为奇数
  • 倍数（公因子）：7x+3y=60 → 60和3y都是3的倍数 → x是3的倍数
  • 尾数法：看尾数特征排除
  • 代入法：选项代入验证
4. 不定方程组
  • 整数型：消元时注意问啥设啥；提速用约分列式
  • 非整数型（如求总和）：大胆用赋0法，设某个未知数为0简化计算
📝 例题1 · 不定方程（倍数法）
买3斤苹果和5斤梨共36元，苹果和梨的价格都是整数，那么梨的价格可能是多少？
A.2　B.4　C.6　D.8
解析：设苹果a元/斤，梨b元/斤，列式 3a+5b=36
3a是3的倍数，36是3的倍数 → 5b也是3的倍数 → b是3的倍数
选项中只有6是3的倍数
答案：C
📝 例题2 · 不定方程（奇偶法）
3x + 4y = 25，x、y均为正整数，求 y 的值。
A.1　B.2　C.4　D.5
解析：4y是偶数，25是奇数 → 3x必为奇数 → x为奇数
x=1时 y=(25-3)/4=5.5✗；x=3时 y=(25-9)/4=4 ✓
答案：C（y=4）

三、周期问题
高频 ▼
1. 周期余数
总数 ÷ 周期 = 商 ... 余数
余数几就是周期中第几个，余0则是最后一个
注意审题：看清是"第几天"还是"过几天"！
2. 周期相遇
核心：找最小公倍数
注意审题：每隔n天 = 每n+1天
多个主体各有周期，同时出发，下一次同时出现 → 各周期的最小公倍数
分数求公倍数：①分母通分 ②求分子最小公倍数 ③分子最小公倍数÷分母
3. 星期日期问题
  • 平闰年判定：能被4整除为闰年；整百年份需被400整除
  • 整年推断：过一个平年星期+1，过一个闰年星期+2
  • 大月小月：一三五七八十腊（12月），31天永不差
  • 大月余三天：31÷7=4余3
  • 每连续7天：必有周一到周日各1天
  • 每连续28天：必有周一到周日各4天
做题方法：画图 + 枚举
📝 例题1 · 周期余数
"红十字会"四个字按顺序循环排列：红十字会红十字会红……第2025个字是什么？
A.红　B.十　C.字　D.会
解析：周期为4（红十字会）
2025÷4=506……余1 → 第1个字是"红"
答案：A
📝 例题2 · 星期日期问题
2024年1月1日是星期一，问2024年12月31日是星期几？（2024是闰年）
A.星期一　B.星期二　C.星期三　D.星期四
解析：2024是闰年，全年366天
366÷7=52周……余2天
1月1日是星期一 → 12月31日 = 星期一+2 = 星期二
答案：B
📝 例题3 · 周期相遇
甲每3天去一次健身房，乙每4天去一次，丙每5天去一次。三人在1月1日同时去了健身房，问下一次三人同一天去是几月几日？
解析：找3、4、5的最小公倍数 → 60天
1月1日+60天 = 1月1日+31天(1月)+29天(2月闰年) = 3月1日
答案：3月1日

四、工程问题
超高频·易拿分 ▼
工作总量 = 工作效率 × 工作时间（W = P × T）
1. 具体单位型
  • 特征：有具体的效率或总量，有单位
  • 方法：列方程，根据问题求解
  • 选项尾数不同时，只用看尾数
2. 完工时间型【考频最高】
三步走：
第一步：赋值总量为各完工时间的最小公倍数
第二步：求各主体效率 = 总量 ÷ 时间
第三步：列表或列方程求解
复杂方程型：不会解就代入选项
变形：工程费用、周期循环工程、多个工程的完工时间型
3. 效率比例型
给效率比 → 按比例赋值效率（效率比的一份设为1）
给定总量比与时间比，求效率比
4. 牛吃草问题
普通型：y = (N - x) × T
变形型：y = (N + x) × T
  • y = 原有草量，N = 牛的数量，x = 草生长速度，T = 时间
  • 列两个方程，消去y，求x，再求所需量
别漏了消长量x！
5. 统筹工程 & 工程图形
  • 统筹工程：合理安排顺序，最优分配
  • 工程图形：结合图形理解工作过程
📝 例题1 · 完工时间型（赋值法）
一项工程由甲、乙单独完成分别需50天和80天。甲乙合作20天后，剩余工程由乙、丙合作需12天完成，则丙单独完成需要多少天？
A.40天　B.45天　C.50天　D.60天
解析：①赋总量=50和80的最小公倍数 400
②甲效率=400÷50=8，乙效率=400÷80=5
③列方程：400=(8+5)×20+(5+丙效率)×12
→ 400=260+60+12×丙效率 → 丙效率=80÷12 → 不对
重算：(8+5)×20=260，400-260=140，140÷12=11.67... → 丙效率≈6.67
丙时间=400÷(20/3)=60天
答案：D
📝 例题2 · 效率比例型
甲工程队与乙工程队的效率之比为4∶5。一项工程由甲单独做6天，再由乙单独做8天，最后甲乙合作4天刚好完成。如果由甲或乙单独完成，甲比乙多多少天？
A.3　B.4　C.5　D.6
解析：①赋值甲效率=4，乙效率=5
②总量=4×6+5×8+(4+5)×4=24+40+36=100
③甲单独时间=100÷4=25天，乙单独时间=100÷5=20天
甲比乙多 25-20=5天
答案：C
📝 例题3 · 牛吃草
一片牧场长满草，每天草匀速生长。27头牛6天吃完，23头牛9天吃完。问21头牛几天吃完？
解析：设原有草量y，草生长速度x
y=(27-x)×6 且 y=(23-x)×9
→ (27-x)×6=(23-x)×9 → 162-6x=207-9x → 3x=45 → x=15
y=(27-15)×6=72
21头牛：72=(21-15)×T → T=72÷6=12天
答案：12天

📝 例题1 · 同比例放缩
一个正方体的棱长扩大为原来的2倍，则表面积扩大为原来的几倍？体积扩大为原来的几倍？
A.2倍、4倍　B.4倍、8倍　C.4倍、6倍　D.8倍、12倍

📝 例题2 · 勾股定理

六、经济利润问题
超高频 ▼
1. 基础公式
利润 = 售价 - 成本（进价）
利润率 = 利润 ÷ 成本
售价 = 成本 × (1 + 利润率) = 进价 + 利润
总利润 = 单利润 × 销量 = 总收入 - 总成本
总价 = 单价 × 数量
定价 × 折扣 = 售价
注意区分：数量关系中利润率 = 利润/成本；资料分析中利润率 = 利润/收入
2. 三种解法
  • 资料分析法：结合资料分析公式解决
  • 方程法：有具体钱数，根据等量关系设未知数
  • 赋值法：常赋值成本为100，减小计算量
3. 分段计费
方法：边读边画，找准分段临界点，分区间讨论计算
涉及水电、资费、提成等
4. 函数最值（利润最值）
单价↑ → 销量↓ → 利润有最大值
方法：用"两点式"求顶点，不列二次函数
设两个已知点 (p₁, q₁) 和 (p₂, q₂)，求利润=单价×销量的极值
📝 例题1 · 基础经济利润
某商品进价100元，按定价打八折出售仍能获得20%的利润，问该商品的定价是多少元？
A.140　B.150　C.160　D.170
解析：售价=进价×(1+利润率)=100×1.2=120元
定价×折扣=售价 → 定价=120÷0.8=150元
答案：B
📝 例题2 · 分段计费
某市水费分段计价：每月10吨以内（含）每吨2元，超过10吨的部分每吨3元。某家庭某月用水15吨，应交水费多少元？
A.30　B.35　C.40　D.45
解析：前10吨：10×2=20元
超出5吨：5×3=15元
合计=20+15=35元
答案：B
📝 例题3 · 利润最值
某商品定价20元时可卖100件，定价每提高1元销量减少5件。问定价多少时利润最大？（进价10元/件）
解析：设定价提高x元
利润=(20+x-10)×(100-5x)=(10+x)(100-5x)
=1000-50x+100x-5x²=1000+50x-5x²
对称轴 x=50/(2×5)=5 → 定价=20+5=25元
答案：定价25元时利润最大

七、容斥原理
高频 ▼
1. 两集合标准型
A + B - A∩B = 总数 - 都不满足
2. 三集合标准型
A + B + C - A∩B - A∩C - B∩C + A∩B∩C = 总数 - 都不满足
适用：题目给出"满足AB""满足AC""满足BC"的数值
3. 三集合非标准型
A + B + C - 只满足两项 - 2×满足三项 = 总数 - 都不满足
适用：题目给出"只满足两个条件""三个都满足"的表述
4. 画图法
出现"只A"等非标准表述 → 立刻画韦恩图
数据往圈里填，从内向外填（先填最里面的交集，再填各部分，最后填都不满足的）
选项尾数不同时，只看尾数快速判断
5. 多集合反向构造
特征："都……至少……" / "至少……都……"
方法：反向 → 加和 → 作差
A∩B最小 = a + b - 总数
A∩B∩C最小 = a + b + c - 2×总数
6. 容斥结合不定方程（最值）
问法：求最值；方法：此消彼长
📝 例题1 · 两集合容斥
某班38名学生参加两次测试，第一次12人得A，第二次16人得A，两次都没得A的有15人。两次都得A的有多少人？
A.5　B.6　C.8　D.10
解析：套公式 A+B-A∩B=总数-都不满足
12+16-x=38-15 → 28-x=23 → x=5
答案：A
📝 例题2 · 三集合标准型
对39种食物调查：含甲17种，含乙18种，含丙15种，含甲乙7种，含甲丙6种，含乙丙9种，都不含7种。三种都含的有多少种？
A.4　B.6　C.7　D.9
解析：套三集合标准型公式
17+18+15-7-6-9+x=39-7
→ 28+x=32 → x=4（用尾数法更快：7+8+5-7-6-9+x=2 → 尾数7+x→x尾数5→不对，直接算x=4）
答案：A
📝 例题3 · 三集合非标准型

八、最值问题
高频 ▼
1. 最不利构造【常考】

九、数列问题
中频 ▼
1. 等差数列【重点】
通项：aₙ = a₁ + (n-1)d
求和：Sₙ = n(a₁ + aₙ)/2 = n×a中项
中项求和：n为奇数 → Sₙ = n × a(中间项)
平均数 = 中位数 = (a₁ + aₙ)/2
必背：S₉ = 45，S₁₀ = 55（1到n的求和）
64的秘密：直接背，等差数列相关技巧
各项成等差数列 → 每个"时间段"的和也成等差数列
2. 等比数列【考频低】
通项：aₙ = a₁ × q^(n-1)
求和：Sₙ = a₁(1-qⁿ)/(1-q)（q≠1）
等比一般使用枚举法，别浪费精力背公式
3. 特殊数列
  • 星期数列：固定公差为7
  • 季度数列：固定公差为3
  • 不用每次重新推导，直接用等差公式
📝 例题1 · 等差数列中项求和
一个等差数列共9项，中间项（第5项）为10，求这9项的和。
A.45　B.80　C.90　D.100
解析：n为奇数 → Sₙ = n × 中间项
S₉ = 9 × 10 = 90
答案：C
📝 例题2 · 等差数列通项与求和
等差数列首项a₁=3，公差d=2，求第10项a₁₀和前10项的和S₁₀。
解析：a₁₀ = a₁ + (n-1)d = 3+9×2 = 21
S₁₀ = n(a₁+aₙ)/2 = 10×(3+21)/2 = 10×12 = 120
答案：a₁₀=21，S₁₀=120

十、行程问题
高频 ▼
路程 = 速度 × 时间（S = V × T）
1. 基础行程
  • 普通行程：直接套S=VT，类似工程问题
  • 火车过桥：
    路程 = 桥长 + 车长
    给出两种情况时间 → 列两个等式求关系
  • 均加速（新型热门）：平均速度 = 平均数，不要想复杂
  • 等距离平均速度：
    V平均 = 2V₁V₂ / (V₁ + V₂)
    即调和平均速度，适用于往返等距问题
背：3.6 km/h = 1 m/s；288 km/h = 80 m/s
2. 相遇与追及
直线相遇：S = (V₁ + V₂) × T
直线追及：S = (V快 - V慢) × T
环形相遇（反向）：周长 × N = (V₁+V₂) × T
环形追及（同向）：周长 × N = (V快-V慢) × T
多次相遇：
左右点出发第N次迎面相遇：路程和 = (2N-1)×全程
同一点出发第N次迎面相遇：路程和 = 2N×全程
第二次相遇：各走的路程 = 第一次的2倍
相遇追及与水流速度无关！
3. 流水行船
V顺 = V船 + V水
V逆 = V船 - V水
V船 = (V顺 + V逆) / 2
V水 = (V顺 - V逆) / 2
4. 队伍行进
队首→队尾：队伍长度 = (人速 + 队伍速度) × 时间
队尾→队首：队伍长度 = (人速 - 队伍速度) × 时间
5. 比例行程
核心：找相等的量，看比例，找份数
时间相同 → S₁/S₂ = V₁/V₂
路程相同 → V₁/V₂ = T₂/T₁
速度相同 → S₁/S₂ = T₁/T₂
📝 例题1 · 相遇问题
甲乙两人从A、B两地同时出发相向而行，甲速60km/h，乙速40km/h，A、B相距200km。问几小时后相遇？
A.1.5h　B.2h　C.2.5h　D.3h
解析：相遇时间 = 总路程÷速度和
T=200÷(60+40)=200÷100=2小时
答案：B
📝 例题2 · 火车过桥
一列长200米的火车以20m/s的速度通过一座长800米的桥，需要多少秒？
A.30s　B.40s　C.50s　D.60s
解析：路程=桥长+车长=800+200=1000米
时间=1000÷20=50秒
答案：C
📝 例题3 · 流水行船
一艘船顺水速度30km/h，逆水速度20km/h，求船速和水速。
解析：船速=(V顺+V逆)/2=(30+20)/2=25km/h
水速=(V顺-V逆)/2=(30-20)/2=5km/h
答案：船速25km/h，水速5km/h
📝 例题4 · 等距离平均速度
一辆车上坡速度40km/h，下坡速度60km/h（同一条路往返），求平均速度。
A.50　B.48　C.46　D.52
解析：等距离平均速度=2V₁V₂/(V₁+V₂)
=2×40×60/(40+60)=4800/100=48km/h
不是简单的(40+60)/2=50！这是调和平均，不是算术平均

十一、排列组合
高频 ▼
1. 基础概念
排列 A(n,m) = n! / (n-m)!（有序）
组合 C(n,m) = n! / [m! × (n-m)!]（无序）
判断标准：有序（排队）用A，无序（组队）用C
分步用乘法（先…再…），分类用加法（要么…要么…）
2. 捆绑法（相邻问题）
"必须挨着" → 先捆绑为一个整体参与全排列，再内部排列
步骤：①将相邻元素看作一个整体 ②整体全排列 ③内部排列
3. 插空法（不相邻问题）
"不能挨着" → 先排无要求元素，再将不相邻元素插入空隙
n个元素排好产生n+1个空（含两端）
4. 插板法（每人至少1个）
n个相同元素分给m人，每人至少1个 → C(n-1, m-1)
5. 错位排列（直接背）
n123456
Dₙ012944265
6. 环形排列
n个人环形排列 = (n-1)!
7. 平均分组
注意除以组数的全排列，消除重复计数
8. 枚举法
限制条件多、选项数据小 → 逐一枚举，别硬套公式
9. 顺序固定（归一法）
全排列后除以顺序不变的排列数
📝 例题1 · 捆绑法
5人排成一排照相，其中甲乙必须相邻，有多少种排法？

解析：①甲乙捆绑为1个整体 → 4个元素全排列 A(4,4)=24

③总计=24×2=48种

A.36　B.48　C.60　D.72
解析：①先排其余3人 → A(3,3)=6
②3人排好产生4个空，甲乙插入 → A(4,2)=12

把7个相同的苹果分给3个小朋友，每人至少1个，有多少种分法？
A.10　B.15　C.21　D.28

十二、概率问题
中频 ▼
1. 基础公式
P(A) = 满足条件的情况数 ÷ 总情况数
选项中和为1的正确率比较大
2. 分类与分步
  • 分类（加法）：多种情况满足，概率相加
  • 分步（乘法）：多个步骤依次满足，概率相乘
3. 反向概率
P(A) = 1 - P(不A)
正面复杂就求反："正难则反"
4. 给概率求概率
已知各步概率，分步相乘求总概率
5. 比赛类概率
方法：枚举所有可能比分情况，分类计算概率再相加
6. 抓阄密码类
等可能概率：每次概率相同，与先后顺序无关
猜题技巧：正确答案选项的分母比较规整
7. 跟屁虫问题
不放回抽样，前面抽到后面就不抽了
8. 骰子问题
画图辅助，列出所有可能组合
📝 例题1 · 基础概率
从一副扑克牌（54张，含大小王）中随机抽取1张，抽到红心的概率是多少？
A.1/4　B.13/54　C.1/2　D.4/13
解析：红心13张，总54张
P=13/54
答案：B
📝 例题2 · 反向概率
同时掷2枚骰子，至少有1个6的概率是多少？
A.1/6　B.1/3　C.11/36　D.1/2
解析：正难则反 → P(至少1个6)=1-P(都没有6)
P(都没有6)=(5/6)×(5/6)=25/36
P=1-25/36=11/36

📝 例题3 · 分步概率
袋中有3红球2白球，不放回依次取2个球，两个都是红球的概率？
解析：分步相乘
第一个红球：3/5
第二个红球：2/4
P=(3/5)×(2/4)=6/20=3/10

十四、溶液问题
中频 ▼
基础公式
溶液 = 溶质 + 溶剂
浓度 = 溶质 ÷ 溶液 × 100%
混合浓度 = (溶质₁+溶质₂) ÷ (溶液₁+溶液₂)
核心：抓住溶质不变
1. 蒸发稀释类
常赋值溶质为100
蒸发：溶质不变，溶液减少
稀释：溶质不变，溶剂（溶液）增加
2. 混合溶液
线段法（十字交叉法）：
溶液A浓度a ── (c-b) ── 混合浓度c
溶液B浓度b ── (a-c) ──
质量比 A∶B = (c-b)∶(a-c)
三种溶液混合 → 两两混合计算
3. 反复倒出类
剩余溶质 = 原溶质 × (1 - 每次倒出比例)ⁿ
先约分，后计算！可以灵活转换为浓度
4. 连续稀释
每次倒出V，加满水，浓度变为原来的 (1-V/总量) 倍
📝 例题1 · 蒸发稀释
一杯盐水200克，浓度15%。蒸发掉一部分水后浓度变为20%，问蒸发掉了多少克水？
A.30g　B.40g　C.50g　D.60g
解析：溶质不变 → 溶质=200×15%=30克
蒸发后：30÷浓度=30÷20%=150克
蒸发量=200-150=50克
答案：C
📝 例题2 · 十字交叉法
将浓度10%和30%的盐水混合成浓度20%的盐水200克，需要两种盐水各多少克？
解析：十字交叉法
10% ── (20-10)=10 ── 混合20%
30% ── (30-20)=10 ──
质量比=10∶10=1∶1
各需100克
答案：各100克
📝 例题3 · 反复倒出
一杯盐水1000克，浓度20%。每次倒出200克后加满水，重复3次后浓度变为多少？
解析：每次倒出比例=200/1000=1/5
剩余比例=1-1/5=4/5
3次后浓度=20%×(4/5)³=20%×64/125=10.24%
答案：10.24%

小明从1楼爬到5楼用了40秒，以同样速度从1楼爬到10楼需要多少秒？
A.80s　B.90s　C.100s　D.110s
解析：注意：1楼到5楼爬了4层（不是5层！）
每层用时=40÷4=10秒
1楼到10楼=爬9层 → 9×10=90秒
答案：B
📝 例题3 · 货物集中
一条公路上有4个仓库，间距均为10km，从左到右货物分别为：A(10吨)、B(20吨)、C(30吨)、D(40吨)。将所有货物集中到一个仓库，运费最少的是哪个？
解析：核心：轻的向重的方向移动
左侧总重=10+20=30 < 右侧总重=30+40=70 → 向右移
A(10)+B(20)向右移到C → C点集中
验证D：左侧(10+20+30=60) < 右侧(40)？60>40 → 不向D移
答案：集中在C仓库

做题优先级
  • ① 工程问题 → 赋值法直接拿分
  • ② 经济利润 → 公式清晰，计算量可控
  • ③ 容斥原理 → 套公式秒杀
  • ④ 周期/日期 → 画图枚举
  • ⑤ 最值问题 → 最不利+1
  • ⑥ 几何问题 → 公式+量尺
  • ⑦ 溶液/年龄 → 技巧性强
  • ⑧ 行程/排列组合/概率 → 计算量大，最后做
猜题蒙题技巧
① 几何题不会做 → 选居中选项（90%概率）
② 选项中有倍数关系 → 看题干比例直接选
③ 选项尾数不同 → 只算尾数
④ 概率题 → 选项中和为1的正确率大；分母规整的更可能对
⑤ 年龄题 → 结合常识代入排除
⑥ 最值题 → 不确定时取整方向：至少向上取整，至多向下取整
⑦ 排列组合 → 识别不出模型就枚举
⑧ 完全不会 → 统一选B或C（别全选一样）
时间分配
数量关系建议用时 10-15 分钟
挑 3-5 道有把握的题做，其余靠猜题技巧
