解题总框架：3+3 体系

先看图形「像不像」，再进对应分支。这是刘义恒笔记的核心骨架，做题第一反应必须从这里出发。

1
第一步：看整体像不像

图形间有没有「一样的图案」（完全相同 / 部分相同 / 带标记符号）？有 → 左侧三分支；没有 → 右侧三分支。

像
有相同图案 → 三个方向

① 位置：图形完全一样 → 平移、旋转、翻转
② 样式：部分一样（黑白块、线条重复）→ 遍历、加减同异、黑白运算
③ 标记：有黑点 / 箭头 / 小圈 → 看标在哪（上下左右、点线面角）

不像
无相同图案 → 三个方向

① 属性：整体特点 → 对称、曲直、开闭（先看属性，对称优先）
② 数量：数 面 / 线 / 点 / 角 / 素 / 笔画
③ 图形间位置：相离、相交（交面/交线/交点）、包含、相切

💡 黄金顺序：数量题先看属性（对称优先）；图形规整美观 → 先想对称；极端情况（如某图形非常特殊）→ 优先考虑图形间关系。
🎯
先看像不像 → 像：位置·样式·标记；不像：属性·数量·图形间位置
总口诀
1

位置规律

0/9

特征：各图形构成完全相同（外形、数量完全一致），只变位置。口诀：基本相同看位置，再看元素往哪儿走。

位置

平移：有哪两大考法方向？

▶

平移是所有图推里特征最明显的一类：图形长得一模一样，只是有小元素在挪位置。

  • 内外分开看：图形分内外两层时，内层元素在内层走、外层元素在外层走，两层互不干扰 —— 这是高频易错点。
  • 常规平移：上、下、左、右、斜向运动；步数可以恒定（最常见）、递增，也可以循环。
📌 识别特征：图形完全相同 ＋ 有格子 / 宫格 ＋ 小元素在动
  • 步数：恒定（高频）、递增，递减较少 —— 但确定方向才是真正的难点。
  • 出题形式：除「分组分类」外都可能出现 —— 平移不考分组！

两个提速技巧：① 特殊图案优先 —— 锁定一个特殊小元素，追踪它的移动路径最省力；② 数个数 —— 统计移动格数找规律。

例题 1 · 4×4 宫格「内外分开看」

题干：下图中，外圈黑点每次顺时针移动 1 格，内圈三角每次逆时针移动 1 格。观察前 3 图，问第 4 图外圈黑点与内圈三角分别在哪？

A. 黑点在右上、三角在右下　B. 黑点在右上、三角在左上　C. 黑点在下右、三角在右下　D. 黑点在左下、三角在右下
解析：先把两层拆开。
外圈 12 格按顺时针编号：(0,0)→(0,1)→(0,2)→(0,3)→(1,3)→(2,3)→…。黑点每步 +1，第 4 格是 (0,3)，也就是右上。
内圈 4 格按逆时针走：(1,1)→(2,1)→(2,2)→(1,2)，也就是右下，三角每步 +1。
所以第 4 图黑点在右上、三角在右下，选 A。要点是内外各数各的，把两层放在同一条路径上数必错。
答案：A
例题 2 · 第一步该锁定什么

题干：做平移题时，第一眼锁定什么能最快破题？

A. 数每个宫格里的元素总数　B. 锁定一个特殊小元素，追踪它的移动路径　C. 先数封闭面　D. 先判断对称
解析：平移题里元素多，优先追踪「特殊」的那一个（颜色特别、形状特别、位置特殊的），它的移动路径最容易看清。
数总数（A）对平移没用——总数往往不变；C、D 属于数量规律和属性规律的思路，不是平移的做法。
答案：B
平移

宫格类平移：9 / 16 / 25 宫格各自怎么定方向？

▶

宫格类平移的关键是先认清是几宫格，再决定怎么定方向。

  • 9 宫格：直线运动（横向 / 纵向）或绕圈运动（顺 / 逆时针）。
  • 16 宫格：先「数每行 / 每列的个数」——横向黑块数量相同 → 横向运动；纵向相同 → 纵向运动。也可以「数内部个数」，内部相等就考虑内外分开看。
  • 25 宫格：比 16 宫格多 1 圈，斜线运动空间更大；黑块由「单个运动」过渡到「整体运动」。
  • 蜂窝类：与 25 宫格底层逻辑一样，但方向可变（横、左斜、右斜都要看）。
📌 口诀：识别考点看「数个数」，定方向靠「数每行每列」或「找大区域（特殊图案）」。
例题 · 16 宫格怎么定方向

题干：一个 16 宫格中，每幅图都有 4 个黑块。图1、图2、图3 每行都各有 2 个黑块，且黑块整体在往右挪。这说明它在做什么运动？

A. 纵向运动　B. 横向运动　C. 绕圈运动　D. 内外分开看
解析：数每行的个数：三幅图每行都是 2 个黑块、个数相同，说明黑块没有跨行移动，只在行内左右平移 → 横向运动。
反过来，如果每列个数相同，就是纵向运动。方向定下来之后，再去数它每步走几格。
答案：B
位置

旋转：怎么快速判断？

▶

旋转题的图形整体在转，所以先定「往哪转」，再定「转多少」。

  • 方向：① 顺时针　② 逆时针 —— 在图上画一个弯箭头，一眼就能看出来。
  • 角度：45° / 90° / 180° 最常见，常呈等差（30°→45°→60°…）或循环。

整体旋转不好观察时，盯住一条特征线或一个特征角——比如箭头、旗子、缺角的位置。它转到哪，整幅图就转到哪。

📌 口诀：顺逆时针先绕圈，再看角度找答案。
例题 1 · 箭头旋转

题干：图形是一支方向箭头，每次顺时针旋转 90°。已知图1 朝右上（↗）、图2 朝右下（↘）、图3 朝左下（↙），问第 4 图是？

A. ↗　B. ↖　C. →　D. ↓
解析：顺时针 90° 的规律：↗（右上）→ ↘（右下）→ ↙（左下）→ ↖（左上）。
盯住箭头的尖端看它先后去哪：右上 → 右下 → 左下 → 左上。
只看「上下」会误选 C，只看「左右」会误选 D，所以一定要看完整的朝向。
答案：B
例题 2 · 旋转还是翻转

题干：如何一眼确定一组图形考的是「旋转」而不是「翻转」？

A. 图形整体变大变小　B. 图形的「手性」发不发生改变　C. 线条变多变少　D. 图形位置有没有移动
解析：旋转只改朝向，不改手性；翻转一定改手性（变成镜像）。
最快的判法：在图上找一个不对称的记号（一个小缺口、一个字母 F），看它在下一幅图里是「转过去」还是「照镜子」。
改成镜像 → 翻转；只换朝向 → 旋转。
答案：B
位置

翻转：横竖轴怎么翻？和旋转怎么区分？

▶

翻转就是照镜子：图会变成镜像，而且一定有一根「轴」。

  • 左右翻转 = 竖轴对称 → 图形左右互换，上下不变。
  • 上下翻转 = 横轴对称 → 图形上下互换，左右不变。
  • 180° 旋转 ≠ 翻转：它是上下、左右同时都变，但不改手性。

怎么快速区分？在图形上找一个不对称的记号（缺口、字母、小三角），看它下一幅是「转过去」还是「照镜子」：

  • 只换朝向 → 旋转（手性不变，永远能通过转动重合）
  • 变成镜像 → 翻转（手性改变，无论怎么转都重合不了）
📌 口诀：横轴对称上下翻，竖轴对称左右翻，全都变 = 180° 旋转。
例题 · 左右翻转

题干：左图是一个 3×3 的「L」形（竖边在左、横边在下），沿竖直对称轴左右翻转后，应该是下面哪一幅？

A. 竖边在右、横边在下（左右镜像）　B. 竖边在左、横边在上（上下镜像）　C. 竖边在下、横边在左（旋转）　D. 与原图一样
解析：抓住「轴」：竖轴对称 → 每一行左右对调、行本身不动。
原图的黑格在第 1 列（竖边）和最后一行（横边）。左右翻转后，竖边跑到第 3 列、横边仍在最后一行 → A。
B 是上下翻转的结果（竖边还在左、横边跑到第一行）；C 是旋转的结果；D 显然不对。
答案：A
位置

常见陷阱与观察技巧

▶

位置规律最容易踩的坑，是把「相邻比较」当成位置规律。两者的信号刚好相反：

  • 有黑块原地不动 → 想「相邻比较」（图案很「像」，但总有一块没动）
  • 每个元素都在动 → 才是位置规律（平移 / 旋转 / 翻转）

其他几个常用观察技巧：

  • 图形完全一样时优先位置，别急着数数量 —— 位置规律的特征最明显。
  • 实在看不出来时，只看相邻两幅图的变化，比盯着一整行更省力。
  • 出现「2、3 两幅图」时，直接对比这两幅就能判断是平移 / 旋转 / 翻转。
心法：位置规律的特征是「一模一样，只动位置」。一旦图案开始变得「像而不一样」，就该换思路了。
例题 · 先看谁在动

题干：图1→图2、图2→图3 之间，只有一个黑点在移动，其余黑块的位置始终不变。最快判断规律的方法是？

A. 一行一行把 3 幅图的规律都找出来　B. 只对比相邻两幅图，找出「没动的」和「动了的那一个」　C. 先数所有黑块的总数　D. 先判断图形的对称性
解析：题干已经给出关键信号：其余黑块始终不动 → 这是相邻比较，不是位置规律。
做法就是只看相邻两图：把「没动的」圈出来、盯住「动了的那一个」看它走几格。完全不需要把 3 幅图放在一起找统一规律（A 会浪费时间）。
答案：B
位置

旋转与翻转：方向、角度怎么定？

▶

旋转与翻转放在一起考，是因为它们看起来都在「动」，但一个不改手性、一个一定改手性。

  • 作图特点：每幅图的图案相同；在重合的情况下，图案数量会减少。
  • 旋转方向：① 顺时针　② 逆时针。
  • 旋转步数（角度）：30° / 45° / 60° / 90° / 180° —— 90°、180° 是高频。
  • 翻转：(1) 左右翻转 = 竖轴对称　(2) 上下翻转 = 横轴对称。
📌 口诀：左右翻转变左右，上下翻转变上下，全都变 = 180° 旋转。
例题 · 数「变了几边」反推考点

题干：图1 到图2，图形的上、下、左、右四个方向全都反了过来。下列判断正确的是？

A. 一定是左右翻转　B. 一定是上下翻转　C. 一定是 180° 旋转（或两次翻转）　D. 一定是平移
解析：数「变了几边」是这类题最快的方法：
· 只变左 / 右 → 左右翻转（竖轴对称）
· 只变上 / 下 → 上下翻转（横轴对称）
· 上下左右全变 → 180° 旋转
四个方向全变，选 C。注意 180° 旋转前后图形手性不变，能通过转动重合，这是它与「翻两次」的区别（翻两次手性也不变，结果相同，所以 C 的表述最准确）。
答案：C
位置

旋转翻转的「箭头法」「时针法」怎么用？

▶

旋转 / 翻转题里，最靠谱的两招是箭头法和时针法。

  • ① 箭头法（找唯一，定方向）：在图形里找一个「唯一」的点或边作参照物，画出箭头方向。适用于方向性强的图形（↑、A、T、三角形、梯形）。
  • ② 时针法：取 3 个特征点，按同一顺序连线，看是顺还是逆时针。「三个同一」—— 同一起点、同一路径、同一终点。
  • 对比选项：图形较乱时，直接逐项对比选项之间的差异，再回题干验证。
  • 手性判断：顺 / 逆时针方向变了 → 一定发生了翻转；没变 → 只是旋转。
⚠️ 两个提醒：① 图案一样 + 分组分类题型 → 不考位置规律（旋转翻转不考分组）；② 黑球不好看时，可以去看白球。但这些技巧不是万能的，别硬套。
例题 · 什么情况下该用时针法

题干：一组图形图案相同，但你怎么都看不出是旋转还是翻转。下一步最该做的是？

A. 数图形里黑块的总数　B. 取 3 个特征点，按同一顺序连线，比较题干与选项的顺 / 逆时针　C. 数封闭区域　D. 直接猜
解析：看不出旋转还是翻转时，就是在判手性——这正是时针法的用途：取 3 个特征点，按同一顺序连线，方向一致就是旋转、方向相反就是翻转。
A、C 是数量规律的思路，对判断手性没帮助；D 不是方法。
答案：B
位置

「相邻比较」是什么？两个判定信号怎么认？

▶

相邻比较 = 只比「相邻两幅图」之间发生了什么变化，而不是盯着一整行找统一规律。

  • 信号一：有黑块不动 —— 图里有一部分图案原地没动。
  • 信号二：平移没规律 —— 按常规平移怎么数都对不上。
  • 作图特点：图案相同，但相邻两图之间有元素保持不动；普通位置规律则是所有元素都在动。

操作步骤：把第 1 图与第 2 图叠着比 → 看哪几个没动、哪几个动了 → 再看第 2、3 图是否重复同样的变化。配套技巧还是那两条：① 特殊图案（大区域）优先追踪；② 数个数，统计移动格数。

⚠️ 易错提醒：相邻比较是位置规律专属的思路。样式规律、数量规律不要用它，会走偏。
例题 · 什么时候该用相邻比较

题干：一组图形图案几乎一样，但你按平移去数，怎么数都对不上；再仔细看，发现每一幅里都有两个黑块的位置从头到尾没变过。这时应该？

A. 继续硬数平移步数　B. 改用「相邻比较」——只对比相邻两图，盯住「动了的那几个」　C. 转去数封闭面　D. 判断对称性
解析：题干给出的两个信息正好命中相邻比较的两个信号：① 有黑块不动；② 平移数不出规律。
这时不要继续在平移上耗时间（A），应该只比较相邻两图，把「没动的」圈出来、盯住「动了的那几个」看它们各自怎么走。
C、D 是别的规律的思路，此时用不上。
答案：B
总纲

图推的「出题形式」有哪几类？出题人偏好什么？

▶

判断考点之前，先看「卷面长什么样」 —— 出题形式本身就是重要线索。

  • 一组图：4~5 幅 + 问号，最常见的问法。
  • 两组图：第一组找规律，第二组照着用（第二组的第三幅是问号）。
  • 九宫格：横看 / 竖看 / 斜看，规律藏在行列之间，最常考「运算」。
  • 空间类：给立体图形，选对应视图或拼合。
  • 分组分类：给 6 个图形分成两组（①②③ / ④⑤⑥），规律是「分组标准」而不是「顺序」。

出题人偏好（背下来能预判）：

  • 平移、相邻比较 → 不出「分组分类」（平移不考分组）。
  • 样式规律 → 以「两组图」「九宫格」为主。
  • 九宫格 → 偏爱「运算」（加减同异、黑白运算、面数量的加减）。
例题 · 看卷面判考点

题干：一道题给了 6 个图形，要求分成两组（①②③ 与 ④⑤⑥）。下列哪个考点最不可能考？

A. 对称性　B. 图形间关系（相离 / 相交）　C. 平移　D. 一笔画
解析：分组分类的分组依据是「属性或关系」，不是「顺序」。
A 对称性、B 图形间关系、D 一笔画都可以作为分组标准（比如：轴对称的放一组、中心对称的放一组）。
而平移考的是「顺序变化」，必须有前后几幅图连着看，分组分类里根本没有「顺序」，所以平移不出分组分类，选 C。
答案：C

样式

遍历：什么意思？

▶

遍历 = 相同的元素反复出现，但每一行 / 每一组都缺一个。做法就一句话：缺啥补啥。

  • 看三层：形状（○△□）、颜色（黑 / 白 / 灰）、方向（↑↓←→）都要看全，缺哪一层就补哪一层。
  • 常与位置结合：元素种类齐全，但摆放位置在轮换 —— 先按遍历补，再看位置是否也在轮换。
📌 口诀：元素重复看遍历，缺啥你就补个啥。
例题 · 九宫格缺什么

题干：九宫格中每行都含有 ○、△、□ 三种形状各一个，且黑色、白色、灰色各出现一次。右下角问号处应该是什么？

A. 黑色三角形　B. 灰色正方形　C. 白色圆形　D. 黑色圆形
解析：分两层看。
形状层：前两行已经各出现过 ○△□ 一次，第三行只剩「正方形」没出现 → 形状是正方形。
颜色层：黑、白、灰三色在前两行也各用过一次，第三行只剩「灰色」没用 → 颜色是灰色。
两层合起来就是灰色正方形，选 B。
答案：B
样式

加减同异：三种运算是什么？

▶

加减同异：图案「部分一样、位置对应」时，把两幅图叠起来做运算。

  • 求同：保留两图相同的黑块 / 线条。
  • 求异：去掉相同的，保留不一样的部分（高频）。
  • 叠加：把所有黑块 / 线条全部加在一起。

出题人喜欢把它和位置结合：先旋转 / 翻转再运算，或者先运算再整体移动。

  • 先看图1、图2 有没有「相同」的部分——这个决定了「谁在动」。
  • 有相同 → 先运算，再考虑图3 是否还转了；
  • 图2、图3 还有相同 → 说明图1 在动；图1、图3 有相同 → 说明图2 在动。
📌 口诀：线条重复求同异，结合位置别忘记。
例题 · 求同运算

题干：图1 与图2 求同（只保留两幅图都有的黑块）得到图3。已知图1 的黑块在左上、右上、下中；图2 的黑块在左上、左下、下中。图3 应该是？

A. 只有左上　B. 左上和下中　C. 左上、右上、左下　D. 右上、左下
解析：求同 = 取交集。
图1：{左上、右上、下中}；图2：{左上、左下、下中}。
两图都有的是 左上 和 下中 → 图3 只有这两个，选 B。
别和求异搞混：求异是「只留不一样的」，那答案就变成右上、左下（C 里的干扰项）了。
答案：B
样式

黑白运算：什么时候用？怎么验证？

▶

黑白运算：轮廓完全相同，但黑白块的数量不一样（黑块在变）—— 这就是它最明显的信号。

  • 逐格对应：同一个位置上的两块相加，得到结果图那一格。
  • 规则现场推：黑＋黑、黑＋白、白＋黑、白＋白 各得什么，题目会给你一组验证；黑＋白 不一定等于 白＋黑。
  • 验证方法：用第一组推出规则 → 第二组验证 → 第三组应用。

两个提速技巧：① 对比选项找差异 —— 选项之间不一样的那一格，只算那一格；② 相同区域一起看 —— 同色区域一次算完，不要逐格抠。

⚠️ 区分：黑块数量相同 → 位置移动（平移）；黑块数量不同 → 黑白运算。这一条能直接分流两类题。
例题 · 黑白运算

题干：图1 与图2 轮廓相同的 3×3 格，规则是：黑＋黑＝白、白＋黑＝黑、黑＋白＝黑、白＋白＝白。图1 黑块在 (左上、中中)；图2 黑块在 (中中、右下)。问结果图的黑块在哪？

A. 左上、右下　B. 中中　C. 左上、中中、右下　D. 全白
解析：逐格对应，一格一格算：
· 左上：图1 黑、图2 白 → 黑＋白＝黑
· 中中：图1 黑、图2 黑 → 黑＋黑＝白
· 右下：图1 白、图2 黑 → 白＋黑＝黑
· 其余格：白＋白＝白
所以结果只有 左上、右下 两格是黑，选 A。
注意：中中本来是「黑＋黑」，按题目给的规则要变白，这就是最容易错的一格。
答案：A
例题 · 判断该用哪个考点

题干：一组图形轮廓完全相同，但每幅图的黑块个数都不一样（有的 3 个、有的 4 个、有的 5 个）。应该优先考虑？

A. 位置移动（平移）　B. 黑白运算　C. 对称性　D. 一笔画
解析：看黑块个数：数量在变 → 黑白运算；数量不变 → 位置移动。
所以选 B。这是分流这两类题最快的一句话：数量变不变，决定用不用运算。
答案：B

标记

功能元素：重点看标记的哪些位置？

▶

功能元素（标记规律）：每幅图里都有一些小元素（黑点、白点、箭头），它们的作用是当探针。

标记放在哪里，就考那一层的特征：

  • 标在点上（交点 / 切点 / 曲直交点）→ 看交线的特征、引出的线条数量。
  • 标在线上 → 看是直线还是曲线、最长线 / 最短线、线的位置。
  • 标在角上 → 是直角 / 锐角 / 钝角。
  • 标在面里 → 看面的大小（最大面 / 最小面）、形状、对称性、面积。
  • 标在上下左右 → 看图形本体的方位关系。

识别信号很简单：每幅图都有小元素 → 立刻想标记规律；只有个别图有 → 大概率不是。

📌 一句话：标记是「探针」，指到哪一层，答案就考哪一层。
例题 · 标记指的是哪一层

题干：6 个图形各带一个小黑点：图①③⑤ 的黑点标在曲线与直线的交点上，图②④⑥ 的黑点标在两条直线的交点上。这组题的分组依据是？

A. 标记所指交点的类型（曲直交点 / 直线交点）　B. 黑点的颜色　C. 图形的大小　D. 图形的笔画数
解析：标记在哪一层，就考哪一层。这里的黑点都标在交点上，所以考的是「交点是什么类型」：曲直交点 vs 直线交点——正好把 6 个图分成两组。
B 黑点颜色题干没说；C、D 与标记无关，属于别的考点。
答案：A
标记

两个黑点 / 箭头型标记怎么考？

▶

标记里有两种常见形态：两个黑点和箭头。它们的看法不一样。

  • 两个黑点：看两点连线的方向（横 / 竖 / 斜）、连线经过什么（点 / 线 / 面 / 空白）、两点是否在同一面同一区域。
  • 箭头：看指向（上 / 下 / 左 / 右）、与图形线条的关系（平行 / 垂直 / 重合）。
  • 对称图形里的标记：常与对称轴结合 —— 在不在轴上、是否两侧对称分布。
📌 一句话：单点看「位置」，两点看「比较与连线」，箭头看「方向」。
例题 · 两个黑点看什么

题干：每组图形里都有两个黑点：图①③⑤ 的两点连线穿过了封闭区域，图②④⑥ 的两点连线不穿过任何封闭区域。判断依据是？

A. 两点连线的方向　B. 两点连线是否穿过封闭区域　C. 黑点的大小　D. 图形的对称性
解析：两个黑点最基本的两个看法是「连线方向」和「连线经过什么」。
这道题 6 个图的黑点方向各不相同，但「穿不穿过封闭区域」正好分成两组，所以分组依据是 B。
遇到两个标记时，先把两点连起来，再问自己：方向是什么？经过什么？

0/4

属性

轴对称：考什么细节？

▶

轴对称的识别信号：图形很规整、好看，或者含有等腰元素（等腰三角形、箭头形、等边图形）。

看到就往三层里走，一层一层往下：

  • ① 一条轴 → 先看方向：竖轴、横轴、还是斜轴（斜轴常常在旋转）。
  • ② 多条轴 → 先数数量：1 条 / 2 条 / 多条，常呈递增或分组。
  • ③ 方向数量都没有答案 → 看轴与图形的关系：轴是否与某条线重合 / 垂直、是否穿过某个点或面。

做题顺序就是上面 ①②③ —— 大部分题走到 ② 就出答案了，卡住了才走 ③，不要一上来就研究细节。

📌 口诀：规则图形看对称，轴和中心要分清；等腰元素别放过，轴画出来更清晰。
例题 1 · 对称轴数量

题干：图1 是等腰三角形（1 条轴）→ 图2 是长方形（2 条轴）→ 图3 是等边三角形（3 条轴），问第 4 图应该有几条对称轴？

A. 3 条　B. 4 条　C. 5 条　D. 6 条
解析：先数数量：1 → 2 → 3，是等差递增，所以下一项是 4 条，选 B。
能画出 4 条对称轴的常见图形有正方形、正八边形等。
注意：这类题不要去看轴的方向（方向没规律），数量才是规律。
答案：B
例题 2 · 对称轴方向

题干：每幅图都只有 1 条对称轴，且依次旋转：图1 竖轴 → 图2 斜 45° 轴 → 图3 横轴。问第 4 图的对称轴方向？

A. 竖轴　B. 斜 135° 轴　C. 横轴　D. 没有对称轴
解析：一条轴时先看方向：竖（90°）→ 斜 45° → 横（0°/180°），每步转 45°。
所以下一项是 斜 135° 轴，选 B。
这类题不用管图形本身长什么样，只跟踪那一条轴转到哪儿了。
答案：B
属性

中心对称 & 轴+中心：怎么判断？

▶

中心对称的判据只有一句话：图形原地转 180° 能和原图重合。

  • 特征图形：平行四边形、N / Z / S 形、以及相同图形「反着放」。
  • 轴对称 + 中心对称：有两条互相垂直的对称轴（正方形、正六边形、圆）—— 轴和中心都成立。
  • 只有轴对称：比如正五边形（奇数条轴），别误判成中心对称。
📌 口诀：N 形 Z 形 S 形，还有平行四边形，原地旋转 180，中心对称就是它；有种图形很贪心，两条垂直对称轴。
例题 · 中心对称但不轴对称

题干：下列哪个图形是中心对称、但不是轴对称？

A. 正方形　B. 平行四边形（一般的，非矩形菱形）　C. 正五边形　D. 圆
解析：逐个验：
· 正方形：4 条轴 + 中心 → 两项都满足（不是答案）
· 一般平行四边形：转 180° 能重合（中心对称 ✓），但画不出任何对称轴（不是轴对称 ✓）→ 就是它
· 正五边形：只有轴，没有中心 → 反了
· 圆：无数条轴 + 中心 → 两项都满足
记住关键特征图：平行四边形是「只中心、不轴」的典型。
答案：B
属性

曲直性：三种情况 + 内外组合

▶

曲直性看的是「这个图形是由直线还是曲线构成的」，分三种情况：

  • 全直线：单一直线多边形（三角形、方形、五边形…）。
  • 全曲线：圆、弧、月牙这类只有曲线的图形 —— 看到圆和弧，优先想曲直性。
  • 曲直混合：既有直线又有曲线。

内外分开看：图形有内外两层时，按「外层 + 内层」组合来分四类 —— 外直内曲 / 外曲内直 / 外直内直 / 外曲内曲。做法是先看外轮廓，再看内部，两步走。

📌 口诀：单一线条看曲直，曲直共存别忘记；单一直线多边形，全直是它的属性；单一曲线圆和弧，优先考虑曲直性。
例题 1 · 三种情况归类

题干：把下面三个图形分别归入「全直线 / 全曲线 / 曲直混合」：① 三角形　② 圆　③ 半圆（一段弧 + 一条弦）。

A. ①全直线　②全曲线　③曲直混合　B. ①全直线　②曲直混合　③全曲线　C. ①曲直混合　②全曲线　③全直线　D. 三个都是全直线
解析：逐个看「有没有曲线、有没有直线」：
· ① 三角形：只有直线 → 全直线
· ② 圆：只有曲线 → 全曲线
· ③ 半圆：一段弧（曲线）＋ 一条弦（直线）→ 两者都有 → 曲直混合
选 A。关键：③ 半圆最容易被当成「全曲线」，一定要数清楚里面有没有直的边。
答案：A
例题 2 · 内外组合

题干：6 个图形分两组：①④⑥ 的外框是直线形、内部是曲线；②③⑤ 的外框是曲线形、内部是直线。这组题的分组依据是？

A. 图形的大小　B. 内外的曲直组合　C. 图形的对称性　D. 图形的一笔画
解析：题干已经点明：分组看的是「外框 + 内部分别是什么线条」，也就是内外的曲直组合（外直内曲 / 外曲内直），选 B。
做法固定：先看外轮廓是直是曲，再看内部是直是曲，两步定类，不要整体混着看。

属性

开闭性：何时才考虑？

▶

开闭性看的是「图形有没有口子」，分三种：

  • 全封闭：完全围住，没有缺口（圆、方形、日字）。
  • 全开：有敞开的缺口（一条弧、一个开口框）。
  • 半开半闭：既有封闭部分、又有开口。

考频提示：开闭性整体考得不多，属于兜底规律 —— 别的规律都想不出来时再试它。尤其是「半开半闭」很淘气，别的不行才考虑。

📌 口诀：遇到开口看开闭，全开封闭都可行；半开半闭很淘气，别的不行才考虑。
例题 · 开闭性怎么分组

题干：六个图形分别是：① 完整的圆　② 一段弧　③ 完整的方框　④ 一个开口的方框　⑤ 三角形　⑥ 一个半圆。要求分成两组，最合适的依据是？

A. 封闭图形的边数　B. 全封闭 vs 有开口（开闭性）　C. 图形的对称性　D. 图形是否由曲线构成
解析：挑最容易分干净的维度。
· 全封闭：① 圆、③ 方框、⑤ 三角形（3 个）
· 有开口：② 弧、④ 开口方框、⑥ 半圆（3 个）
正好 3 : 3，选 B。
其他选项都分不干净（A 封闭图形边数不统一；C 对称性不是所有图都有；D 曲线/直线在两组里都有）。

数量规律

0/7

特征：元素凌乱、各不相同 → 数量类。六个数点：面、线、点、角、素、笔画。顺序：先属性后数量，用特征图锁定考点。

数量

面的考点：「6+6」记忆口诀是什么？

▶

面 = 图形里白色的、封闭的区域。黑色不算面 —— 这句话是数面时最常犯的错。

识别信号：图形被线条切成好几块、封闭区域很明显，或者图形很「生活化」（切开的西瓜、拼图）。

数完总数还没答案，就往细化考法走：

  • 所有面：每个面分别是什么形状（三角形 / 四边形…）。
  • 只两种图形：整个图里只出现两种形状 → 数「每种各几个」。
  • 三角形：面全是三角形，或数三角形的数量。
  • 最大面 / 最小面：看最大的那块是什么形状、什么属性、面积多大。
  • 相同面：有没有两块完全一样的面 → 数相同面的个数。
📌 口诀：多个窟窿入眼帘，数面考点灵光现；数完无解别放弃，面的形状全考虑；多胞胎面一出现，就要考虑相同面；图形明显大小面，关注形状和属性。
例题 1 · 面数量的递增

题干：一组图形的封闭区域数量依次为 3、4、5，问第 4 个图形应该有多少个封闭面？

A. 5　B. 2　C. 6　D. 8
解析：3 → 4 → 5 是等差递增（每次 +1），所以下一项是 6，选 C。
数面时要点：只数白色封闭区域；被分割出来的每一小块都算一个面；黑色区域不算。
答案：C
例题 2 · 最大面考法

题干：图①③⑤ 的「最大面」是三角形，图②④⑥ 的「最大面」是四边形。这属于什么考法？

A. 面数量的运算　B. 面的大小 + 形状（最大面）　C. 图形间关系　D. 一笔画
解析：题干里出现了「最大面」这个词，就是面的大小考法；再进一步看它「是什么形状」，所以是「大小 + 形状」的组合，选 B。
这类题的固定动作：先把最大面找出来，再看它的形状、属性（对称）、面积。
答案：B
数量

线的考点：直线 / 曲线 / 平行线

▶

线数量的考点就三样：直线数、曲线数、平行线。

  • 直线数：单一直线多边形（三角形、五边形…），属性不行就数直线。
  • 曲线数：单一曲线圆和弧，属性不行就数曲线。
  • 平行线：出现大量平行线段时，数平行线的组数；也常考「内外线条数」「线条的加减」。

顺带一提：笔画数也是线的考点之一，但它有自己的判定方法（见下一张「笔画数」卡片）。

例题 · 数直线

题干：一组图形依次是：三角形（3 条直线）、四边形（4 条直线）、五边形（5 条直线），问第 4 个图形有几条直线？

A. 6　B. 7　C. 8　D. 5
解析：3 → 4 → 5 每次 +1，所以下一项是 6 条直线（六边形），选 A。
要点：只数直线，别把曲线混进来；线段被交点分开时，要按「整条直线」数，而不是按小线段数。
答案：A
数量

点的考点：交点 / 切点 / 曲直交点 / 框上框内

▶

点数量的考点：点 = 线条与线条相交的位置。但考试里不会笼统地问「几个点」，而是分类问：

  • 交点：线与线交叉 / 相接的位置，最常见。
  • 切点：曲线与曲线、曲线与直线「相切」的位置。
  • 曲直交点：曲线与直线的交叉点 —— 图里出现曲线时的提分点。

看到什么特征，就数什么点：

  • 线条交叉很多（大树杈）→ 数交点。
  • 有曲有直、交叉明显 → 数曲直交点。
  • 圆与直线相切多 → 数切点。
  • 图形有外框（金刚罩）→ 按框上 / 框内 / 框外分开数。
📌 口诀：大树杈子非常多，别忘交点数起来；图形有曲又有直，曲直交叉很明显；图形都有金刚罩，围绕外框想考点。
例题 · 曲直交点递增

题干：一组图形中，圆与直线的曲直交点数依次为 1、2、3，问第 4 个图形的曲直交点数？

A. 3　B. 5　C. 4　D. 6
解析：1 → 2 → 3 每次 +1，所以第 4 个是 4 个曲直交点，选 C。
数曲直交点时要只数曲线与直线的交点；两个直线相交的点、两条曲线相交的点都不能算进来。
答案：C
数量

角的考点：直角为主

▶

角的考点里，直角是绝对主角 —— 考试几乎只考直角。

看到「横平竖直、垂直结构多」的图形（直角三角形、十字架、矩形），第一反应就是数直角。

  • 十字交叉：一次产生 4 个直角。
  • 丁字交叉：一次产生 2 个直角。
  • 外框：矩形 / 正方形外框自带 4 个直角 —— 这是最容易漏的地方。
  • 折线：折出多少个角，就数多少个。
⚠️ 三个易错点：① 忘了数外框的直角；② 把锐角、钝角也算进来（只有直角才算）；③ 十字交叉只算 1 个（其实是 4 个）。
例题 · 直角递增

题干：一组图形的直角数量依次为 1、2、3，问第 4 个图形的直角数量？

A. 3　B. 4　C. 5　D. 6
解析：1 → 2 → 3 每次 +1，所以第 4 个是 4 个直角，选 B。
数直角的老规矩：先数外框，再数内部交叉处，最后相加。十字交叉要按 4 个算，别只算 1 个。
答案：B
数量

素的考点：种类 / 个数 / 部分数 / 换算

▶

素 = 独立的小图形。看到图里散着一堆小图案（圆、三角、星、汉字），就想「素」。

四个考法，从易到难：

  • 种类：有几种不同的图形（颜色不同、形状不同都算不同种）。
  • 个数：一共几个，或者每种各几个。
  • 部分数：连在一起的算一部分，分开的算两（多）部分。
  • 换算：1 个大的 = n 个小的（如 1 个星 = 2 个圆），先换成同一单位再相加。

识别信号：多个小图形出现 → 先数种类和数量；生活化图形 / 粗线条 / 汉字 → 数部分数；大小明显不同 → 想换算。

📌 口诀：外框形状要牢记，多个小图形出现，先数种类和数量；生活化或粗线条，部分数量经常考。
例题 · 部分数递增

题干：一组图形依次是：「品」字形（3 部分）→「串」字形（2 部分）→ 完全连在一起的图形（1 部分）。这是什么考法？

A. 面的数量　B. 部分数　C. 图形间关系　D. 一笔画
解析：题干数的都是「分成几块、连不连」—— 这就是部分数。
要点：连在一起（共用边或点）就算一部分。「品」是三个「口」分开 → 3 部分；「串」是两个「口」被一条线穿起来 → 连成 1 大部分加上下方的小块 → 2 部分。所以选 B。
答案：B
数量

笔画数：奇点判定（必考高频易错）

▶

笔画：在不重复的情况下，能不能一笔画成。提示：点可以重复经过，线不能重复画。

判定只靠一个概念 —— 奇点：从该点引出的线条数是奇数，这个点就是奇点。

  • 线条必须连通；不连通要分开算，再相加。
  • 奇点数为 0 或 2 → 一笔画。
  • 笔画数 = 奇点数 ÷ 2。
  • ⚠️ 端点也是奇点，数的时候千万别漏。
  • ⚠️ 奇点一定成对出现（0、2、4、6…），数出奇数个说明数错了。

特征图：五角星、日字及其变形、田字及其变形、切圆、多端点图形、汉字「中」。多笔画一般不超过三笔，常考「一笔 vs 两笔」的分组。

📌 口诀：一根线条画到底，首尾特别要注意（端点即奇点）。
例题 1 · 日字与田字

题干：「日」字和「田」字分别是几笔画？

A. 都是一笔画　B. 日字一笔画、田字两笔画　C. 日字两笔画、田字一笔画　D. 都是两笔画
解析：数奇点：
· 日字：只有上下两个端点引出奇数条线 → 2 个奇点 → 一笔画。
· 田字：四个角是奇点（中间十字交叉处引出 4 条线，是偶点）→ 4 个奇点 → 笔画数 = 4 ÷ 2 = 两笔。
选 B。顺带记牢：日字一笔、田字两笔，这两个图形几乎每年都出现。
答案：B
例题 2 · 汉字「中」几笔

题干：汉字「中」（一个「口」加一竖穿过）是几笔画？为什么很多人会判错？

A. 一笔画，因为竖线上下贯通　B. 两笔画，因为竖线与「口」的交点处引出了 4 条线　C. 三笔画　D. 无法判断
解析：「中」字的图形是：一个方框，中间一竖穿过上下两条边。竖线与框的两个交点各引出 4 条线（2 条竖 + 2 条横） → 这 4 条线是偶数，所以这两个点不是奇点。
真正的奇点在竖线的上下两个端点，共 2 个奇点……等等——如果只看「口 + 竖」，竖的上下两端各露出框外一小段，那两个端点就是奇点（各引出 1 条线），共 2 个奇点 → 一笔画。
但考试里的「中」字，竖线常常不出头，这时竖线的两端正好落在框边上，交点引出 3 条线（1 竖 + 2 横）→ 奇点变成 4 个 → 两笔画。
所以答案是 B：判断的关键是「竖线出不出头」，很多人只凭印象答题，就栽在这里。
答案：B
数量

数量规律怎么快速锁定考点？

▶

数量规律有六个分支，靠什么决定先试哪个？靠图形的特征 —— 特征越强，指向越明确。

强特征 vs 弱特征：

  • 强特征（一眼认出）→ 直接对应考点：窟窿多→面；交叉多→点；五角星 / 日田→笔画；横平竖直→直角。
  • 弱特征（模棱两可）→ 按 属性 → 数量 的顺序试探：先看对称、曲直、开闭，再数数。
  • 数量规律本身常考等差、循环、恒定、和相等（每行之和相等）。

这一步的顺序很关键：先属性后数量。图形很规整就先想对称，别一上来就数数。

图形间五大关系是什么？

▶

图形间关系：图形由几块拼在一起时，考的不是每块长什么样，而是它们彼此之间是什么关系。

一共五种关系：

  • 相离：几个图形独立站，互不接触。
  • 相切：只碰到一个点或一条线（内切 / 外切）。
  • 相交：有重叠 —— 交于点 / 交于线 / 交于面。
  • 包含：一个图形完全包住另一个。
  • 覆盖：一个图形压在另一个上面（被压住的部分看不见）。

识别信号：封闭区域很明显、多个图形独立站，或者图形特别简单（只有两三个），就往图形间关系想。

📌 口诀：封闭空间很明显，图形关系成考点；多个图形独立站，相离关系是答案；多个图形交于点，或者彼此一线牵。
例题 · 线连接还是点连接

题干：图①③⑤ 的两个图形「线连接」（共享一条边），图②④⑥ 是「点连接」（只在一个点接触）。这属于什么考点？

A. 数量规律（数线）　B. 图形间关系（连接方式）　C. 对称性　D. 一笔画
解析：题干看的是「两个图形怎么连在一起」—— 共享一条边还是只碰一个点，这就是图形间关系里的「连接方式」，选 B。
做法：先找那两个图形在哪接触，再判断是点、是线、还是面。注意别被「数线」（A）带跑：数线数的是图形自身有几条线，不是两块之间怎么连。
答案：B

「相交」还能怎么细化？

▶

「相交」是图形间关系里的重头戏，往下还要分三小类：

  • 相交于点：看交点的数量（1 个 / 2 个）、位置（在内部还是边缘）。
  • 相交于线：看相交线的数量（1 条 / 2 条）和长短。
  • 相交于面：看相交部分的形状、大小、属性（是否对称）、面积、边数 —— 这一类比得最多。

做题顺序：先定「交于点 / 线 / 面」，再在这一类里往下细化。两个图形相交于面时，优先看这个面的形状和属性。

📌 口诀：两个图形面交叉，相交面是重头戏；形状大小和属性，全部都是得分地。
例题 · 相交面的分组

题干：两个图形相交于面：图① 的交面是四边形，图② 的交面是三角形。这组题的分组依据是？

A. 两个图形的边数　B. 交面的形状　C. 两个图形的面积　D. 图形的对称性
解析：题干已经点明考的是「相交部分的形状」—— 四边形 vs 三角形，正好分成两组，选 B。
「相交于面」这一类里的固定动作：先看交面的形状，再看它的大小、属性（对称）、面积。如果形状分不开，就往下走一层。

黑白块专项（26版）

0/4

刘义恒黑白块完整框架：对称 / 非对称 / 明显 三大类。黑白块 = 换装的位置+样式+数量，先分类再定位考点。

黑白

黑白块总框架：三大类怎么分？

▶

黑白块题的第一问不是「数几个」，而是「它属于哪一类」。分类错了，后面全错。

三类怎么分：

  • 对称类：图形整体明显对称 → 先识别对称类型，再细化对称轴。
  • 非对称类：看不出对称 → 位置移动 / 黑白运算 / 部分数。
  • 明显类：有明显特征（黑块占一半、连成线、分堆、黑块多且密）→ 面积占比 / 相邻比较 / 笔画。

记忆钩子：先看对不对称，再问数量变不变（变→运算；不变→平移），都不行走「明显特征」路线。

📌 顺序：先对称 → 再非对称（数量 → 部分数 → 一笔画）→ 最后明显类。别一上来就数黑块。
例题 · 第一步该想什么

题干：一组黑白块图形，整体看过去明显左右对称。第一步应该优先考虑什么？

A. 数黑块的总个数　B. 数黑块分成几堆　C. 先识别对称类型，再细化对称轴　D. 数整个图形的笔画
解析：题干的关键词是「明显对称」—— 一旦整体对称，就直接进对称类：先看是轴对称、中心对称还是轴+中心，再看对称轴的方向和数量，选 C。
A、B、D 都是「非对称类」或「明显类」的做法，对称类还没走完之前不该跳到它们。
答案：C

对称类：怎么细化？

▶

判断出是对称类之后，往下细化四层：

  • 先识别：轴对称 / 中心对称 / 轴＋中心。
  • 对称轴的数量与方向（一条轴先看方向，多条轴先数数量）。
  • 对称轴是否切割黑白块：左右（上下）两侧的黑白分布是否一致。
  • 黑块排列成等腰 → 对称规律别忘记；黑块看不出，就去看白块。
📌 口诀：黑块排列成等腰，对称规律别忘记；黑块不行看白块，白块也是重要的。
例题 · 对称轴方向

A. 黑块的数量　B. 对称轴的方向　C. 图形的大小　D. 黑白块的面积比
解析：题干里每幅图都能画出一条对称轴，而分组靠的是「轴是竖的还是横的」—— 这就是对称类的第二层考法：对称轴方向，选 B。

非对称类：三选一怎么定？

▶

看不出对称，就进非对称类。这里只有三条路，按顺序试：

  • ① 数量：黑块 / 白块各几个 —— 数量不同往往是关键。
  • ② 部分数：黑块连成几堆（连在一起算一堆）。
  • ③ 一笔画：黑块连成一整片时，数奇点判一笔画。

更细一层：黑块数量相同 → 位置移动（平移）；黑块数量不同、轮廓相同 → 黑白运算；黑球分堆 → 部分数（甚至做部分数的运算：黑−白、黑÷白）。

📌 口诀：黑球分堆图中现，部分数量来考虑；黑球白球都重要，实在不行做运算。
例题 · 三选一怎么定

题干：连续 3 幅 3×3 图里，黑块个数都是 2，整体看不出对称。应该优先考虑什么考法？

A. 黑白运算　B. 位置移动（平移）　C. 面数量　D. 直角数量
解析：先看数量：三幅图黑块个数都是 2，没有变化 → 不可能考黑白运算（运算会让数量变），而是位置移动，选 B。
这就是非对称类的第一条判据：个数相同 → 平移；个数不同 → 运算。选定了再去看方向 / 步数。

明显类：还有什么花活？

▶

明显类走的是「一眼就看出不寻常」的特征：

  • 面积占比：黑块占整体 1/2、1/3、1/4，或者黑块被网格分割后看面积。
  • 大小明显：黑色面积与白色面积比大小。
  • 相邻比较：两图之间只有 1~2 处不同 → 逐对比较。
  • 笔画 / 周长：所有黑块连成线 → 数笔画；黑块周长 10 / 12 分组。
  • 图形间关系：黑面与白面相交的线条数、黑面与白面的个数、黑面与外框的关系。
📌 口诀：所有黑块连成线，笔画数量是考点；黑块图中占一半，先看黑块的面积；黑块形状较丰富，黑块种类数一数。

空间重构：六面体 + 四面体

0/6

核心心法：所有方法都是排除法；技巧不是越多越好，越熟越好。最推荐组合：箭头法（主）+ 公共边（辅）。

空间

六面体解题「三步走」是什么？

▶

先明确一件事：所有空间重构的技巧都是排除法 —— 能排除就排除，不要试图「拼出对的答案」。

解题三步走（顺序不能乱）：

  • 第一步：找相对面 —— 选项里一旦出现相对面，直接排除该选项。
  • 第二步：找唯一边或唯一点 —— 有唯一边用箭头法，有唯一点用画边法。
  • 第三步：找关联点 —— 两个面近、一个面远 → 用公共边；三个面都近 → 用公共点。

另外要认清折叠方向：靠想象力时要注意是往里折还是往外折；靠技巧时用的是排除法，不需要真的把盒子折出来。

例题 · 1-4-1 结构找相对面

题干：展开图为 1-4-1 结构：上排是 A；中间一排是 B、C、D、E；下排是 F（在 E 的正下方）。与面 A 相对的是哪个面？

A. B　B. C　C. F　D. E
解析：「相隔一个面」就是相对面：
· 中间一排 B、C、D、E：B 与 D 相隔 C，相对；C 与 E 相隔 D，相对。
· A 在最上面、F 在最下面，两者之间隔了整个中间一排 → A 与 F 相对，选 C。
记住口诀：同行同列隔一个、Z 字两端，都是相对面。
答案：C
空间

相对面：两条识别口诀？

▶

相对面是六面体题的第一道筛子：找出来之后，选项里只要出现一组相对面，那个选项直接排除。

两条识别口诀：

  • 同行 / 同列相隔一个面 —— 中间隔了 1 个面（或 1 列），这两个面就是相对面。
  • Z 字形两端 —— 紧邻 Z 字中线的两个面，也是相对面。

为什么有用：相对面在立体图形里永远不可能同时被看见。所以只要选项把一对相对面画在一起，就是错的。

  • 优点：很快，几乎不用动脑，适合当第一道筛子。
  • 缺点：实战中出现次数少，只能排除个别选项，不能直接定答案 —— 所以还要会箭头法、公共边、画边法。
📌 口诀：中间隔 1 个，或隔 1 列，都是相对面。
例题 · 找相对面

题干：同一张展开图（B、C、D、E 一排四个面），下列哪两个面是相对面？

A. B 与 C　B. C 与 D　C. B 与 D　D. D 与 E
解析：用「相隔一个面」这句口诀：一排四个面 B、C、D、E 里，隔一个就是相对面 —— B 与 D 相隔 C、C 与 E 相隔 D。
相邻的面（如 B 与 C、C 与 D、D 与 E）是相邻面，不是相对面。所以选 C。
答案：C
空间

箭头法：口诀 + 操作步骤？

▶

箭头法是六面体题最主用的方法，口诀四个字：找唯一，定方向。

  • ① 找唯一：结合选项，找出一个「唯一点」或「唯一边」（就是那个图案最特别、最好认的位置）。
  • ② 定方向：以这个唯一的位置为参照物，画出箭头方向。
  • ③ 比对：题干和选项的箭头方向必须一致 —— 不一致就排除。

几个实战要点：

  • 找不到唯一时，优先看直接靠在一起的面和位置居中的面（好观察）。
  • 双箭头：两个面都能找到唯一方向时，画两个箭头比它们的夹角 —— 解决「都在右边、忽略细节」的问题。
  • 缺点：没有直接相邻时需要移动（这时用公共边补）。
例题 · 箭头法的操作顺序

题干：用箭头法解六面体题，核心的操作顺序是？

A. 先画箭头定方向，再去找唯一的点或边　B. 先找唯一点或唯一边，再以它画箭头定方向，最后与选项比对　C. 先数面数，再数棱数　D. 先把展开图折成盒子再说
解析：箭头法的顺序是「先找、再画、后比」：
① 找唯一点 / 唯一边 → ② 以它画箭头定方向 → ③ 与选项比对方向是否一致。
A 把顺序颠倒了（没找到参照物就画不出可信的箭头）；C、D 都不是箭头法的内容。所以选 B。
答案：B
空间

公共边：快速记忆三条？

▶

公共边 = 两个面共同拥有的那条边。折叠之后，公共边两侧的图案必须对得上。

三条必须背下来：

  • ① 相邻两个面共用的那条边就是公共边。
  • ② 展开图中构成「一条直线」的两条边，折叠后是同一条边。
  • ③ 相隔一条边的两条平行边，折叠后也是同一条边。
  • 优点：公共边周边的图案一对比，区分度快，不用想象也能排除。
  • 缺点：图案一样时左右容易混淆 —— 这时配上箭头法就能解决。

什么时候用：三个面相邻、又找不到唯一点 / 唯一边时，就先去找公共边。

例题 · 构成直角的两条边

题干：在展开图里，「构成直角的两条边」折叠之后是什么关系？

A. 互为平行边　B. 是同一条（公共）边　C. 是一条对角线　D. 没有关系
解析：这是公共边的第二条规律：展开图中构成直角的两条边，折起来之后会「合上」成为立体图形上的同一条边，选 B。
记成一句话：成直角的两条边，折后合成一条边。做题时拿它去对选项的边两侧图案，对不上就排除。
答案：B
空间

公共点 & 画边法：什么时候用？

▶

公共点：相邻三个面交会的那个点，在立体图形里是唯一的。

  • 折叠前后，公共点引出的线或图形保持不变 —— 题干里这个点引出了什么，选项里也必须一样。
  • 优点：唯一性强，不用纠结选哪条公共边；图案和线条多时排除更快。
  • 缺点：三个面相对位置一错，顺 / 逆时针就分不出来了。

画边法：有唯一点时用它查方向细节，三步走：

  • ① 找一个唯一点或唯一边。
  • ② 从它出发，沿顺时针方向给边标号（1、2、3、4）—— 题干和选项必须描同一个面。
  • ③ 对应位置的图案 / 颜色对不上，直接排除。
⚠️ 画边法偏慢，用来查「方向细节」。三个「同一」要记牢：同一个面、同一个起点、同一方向。
例题 · 画边法的「三同」

题干：用画边法给边描号时，最关键的「三同」是什么？

A. 同一个面、同一个起点、同一个方向　B. 同一个颜色、同一个大小、同一个形状　C. 同一个角度、同一条边、同一个点　D. 同一张图、同一个选项、同一个答案
解析：画边法最容易出错的地方就是「描的不是同一个面」或「起点不同」—— 那样标出来的 1、2、3 号边根本没有可比性。
所以关键是同一个面、同一个起点、同一个方向（顺时针），选 A。题干和选项两边都严格按这三条来，标号才能对齐。
答案：A

四面体 + 特殊题型怎么办？

▶

四面体比六面体简单：只有 4 个面，每个面都是三角形，方向感更强，箭头法就够用。

流程只有两步：

  • 有「唯一边或唯一点」 → 优先用箭头法（备选画边法）。
  • 没有唯一边 / 唯一点 → 优先用公共边。

公共边的两条规律（四面体必背）：

  • ① 展开图中构成一条直线的两条边，折叠后是同一条边。
  • ② 平行四边形两端的两条边，是同一条边。

几条特殊情况（知道就行）：

  • 6 个面都一样 → 找「特殊关系」（特殊图形 / 特殊线）。
  • 同一立方体的不同视角 → 位置关系不变，用箭头法 + 公共边代入选项。
  • 组合展开图（4 部分拼成）→ 先找「唯一」，再用斜线 / 特征线与目标面相邻关系判断。
核心秘密：箭头法熟悉之后 = 你有了「想象力」。新手先练箭头，再练画边。

解析：这是四面体公共边的第一条规律：展开图里构成一条直线的两条边，折起来之后会合成同一条边，选 B。
配合第二条（平行四边形两端的两条边也是同一条）一起背，四面体的公共边题基本就只剩「对号入座」了。

三视图

三视图指的是什么？怎么与「视图」区分？

▶

三视图指的就是三个固定方向的投影：

  • 主视图：从正面看（从前往后）。
  • 俯视图：从头顶向下看（从上往下）。
  • 左视图：从左侧看（从左往右）—— 注意是从左边看过去，看到的是左侧面。

三视图 vs 视图：题目说「三视图」，就锁定主视、俯视、左视这三个方向；只说「视图」，则可能是任意角度。一字之差，做法完全不同。

两种常见问法（先判清是哪一种）：

  • ① 给出立体图形，问「符合的俯视图 / 左视图是哪一项」→ 考同一个物体的三个视图。
  • ② 给一组视图，问「选哪项填入问号处使其呈现规律」→ 本质是数量 / 位置规律，按图推那套做。
例题 · 三视图还是视图

题干：题干只说「选一个符合的视图」，没有限定方向。这时应该？

A. 只按主视图看　B. 先看清题目是否限定了「俯视 / 左视」等具体方向；没限定就可能是任意角度　C. 直接放弃　D. 只按俯视图看
解析：「三视图」和「视图」是两个不同的东西：三视图只指主视、俯视、左视三个固定方向；「视图」可以是任意角度。
所以拿到题先看限定词：限定了方向就按那个方向投影；没限定就要考虑任意角度，选 B。
答案：B
三视图

画三视图的 4 个注意点是什么？（最易错）

▶

三视图最容易错的地方不在「会不会看」，而在这四条细节：

  • ① 都是平面图：观察到的三视图必须是平面图，不能有立体感 —— 有透视感的选项直接排除。
  • ② 原图有线，选项不一定有线；原图没线，选项一定没线。 这是排除法的核心依据。
  • ③ 被遮挡的部分看不见：被挡住的棱可以用虚线表示，也可以不画。
  • ④ 曲面投影后变成直线：圆的侧面投影是一条直线。
⚠️ 核心口诀：原图没线 → 选项一定没线。这一条能直接排除一批选项，是拉开差距的地方。
例题 · 用「有线没线」排除

题干：原图中某处没有这条棱，选项里却画出了这条线。这个选项应该？

A. 保留，可能是被遮挡的线　B. 直接排除　C. 保留，只要轮廓对就行　D. 无法判断
解析：「原图没线 → 选项一定没线」是硬规则。
原图根本没有这条棱，就不存在「被遮挡」的问题 —— 被遮挡说的是原图有、但看不见。所以选项画出了这条线，一定是错的，直接排除，选 B。
反过来：原图有线时，选项可以有、也可以没有（可能就是被遮挡了），这时不能只凭这一条排除。
答案：B
截面

截面题有哪两条高频结论？

▶

截面题的做法只有一个：先想「刀怎么下」—— 横着切、竖着切、还是斜着切。

正方体的截面（能截出什么）：

  • 三角形：只可能是锐角三角形，截不出直角三角形，也截不出钝角三角形。
  • 四边形：矩形、梯形、平行四边形都可以。
  • 五边形、正六边形（过六条棱的中点截）。

圆柱的截面：

  • 横切（平行于底面）→ 圆。
  • 斜切（不过底面）→ 椭圆。
  • 竖切（垂直于底面）→ 矩形。
例题 · 正方体的截面

题干：用一个平面去截正方体，下列哪种截面不可能出现？

A. 锐角三角形　B. 直角三角形　C. 正六边形　D. 五边形
解析：正方体有六个面，任何一个截面最多和三个面相交成三条边；而且因为三个面两两垂直，形成的三角形三个角都是锐角。
所以只可能是锐角三角形，绝不可能是直角三角形（也不可能是钝角三角形），选 B。
A、C、D 都可以：锐角三角形随便斜切就得到；正六边形过六条棱的中点；五边形也能截出。
答案：B
三视图

三视图与立体图形的「转换思维」怎么用？

▶

三视图和立体拼合经常连在一起考：给你一个视图，问哪个立体能拼出来。

做法：把视图还原成平面数字网格（每格的数字代表该处的高度），再拿这个网格去和选项比对。

  • 先数方块总数 / 层数，把明显对不上的选项排除。
  • 逐层相加：把选项的每一层加进网格，看能不能正好凑成目标网格。
  • 数字网格是桥梁：视图 → 网格 → 立体，把三维问题降成二维计数问题。
📌 一句话：先用「数字网格」把立体翻译成平面，再用数数解决问题 —— 正确率会明显提升。
例题 · 转换思维怎么用

题干：已知俯视图中某个位置的高度是 2，选项中该位置的方块堆了几层？

A. 1 层　B. 2 层　C. 3 层　D. 任意层都行
解析：数字就是高度：俯视图里某格写 2，说明这个位置从下往上堆了 2 层方块，选 B。
这就是「转换思维」的核心：把三维问题写成二维数字网格，再一格一格对。俯视图给「每个位置堆几层」，主视图给「每一列最高多少」，左视图给「每一行最高多少」——三者互相约束。
答案：B
三视图

做三视图题的「答题思路」是什么？

▶

三视图题的思路可以浓缩成一句话：外部轮廓定方向，内部线条定选项。

  • 第一步：看外部轮廓 —— 根据外轮廓锁定方向，这一步能排掉一批明显不符的选项。
  • 第二步：看内部线条 —— 用内部线条的有无、位置，在剩下的选项里定选。

两个补充判断：

  • 找不到特殊图形时 → 看线条是否平行、是否被遮挡（遮挡处不画线）。
  • 图形较乱时 → 直接对比选项之间的差异，再回题干验证。
  • 判断某条线要不要画时，问自己一句：这条线在那个方向上看得到吗？
例题 · 先看什么

题干：拿到一道三视图题，第一步最该做的是？

A. 逐条线判断要不要画　B. 先看外部轮廓，锁定方向并排除明显不符的选项　C. 先数方块总数　D. 先判断图形对称性
解析：正确顺序是「先粗后细」：
① 先看外部轮廓，锁定方向、排掉一批明显不符的选项；
② 再用内部线条在剩下的选项里定答案。
A 是第二步的活，一上来就逐条线判断会很慢；C、D 与三视图无关。所以选 B。

立体拼合

「看选项，选方法」的速记口诀是什么？

▶

立体拼合不要一上来就硬拼 —— 硬拼是最慢的办法。先看选项之间差在哪，再决定用哪种方法。

速记口诀：① 个数　② 层数　③ 特殊

  • ① 选项个数有差别 → 优先数个数：把每个选项的方块数数出来，和题干对比，个数不对直接排除。选项里 3 个一致时，尽量不用这一招（省时间）。
  • ② 选项分层明显 / 每层个数不一样 → 优先分层数：把立体按高度切成几层，逐层数。数层数性价比最高；每层个数一致的选项，正确可能性更高。
  • ③ 找特殊：题干里最大或最抽象（不规则）的那块，优先代入。越大 / 越抽象的块，位置局限性越大，越好排除。
例题 · 先数个数

题干：四个选项的方块个数明显不一样（A 有 3 块、B 有 4 块、C 有 5 块、D 有 6 块），题干图形需要 4 块。这时最快的做法是？

A. 逐个选项硬拼　B. 直接数个数，个数对不上的排除　C. 先数封闭面　D. 先判断对称性
解析：选项个数有差别 → 优先数个数。
题干需要 4 块，那么 A（3 块）、C（5 块）、D（6 块）全部直接排除，只剩 B。
这就是「看选项选方法」的价值：先看选项差在哪，就能用最省力的方法 —— 硬拼（A）是最后才用的办法。
答案：B
立体拼合

例题：怎么从「分层数」快速选出答案？

▶

当选项分层明显、或每层个数不一样时，就用分层数：把立体按高度切成几层，逐层看。

  • 先数题干每层有几块，记下来。
  • 再把选项的每一层加进来，看哪一项能正好凑齐。
  • 每层个数一致的选项，正确可能性最高；数每层个数时，优先考虑不旋转的情况。

另一种做法是转成平面图：把题干图形标出每格的层数（数字网格），再和选项逐层相加。两种做法本质一样，看哪种更快。

例题 · 什么时候用分层数

题干：四个选项的分层结构明显不一样（有的 3 层、有的 4 层，且每层个数不同）。这时应该优先？

A. 优先数总个数　B. 优先分层数，逐层核对　C. 优先判断对称性　D. 优先数封闭面
解析：题干给的关键信息是「分层明显、每层个数不一样」—— 这正是分层数的适用条件，选 B。
反过来，如果选项总个数差别很大，才优先数个数（A）。一句话：差在哪，就数哪。
答案：B
例题 · 分层数的关键前提

题干：用分层数解立体拼合时，关于「旋转」应该怎么处理？

A. 优先考虑旋转　B. 优先考虑不旋转，旋转是最后的手段　C. 必须旋转才能解　D. 与旋转无关

所以顺序是：先试平移（不旋转）→ 不行再试旋转 → 最后才试翻转，选 B。

不规则图形：最实用的排除技巧是什么？

▶

不规则展开图（也叫立体空间不规则）不要硬折，用两个排除技巧就够了。

技巧① 选项找差异，公共边做排除

  • 选项找差异：先比选项之间不同在哪，再看这些不同点在题干里能不能成立。
  • 公共边长度必须相等：长度不等的直接排除 —— 这一条在不规则展开图里几乎必用。

技巧② 题干找特殊，看周边

  • 找题干里最大的面或带标记的那块，这是突破口。
  • 重点看它周围有几个面、都是什么面。
  • 示例：题干最大面周围应出现三个灰面 → 选项里哪个能对上就用哪个；最大面右端应是白色长方形面 → 直接排除不符项。
例题 · 不规则展开图先做什么

题干：拿到一道不规则展开图的拼接题，四个选项都差不多，最有效的第一步是？

A. 硬把展开图折成盒子　B. 先比选项之间差在哪，再看这些差异点在题干里能否成立　C. 先数一共有几个面　D. 先判断对称性
解析：四个选项「都差不多」时，差异点就是唯一的抓手：找出它们不同的那条边 / 那个面，回题干里检验。
再配合公共边长度必须相等这条硬规则，往往一两条就能排除掉三个选项。
A 硬折既慢又容易错；C 数面数没有区分度；D 与拼接无关。

平面拼合

「只有白色面」的平面拼合：原理与解法？

▶

平面拼合（只有白色面）：给出几块碎片，问哪一项能拼成题干的目标图形。

出题者怎么画：画一个图形之后，先复制粘贴，再切割 —— 所以每块碎片其实来自同一个图形。

  • 基本原则：图形只能上、下、左、右平移，不能旋转、不能翻转。
  • 解题三步：① 找特殊线条（唯一的长线或横竖线）→ ② 找等长的线 → ③ 必要时拆分选项。

核心思路：既然碎片是「复制后切割」出来的，就一定能拼回原图 —— 所以盯住特有的边和角即可。

例题 · 白色面拼合能不能旋转

题干：「只有白色面」的平面拼合题，碎片可以做什么变换？

A. 平移、旋转、翻转都可以　B. 只能平移，不能旋转和翻转　C. 只能翻转　D. 只能旋转
解析：只有白色面的平面拼合，碎片只能平移（上、下、左、右），不能旋转、不能翻转，选 B。
这一点和「黑白面」的平面拼合正好相反 —— 黑白面因为翻过来颜色会变，所以允许旋转和翻转。做题时先看清是白色面还是黑白面。
答案：B
平面拼合

「黑白面」的平面拼合：为什么能旋转翻转？

▶

平面拼合（黑白面）：给四张纸片，每张一面黑、一面白 —— 翻过来颜色就变。

  • 基本原则：可以平移、旋转、翻转（和「只有白色面」不同！）。
  • 解密关键：旋转 → 颜色一致；翻转 → 颜色变化。本质就是区分旋转和翻转。
  • 做法的选择：只考平移时按边长对齐；允许旋转 / 翻转时，先看颜色能不能对上，颜色对不上直接排除。

对比记忆：

  • 只有白色面 → 只能平移，不能旋转翻转。
  • 黑白面 → 可以平移、旋转、翻转，靠颜色变化判断是否翻转。
例题 · 黑白面怎么判断翻转

题干：黑白面的平面拼合中，怎么判断碎片在拼合时发生了「翻转」？

A. 看形状有没有变大　B. 看颜色分布有没有变化　C. 看边数有没有变　D. 看面积的多少
解析：黑白面纸片翻过来颜色就换（黑变白、白变黑），所以「颜色分布变了」就等于发生了翻转，选 B。
而旋转不会改颜色分布，只改朝向 —— 这正是旋转与翻转的分界线。
实战用法：先比颜色，颜色对不上的选项直接排除；颜色都对得上，再用时针法查方向。
答案：B
折纸

折纸（折叠）类怎么做？

▶

折纸（折叠） 本质上考的还是对称性 —— 折痕就是对称轴。

  • 对折一次 → 1 条折痕；对折两次 → 2 条折痕（折几次就有几组对称轴）。
  • 展开后，图形必须关于每一条折痕对称。
  • 剪掉一块 → 展开后会出现它的镜像，而且是「成对出现」。

做题顺序：数折痕 → 判断折痕方向 → 用对称性筛选项 → 再看内部花纹。

  • 洞的数量：折一次 → 1 个洞展开成 2 个；折两次 → 展开成 4 个。永远是 2ⁿ 的倍数。
  • 选项里多出 / 少掉洞的，直接排除。
例题 · 折纸的本质

题干：正方形纸片沿一条对角线对折，再沿另一条对角线对折，展开后的图形应该关于什么对称？

A. 只关于一条对角线对称　B. 关于两条对角线都对称　C. 关于四条边都对称　D. 没有对称性
解析：折痕就是对称轴：沿第一条对角线折 → 展开后关于这条对角线对称；再沿另一条对角线折 → 又多一条对称轴。
两次折叠一共产生两条互相垂直的对角线折痕，所以展开图必须同时关于这两条对角线对称，选 B。
选项里只关于一条对角线对称的，直接排除。

技巧性：为什么「优先考虑不旋转」？

▶

立体拼合里有一条铁律：优先考虑不旋转。

  • 绝大多数题目的答案不需要旋转，先按「只平移」验证一遍，能省大量时间。
  • 只有「不旋转」拼不出来时，才允许旋转（题干通常也会说明）。
  • 理由：一旦允许旋转，可能性会成倍增加，硬试很慢。

落地做法：

  • ① 先找到一块「凸出最多」的块，按它原本的方向放进去。
  • ② 填完一层再填下一层。
  • ③ 走不通时，只对「最难放的那块」尝试旋转。
  • ④ 一次只改一个块的朝向，改完立刻核对，方便回溯。

① 多数题的答案本来就不需要旋转，先按「只平移」验证一遍，往往直接就出来了；
② 一旦允许旋转，可尝试的摆放方式成倍增加，硬试非常耗时。
所以顺序是不旋转 → 旋转 → 翻转，选 B。注意 C 不对：旋转不是「一定错」，只是「先别急着用」。

选修一：平面图推思维导图串讲

补自刘义恒 91 页笔记选修第一节（P75–P85） —— 用思维导图把前六节的平面考点串成一张网，适合二轮复习时快速过一遍。

串讲

平面图推怎么「一张图串起来」？

▶

串讲的主线只有一句：先看「图案像不像」，它直接决定用哪一套方法。

  • 完全一样 → 位置规律（平移 / 旋转翻转 / 相邻比较）。
  • 部分一样 → 样式规律（遍历 / 加减同异 / 黑白运算）。
  • 都不一样 → 属性规律（对称 / 曲直 / 开闭）→ 数量规律（面线点角素笔画）→ 图形间关系。

串讲的作用：把分散的考点按「看到什么特征 → 想哪个考点」重新连起来，练成条件反射。考场上没有时间去回忆目录，只有条件反射才管用。

  • 特例：图形特别简单（两个圆）或特别复杂（一堆黑块）→ 直接看「图形间关系」。
  • 空间类另成一条线：六面体、四面体、三视图、立体拼合、平面拼合、折纸。
例题 · 第一根主轴

题干：拿到一道图推题，第一件事应该判断什么？

A. 先数封闭面　B. 先看「图案是不是都长得一样」　C. 先数交点　D. 先判断一笔画
解析：先看图案像不像，这是整张导图的第一根主轴：
· 完全一样 → 位置规律
· 部分一样 → 样式规律
· 都不一样 → 属性 / 数量 / 图形间关系
把这一步判断对了，后面就只是在对应分支里找叶子。A、C、D 都是「数量规律」分支里的动作，跳过了第一步。
答案：B
串讲

串讲里的高频易错点有哪些？

▶

把最常见、最容易丢分的地方列成一张清单，考前过一遍：

  • ① 一上来就数数量 —— 图案相同也可能考位置，先看「像不像」再决定数不数。
  • ② 忘了「相邻比较」 —— 总有一块不动就是相邻比较，不是位置规律。
  • ③ 求同 / 求异记反 —— 求同＝留相同；求异＝去同存异（求异是高频）。
  • ④ 黑白运算漏验证 —— 黑＋白 不一定等于 白＋黑，必须找一组验证。
  • ⑤ 数面时把黑块算进去 —— 面只数「白色的封闭区域」。
  • ⑥ 笔画忘了「连通」 —— 线条不连通要分开算，再相加。
  • ⑦ 对称只数到「方向」 —— 方向一样时还要数数量，最后看轴与图形的关系。
  • ⑧ 三视图方向搞混 —— 左视图是「从左往右看」，不是「看左面」。
⚠️ 这八条其实只源于一件事：顺序错了。图推没有难题，只有「步骤乱」的题。
例题 · 最常见的失分点

题干：一笔画题最常见的失分点是？

A. 忘记端点是奇点　B. 忘记判断图形特别复杂　C. 忘记数面　D. 忘记对称
解析：数奇点时，端点（只有一条线连着的那一头）也是奇点 —— 这是最容易漏的地方。漏掉端点，奇点数就少算了，笔画数自然错。
另外还要记两条：① 线条必须连通，不连通要分开算再相加；② 奇点一定成对出现，数出奇数个说明一定数错了。所以选 A。
答案：A
串讲

二轮复习怎么用它？

▶

这张导图最好的用法不是「看一眼」，而是当检查清单用。

  • 一轮：照着导图把每一节过一遍，边过边在图上打勾。
  • 二轮：只做「打不了勾的分支」—— 那就是你的薄弱考点。
  • 三轮：把导图默画一遍，画不出来的就是没记住。

复习节奏建议：

  • 每天 20 题：10 题按导图顺序做，10 题限时做。
  • 每道错题回到导图上，标出它属于哪个分支。
  • 一周后数一数：哪个分支的错最多，就专项补哪个。
  • 考前只做两件事：默画导图 + 背口诀。

为什么要用导图而不是题海：图推的考点是有限且封闭的，一共就那么几十个。把考点串成树，做题就变成「沿树找叶子」，而不是碰运气 —— 题海只增加熟练度，导图才增加命中率。

例题 · 二轮怎么用

题干：二轮复习时，用这张思维导图最有效的做法是？

A. 从第一页重新看一遍　B. 只做「打不了勾」的分支，那就是薄弱考点　C. 把导图背下来　D. 只看口诀部分
解析：一轮已经逐节过过一遍并打了勾，二轮再从头看一遍（A）效率很低。
正确做法是：只做那些「打不了勾」的分支 —— 打不了勾就说明这个考点你还不会，而已经会的地方再花时间是浪费，选 B。
导图的精髓就是把复习变成「定位薄弱点」，而不是重复劳动。
答案：B

有相同：位置·样式·标记；无相同：属性→数量→图形间关系。二轮用思维导图默写复盘

总览

全册思维导图：怎么用它查漏补缺？

▶

把全册串成两栏：左边是六条必修规律，右边是六块特殊题型。

  • 规律类（必修）：位置规律、样式规律、标记规律、属性规律、数量规律、图形间关系。
  • 特殊类：空间重构、三视图与截面、立体拼合、平面拼合 / 折纸、黑白块专项、考场策略。

用法：拿它当清单，逐个考点问自己「我会不会」。

  • 先看大分支（规律类 / 特殊类），确认没有整块遗漏。
  • 再逐条看最末端的小考点，说不出判定特征的就是漏洞。
  • 把漏洞记下来，回到对应章节的卡片重看一遍。
例题 · 怎么查漏补缺

题干：用全册思维导图查漏补缺，正确的做法是？

A. 从第一页看到最后一页　B. 逐条问自己「这个考点的判定特征是什么」，答不上来的就是漏洞　C. 只背大分支名称　D. 只看自己会的部分
解析：导图的价值在于逐个考点自测：看到「数量规律 → 笔画」，就问自己「看到什么特征该想笔画」（答：五角星、日字、田字、切圆、多端点）——答不上来就是漏洞。
A 只是「看过」，不等于「会」；C 只背大分支等于没查；D 会的地方不用再花时间。所以选 B。
答案：B

实战

万能破题顺序是什么？

▶

考场上按这个顺序走，不会乱：

  • 先看元素组成：图案像不像？
  • 相同 → 位置规律（平移 / 旋转翻转 / 相邻比较）。
  • 相似（部分一样） → 样式规律（遍历 / 加减同异 / 黑白运算）。
  • 都不同 → 先属性（对称 → 曲直 → 开闭），再数量（面 → 线 → 点 → 角 → 素 → 笔画），最后图形间关系。

三个补充策略：

  • 特征图优先：对称图 → 对称；线条交叉 → 点；窟窿多 → 面；五角星 / 日字 / 田字 → 笔画。
  • 简单规律不行 → 考虑复合考点（对称＋曲直、数量＋属性、位置＋样式）。
  • 空间重构用排除法，不要硬想。
例题 · 第一步看什么

题干：图形元素组成完全不同、彼此都不相似、摆放也很凌乱。第一步应该看？

A. 先数封闭面　B. 先看对称、曲直、开闭这些属性　C. 先数交点　D. 先判断一笔画
解析：元素完全不同、又都不相似 → 既不是位置规律，也不是样式规律。
接下来按顺序是先属性、后数量：属性（对称 → 曲直 → 开闭） 优先级更高，因为它们「一眼就能判断」；属性都对不上，才去数量（A、C、D 都在数量里）。所以选 B。
记住这条顺序：属性 ＞ 数量，能省很多时间。
答案：B
实战

四大高频易错点

▶

考前把这四条再过一遍，每一条都是「知道就会、不知道就丢分」：

  • ① 一笔画的奇点判定：端点也是奇点，别漏；奇点一定成对出现。
  • ② 对称轴的考法：数量 ＋ 方向 ＋ 是否与线条重合 / 垂直，三样都要看。
  • ③ 黑白叠加运算：规则现场推 —— 第一组推规则、第二组验证、第三组应用。
  • ④ 内外平移：内外层分开移动，别整体看。
例题 · 一笔画最容易错的地方

题干：数一笔画的奇点时，最容易漏掉的是什么？

A. 交叉点　B. 端点　C. 切点　D. 中点
解析：端点（只有一条线连着的、悬空的线头）也满足「引出的线条数是奇数」，所以也是奇点，但很多人只盯着交叉点看，就把端点漏了，选 B。
连带记住：奇点一定成对出现（0、2、4、6…）。如果数出来是奇数个，说明中间数错了，回头再数一遍。
答案：B
实战

时间管理：30 秒原则

▶

图推最容易亏分的地方不是「不会」，而是「在一道题上死磕」。

  • 30 秒原则：一道题 30 秒还没思路，立刻跳过，做完其他模块再回头看。
  • 遇到难题：先排除明显错的选项（比如出现了相对面），提升蒙对的概率。
  • 心态：图推没有玄学，只有规律 —— 规律用熟了，80% 以上的题都能拿下。
📌 考前提醒：熟记特征图 + 口诀，比刷更多题更重要。
例题 · 时间分配

题干：考场上做图推，一道题 40 秒还没思路，应该？

A. 继续死磕直到做出来　B. 先跳过，做完其他题目再回头看　C. 随便选一个马上走　D. 换一种方法从头再来
解析：图推的题量不小、单题分值有限，在一道题上死磕会连带影响后面的题。
正确做法是先跳过（B），把能拿的分先拿到手，最后再回头处理难题。
C 虽然快，但连「先排除明显错的选项」都没做，正确率会低很多；A、D 都是继续耗时间，不划算。
答案：B
