1. 一句话记住「3+3」
拿到一道图推，先问自己一句 —— 「图形像不像？」
· 像（有一样的图案）→ 看 位置 / 样式 / 标记（3 类）；
· 不像（没有一样的图案）→ 看 属性 / 数量 / 图形间位置（3 类）。
3 + 3 = 两条大道、六个路口、三十多个考点。
分支什么时候走往下看什么本页章节
位置规律图形完全一样，只是挪了地方平移 / 旋转 / 翻转（定方向 + 数步长）一
样式规律图形部分一样（线条、轮廓重合）加减同异 / 黑白运算二
标记图上有小黑点、箭头、特殊线条标记点 / 标记线 / 功能元素二
属性规律图形各不相同、风格统一对称性 / 曲直性 / 开闭性三
数量规律图形很乱、没规律可循面 → 线 → 点 → 笔画 → 元素 → 直角四 五
图形间位置图形不止一个，凑在一起相离 / 包含 / 相交（含相接的细分）三
空间类出现立体图、展开图、剖面六面体 / 四面体 / 三视图 / 截面 / 立体拼合六 七 八
特殊题型不规则轮廓、拼合、折纸公共边排除 / 找特殊 / 平移拼合九
2. 复习路线（按这个顺序学）
  • 第 1 步 · 打底：先学位置与样式—— 这两类最直观、最容易上手，也是「像」分支的全部。
  • 第 2 步 · 主力：数量（面 / 线 / 点）是图推考得最多的一块，必须刷透；接着补笔画、元素、直角。
  • 第 3 步 · 属性兜底：属性规律看着简单，但它是「想不出规律时」的第一落点。
  • 第 4 步 · 立体：六面体 + 四面体是国省考常客（每年必考），三视图、立体拼合次之。
  • 第 5 步 · 查漏：不规则 / 平面拼合 / 折纸 属特殊题型，考前过一遍即可。
  • 收尾：用思维导图串讲把整个体系串起来，考前只看这一页复盘。

一、位置规律 + 相邻比较
第一组 · 图形「像」 ▼
1. 了解“出题形式”——不同形式，不同的观察角度

拿到一道图推题，先别急着找规律，要先看题干是怎么出的。不同的出题形式，有不同的观察角度，也藏着出题者不同的偏好。

  • 一组图：一串图形从头看到尾。出题者喜好是"各图有共同的特点"，规律多和数量有关——恒定、等差、周期。
  • 两组图：左边一组、右边一组，左右可以分开看。第一组给出规律，第二组照搬推问号；同样是"共同的特点 + 数量有关（恒定、等差、运算）"。
  • 九宫格：每排或每列可以分开看。九宫格最喜欢考"运算"（一排三个，第三个由前两个算出来）。
  • 分组分类：把六个图形分成两类，每类图形都有各自的共同特征或规律。出题者喜好——①两种规律（优先考虑，例如①③④各有某特征、②⑤⑥各有另一特征）；②有规律和没规律（这是新趋势，属性规律出现得多）。
  • 空间类：立体拼合，以及四面体、多面体、三视图、截面图、平面拼合等。

数量中的数字规律也要先过一遍，因为图形里的"数量"本质就是这几种数列：

  • 恒定：1、1、1、1、1 —— 最常见，优先看。
  • 等差：1、2、3、4、5（递增）；1、2、3 / 1、2、3 / 1、2、? —— 优先。
  • 周期：1、2、1、2、1 —— 其次。
  • 运算：1、5、6（1+5=6）；5、1、6 / 2、3、5 / 3、1、? —— 出现较少，但九宫格里"运算"很爱考，且经常是"难"的那一档。
数量规律的优先级：等差 > 恒定 > 周期 > 运算。
但九宫格是例外——九宫格最喜欢考"运算"。
出题者喜好速记：
① 平移、相邻比较不出"分组分类"；
② 样式规律以"两组图""九宫格"为主；
③ 九宫格喜欢"运算"；
④ 九宫格的观察方向：横向为主，纵向难，交叉（斜着看）较少出现。
出题形式四类：一组图 / 两组图 / 九宫格 / 分组分类（另加空间类）
2. 了解“作图特点”——作图特点决定大方向（3+2 体系）

这一节的核心是刘义恒老师"图推 3+2"体系的判断口径：先看图与图之间有没有"一样的图案"，这一步决定往哪个方向找规律。

  • 有一样的图案（3 类）
    • 完全一样 → 考位置：平移、旋转/翻转；位置里再细分出"相邻比较"。
    • 部分一样 → 考样式（运算）：黑白运算、加减同异。
    • 标记。
  • 没有一样的图案（3 类）
    • 属性：对称性、曲直性、开闭性。
    • 数量：面（所有/大小/相同，一般看内部）；笔画；点（曲直交点、切点、端点）；线（曲直、横竖、框、平行线、贪吃蛇）；元素；直角。
    • 图形间位置。
口诀：有相同 → 位置 / 样式 / 标记；无相同 → 属性 / 数量 / 图形间位置。
位置规律内部还有一层"看图特点"，务必分清：
· 图案都在动 → 平移、旋转翻转；
· 有图案不动 → 相邻比较（这是本讲的第三个考点）。
3. 考点一：平移（基础）

命题者的作图特点：每幅图的图案完全相同。一组黑点、一组小方块反复出现，只是位置在变。要特别注意一个"特殊情况"：

图案在移动的过程中，一旦发生重合，图案的数量就会减少（少了不是消失了，是被盖住了）。所以"数量对不上"恰恰是平移的一个信号。

平移看两个要素：

  • 1. 方向：① 直线——上、下、左、右、斜对角线；② 绕圈——顺时针 / 逆时针。
  • 2. 步数：恒定（高频）、递增。

【出题形式】除了"分组分类"以外，一组图、两组图、九宫格都可以出。

出题者的"小心思"就是加密：把同一道题换成九宫格黑点、16 宫格、蜂窝、内外圆环……本质都是"图案在动"。破解靠"解密"：

  • 拆分思维：先把图拆成几个部分（内部 / 外部、这个图案 / 那个图案），分开看。
  • 就近假设：判断某个图案上一步在哪，优先假设"离它最近的那个位置"——因为出题者不会让它一步跳很远。
平移三问：谁在动？往哪走（直线 / 绕圈）？走几步（恒定 / 递增）？

易错提醒："内外分开看"是 16 宫格和蜂窝类的"第一反应"。内部那 2×2 一般是绕圈走（顺/逆时针），外部那一圈也是绕圈走，但内外方向可以相反；判断方向时用"就近原则"，别把内部的顺时针当成外部的顺时针。
小结：16 宫格的标准流程是——① 先看内部 2×2；② 有规律就内外分开；③ 内部没规律再按常规平移（直线、斜线，方向可变）。
4. 平移（拔高）：内外分开看 · 定方向 · 走到头 · 隐藏线条

确定是"平移"之后，不要急着数步数。按下面的顺序走，效率最高：

  • 第一步：先观察内部是否有规律。
  • 内部有规律 → 考虑"内外分开看"。运动方向：绕圈（顺 / 逆时针）。' '典型结构是 16 宫格——内部 4 格自己绕圈、外部 12 格自己绕圈；蜂窝类同理（把蜂窝看成"内部 + 外圈"）。
  • 内部无规律 → 考虑常规平移。运动方向：直线（上下、左右、斜对角线），' '而且方向是可变的——不必一直朝一个方向走。
"定方向"两大技巧：
① 找特殊图案（大区域）——那块面积最大、最显眼的黑块，通常就是突破口，盯住它看它怎么走；
② 数个数——如果横向每行的黑块数量相同，说明是横向运动；如果纵向每列的黑块数量相同，说明是纵向运动。
"走到头"了怎么办？出题者只有两种出法：
① 循环走——从头开始，回到起点；
② 反弹走——撞到头直接弹回来。
隐藏图形 / 隐藏线条：线条类题目要留意图里"藏"着的高频图形（三角形、正方形、菱形、六边形、箭头……）' '以及特殊线条——尤其是"虚线"，它往往就是出题者埋的那个"特殊图案"。
定方向：特殊图案（大区域）+ 数个数；走到头：循环走 / 反弹走

拔高题的特征是：图形更密、动的东西更多，这时候"套路"比"眼力"更重要。

  • 16 宫格（4×4）：先看中间 2×2 那四格有没有规律。有，就内外分开各自绕圈；没有，就按常规平移看。
  • 蜂窝类：蜂窝可以看成"内部 + 外圈"两层；先看内部的几个点，再看外圈怎么转。
  • 大面积图案 / 特殊图案：一堆黑块里，那个连成"大区域"的往往是最好追的目标。
  • 斜着运动：五宫格、更密的格子里，黑块经常是斜着走的（方向可变）。
  • 隐藏线条：图形里藏着虚线、长线等特殊线条，或者藏着高频图形（三角形、正方形、菱形、六边形）。
答题心态：拔高题不要一上来就"数格子"。先找那块最大的黑块——它的移动方向往往最容易被看清；然后用"就近假设"把其余黑块对上号。

5. 考点二：旋转、翻转

位置规律的第二个考点。命题者作图特点同样是"每幅图图案相同"，但图案不是平移，而是"转"或"翻"。

  • 1. 旋转
    • 方向：顺时针、逆时针。
    • 角度（步数）：30°、45°、60°、90°、180° 等常见角度。
  • 2. 翻转
    • 左右翻转：图形沿竖轴对称。
    • 上下翻转：图形沿横轴对称。

怎么区分"旋转"和"翻转"？只看一件事：变的是什么方向。

· 左右翻转：只变左右（上下不动）；
· 上下翻转：只变上下（左右不动）；
· 180° 旋转：上、下、左、右都变——口诀"怎么变，怎么翻，全变就是 180°"。
  • 技巧①特殊图案（大区域）：先盯住最大、最特殊的那一块，看它是转还是翻。
  • 技巧②时针法：注意"三个同一"——同一起点、同一路径、同一终点。三点连成一条闭环，' '看它是顺时针还是逆时针，翻转一定会改变时针方向。
  • 技巧③箭头法：找图中唯一的、有指向性的图案来定方向。常见指向性较强的图形：' 'A、T、↑、△、▲、梯形。
当四个图案都在动、看不出谁不动时：别硬推，直接"对比选项"——' '用选项之间的差别反推规律，往往比从头推更快。
只变左右 = 左右翻转；只变上下 = 上下翻转；全变 = 180° 旋转

6. 考点三：相邻比较

相邻比较是位置规律里"另一种作图特点"，也是近几年的高频考法。先把两种作图特点摆在一起对比：

  • 位置规律（平移、旋转翻转）的作图特点：图案都在动。
  • 相邻比较的作图特点：① 有黑块（图案）不动；② 平移没规律。

所以，当你发现"图与图长得很像"，可数步数又怎么都对不上时，就该换思路了——比较相邻两幅图，先找出"不动的图案"。

实战思维（完整版）：
平移 → （内部有规律）内外分开看 /（内部无规律）常规平移（上下左右、斜着运动，方向可变）→ 技巧：特殊图案、数个数；
如果有黑块不动或者平移没规律 → 走相邻比较。
"有图案不动（很像）"最常见的四种：黑块-相邻比较、矩形-相邻比较、' '小球-相邻比较、线条-相邻比较。
做题顺序建议：先看不动的 → 再看"不动的图案之间的间隔" → 最后看"动的图案往哪走"。
特别提醒：相邻比较题里"可以没有规律"——只要能把不动的找出来，剩下的部分哪怕看起来"没规律"也不影响做题。
相邻比较：先找"不动的" → 再看"动的"（相邻两图对比，而不是从头推）

② 特殊情况：图案移动过程，在重合情况下，图案数量会减少。
③ 考点：1. 平移　2. 旋转、翻转

① 确定"平移"后，第一步先观察内部是否有规律。
② 内部有规律，考虑内外分开看；运动方向：绕圈（顺/逆时针）。

　（二）"走到头"后：1. 循环走　2. 反弹走
④ 运动步数：恒定、递增为主。
【旋转、翻转】
① 旋转：1. 方向：顺时针、逆时针；2. 角度：30°、45°、60°、90°、180° 等常见角度。
② 翻转：1. 左右翻转：图形沿竖轴对称；2. 上下翻转：图形沿横轴对称。
③ 技巧：1. 特殊图案（大区域）　2. 时针法、箭头法

位置规律两步走：先看"图案是否完全一样"，再看"都在动"还是"有不动"
整讲最容易失分的地方：
① 忘了"重合会减少数量"，一发现数量对不上就以为不是平移；

③ 旋转、翻转分不清，不知道该看"左右变"还是"上下变"；

1. 样式规律（运算）总览：先判断"有没有一样的图案"

样式规律属于"图形有一样的地方"时优先考虑的规律。它的命题者作图特点非常鲜明：每幅图的图案部分一样——要么线条长得像、位置对应，要么都是一些小黑块重复出现。凡是遇到"几幅图长得像一家人"的题，思路就要立刻切到"样式运算"上来。

  • 考点①　加减同异：出题者作图以线条居多，图案部分一样且位置对应。
  • 考点②　黑白运算：出题者作图以黑块居多，图形轮廓和分割区域相同，但黑块个数不同。
加减同异 4 式：①相加　②相减/求异（去掉相同线条）　③求同（保留相同线条）　④求异（相同删除，再重组）

把两个图形看成两个"集合"，四则运算就是它们之间的四种关系（下图即讲义板书示意，绿色线条代表"相同线条"）：

判定口诀：图案部分一样 + 位置对应 → 想"加减同异"；图案一样、轮廓相同但黑块个数变了 → 想"黑白运算"。
2. 加减同异 · 基础：相加 / 求同 / 求异

命题者作图特点：图案部分一样（线条居多），且位置对应。

  • 相加：两图线条全部叠上去（又叫"叠加"）。
  • 相减 / 求异：去掉相同线条，保留不同线条。区别在于"是否重新组合"——求异要把剩下的线条重新拼回一个完整图形。
  • 求同：只保留两幅图相同的线条。
答题思路：优先看"前两幅图 − 相同部分"。求异是高频考点；出题形式：两组图、九宫格；九宫格中若横向走不通，立刻换纵向（去同存异）。
求异/相减的"特殊情况"：两图毫无相同线条时，求异的结果＝两图直接叠加。

4. 黑白运算：先看"轮廓是否相同"

命题者作图特点：相同的黑块重复出现；图形轮廓和分割区域相同，但每幅图里黑块的个数不同。

解题思路：相同位置的运算
  • 把每幅图切成同样的小格，逐格做"黑+黑""白+白""黑+白""白+黑"的规则推演。
  • 运算法则要具体题目具体找，不能背固定公式。
  • 黑+白 不一定等于 白+黑，必须逐题验证（黑、白谁在前，结果可能不同）。

基本原理示意：同样四格，两图逐格相加，结果每一格的颜色由"该格两图的颜色组合"决定：

黑白运算的"提速技巧"
  • 技巧1　对比选项找差异：四个选项长得几乎一样，只在个别格子不同。先找出选项之间"不一样的那一格"，再回到题干推这一格，往往一步出答案。
  • 技巧2　相同区域一起看：把两幅图里"颜色相同的区域"拉出来一起观察，能迅速定位需要推演的格子。
如何区分"黑白运算"与"加减同异"？两者的运算逻辑其实很相似（都是"相同位置的运算"），有时不必刻意区分。经验上：黑白运算画"黑块"居多，加减同异画"线条"居多。遇到"图案部分一样但线条/黑块说不清"的题，直接按"相同位置运算"往下推即可。
出题形式：两组图、九宫格；九宫格横向不通就换纵向（纵向规律）
创新点提醒：黑白运算近年常"换皮"出现——外框创新（不成方格的轮廓）、颜色创新（灰/斜线/网格等多种填充色）、题型创新（把两组图换成金字塔式"A+B=C"，结果越往上越"少"）。解题时先固定"轮廓与分割区域相同"这一前提，再逐格比对。
5. 标记（一）：命题特征、标记位置与标记图形

命题者作图特点：每幅图里都有"一样的小元素"——黑点、白点、箭头或其他小图案，每幅都有。此时优先考虑它的"标记作用"。

  • 考查方式①　标记位置：上、下、左、右、内、外。
  • 考查方式②　标记图形：即这个标记物"标记"的是图形上的什么对象。
标记图形要看的四类对象（考点清单）
  • 点：曲直性、引发的线条数量。
  • 线：直线/曲线、最长线/最短线、线的位置（首尾、中间）。
  • 角：直角/锐角/钝角、最大角/最小角。
  • 面：单独面/相交面、相同区域/不同区域、形状、属性、面积。

  • 连线经过交点 / 顶点，或把图形分成相同的部分。

8. 全讲速记（样式规律＋标记）
【样式规律】（运算）
  • 命题者作图特点：每幅图图案部分一样。
  • 考点：①加减同异　②黑白运算。
【加减同异】
  • 命题者作图特点：图案部分一样，且位置对应。
  • 考点：1.相加；2.相减/求异（去掉相同线条）；3.求同（保留相同线条）。
  • 答题思路：确定"加减同异"后，第一步先看图1、图2是否有相同线条。
    ① 有相同先运算，再考虑图3转的可能；
    ② 无相同先旋转，跟图3对比：图2与图3有相同线条→图1转；图1与图3有相同线条→图2转。
【黑白运算】
  • 命题者作图特点：图形轮廓和分割区域相同，且黑块数量不同。
  • 答题思路：相同位置的运算。
  • 小技巧：1.相同区域；2.对比选项。
【标记作用】
  • 命题者作图特点：每幅图图案部分一样，例如都有黑点、白点、箭头等小图案进行标记。
  • 考点：1.标记位置（常见：上、下、左、右、内、外）；2.标记图形——
    　点：曲直性、引发的线条数量；
    　线：直线/曲线、最长线/最短线、线的位置；
    　角：直角/锐角/钝角、最大角/最小角；
    　面：单独面/相交面、相同区域/不同区域、形状、属性、面积。
  • 多个标记：1.标记物之间的比较；2.连线后与原图的关系。
实战思维：加减同异 → 先看图1图2相同线条 → 有相同（先运算，可能图3动）／无相同（先旋转：13一样→图2动，23一样→图1动）
一句话总结：图案有一样的部分，就往"运算"里想——线条动脑（加减同异），黑块动眼（黑白运算）；图里有小标记，就问自己"它在标什么、连起来又与原图什么关系"。

三、属性规律 + 图形关系
第二组 · 图形「不像」 ▼
1. 属性规律怎么考：命题者的"作图特点"决定大方向

图推的题面只有两种：有一样的图案和没有一样的图案。老师给的"3+3"框架把考点一次锁死——

刘义恒图推"3+3"框架

  • 有一样的图案（3类）：【1】位置（平移、旋转/翻转 → 相邻比较）；【2】样式（运算：黑白运算、加减同异）；【3】标记。
  • 没有一样的图案（3类）：【1】属性（对称性、曲直性、开闭性）；【2】数量（面、笔画、点、线、角、元素）；【3】图形间位置。

命题者作图特点：每幅图图案都不一样 → 当题干里每一幅图都换了"花样"，先别急着数，先看属性。

宏观思维（做题顺序）：
  • ① 先属性，后数量，且属性规律中的对称性优先级最高；
  • ② 背诵数量规律中图形特征，用它直接定位（例如大量散点→点、封闭区域→面）；
  • ③ 极端情况，优先考虑"图形关系"（图特别简单或特别复杂时）。

属性规律只有三兄弟，各有各的"长相"（看到什么，就往哪儿想）：

对称性 → 图形很"规则""美观"　|　曲直性 → 图形里出现曲线（1/2、2/3）　|　开闭性 → 图形很"生活化"

下面依次展开：对称性（基础 → 细化 → 拔高）、曲直性、开闭性，最后是图形间关系。

2. 对称性·基础：先"识别"，再"细化"

看到题干图形很规则、很美观（车辆车标、几何图形），第一反应就是对称性。解题口诀只有一句：

规则、美观 —— 对称性 —— 先识别 —— 后细化

先识别（区分对称类型）：轴对称 / 中心对称 / 轴对称+中心对称。

  • 轴对称——"等腰"元素出现（能画出对称轴）：三角形、等腰梯形、心形、笑脸、月亮脸……
  • 中心对称——平行四边形、N、Z、S 变形、相同图形反着放（旋转 180° 与自身重合）。
  • 轴对称 + 中心对称——存在两条相互垂直的对称轴：如圆内十字、圆内斜线交叉、正六边形、长方形（十字对称）。
破解出题者"小心思"：题干给你一个漂亮的"对称外框"（三角形、六边形）把人骗住，真正的答案要看内部填充的图形——所以判对称，一定要连内部一起看。

3. 对称性·细化：一条轴看方向，多条轴看数量，都没答案看"关系"

"识别"出是轴对称以后，出题者还会继续往下考，这就是对称轴的细化考法：

  • 1 条对称轴 → 优先看对称轴方向（横、竖、斜，以及 45° 的旋转规律）。
  • 多条对称轴 → 优先看对称轴数量（1、2、3、4……递增或递减）。
  • 方向和数量都没答案 → 看对称轴与原图形①线②面③点的关系（轴是否与某条线重合、是否平分某个面、是否经过某个点）。
多个规则图形要"拆分"看：
  • 2~3 个规则图形"挨着" → 考虑拆分，看对称轴之间的位置关系：平行、垂直、相交；
  • 2 个规则图形"内、外" → 考虑拆分，看内外两层分别是什么属性（识别），甚至做运算。
规则、美观 —— 对称性 —— 先识别 —— 后细化 —— 1条轴看方向｜多条轴看数量｜都没答案看与原图形（线/面/点）的关系

  • 1. 相离：两个图形互不接触；
  • 2. 包含：一个图形完全在另一个图形内部（如圆内套三角形）；

常见考查方式：

  • ① 区分"交点"和"切点"，以及连接处的曲直性；
  • ② 相交于线时：数数量；看特点——最长/最短、整体/局部、曲线/直线、线的位置（横/竖/斜）；
  • ③ 相交于面时：看形状（自身、外框）、属性（对称、曲直）、面积（是否为整体的 1/2）。

1. 数量规律总纲：图案不同 → 先属性，后数量

本节的命题者作图特点是“每幅图图案不同”。看到一组图案各不相同的图形，方向就只有三条：属性 → 数量 → 图形关系。刘义恒老师的宏观思维是：

  • 先属性，后数量，而属性规律中对称性优先级最高；
  • 背诵数量规律中的“图形特征”，看到特征直接定位考点；
  • 遇到极端情况（如六幅图分两类、图形关系明显），优先考虑“图形关系”。
属性三条线：对称性（图形规则）→ 曲直性（有曲线）→ 开闭性（生活化）。属性没规律，立刻转数量。

数量规律的六大考点依次是：①面 ②线 ③点 ④笔画 ⑤元素 ⑥角。本节解决前三个：面、线、点。

图形特征优先级：线特征 > 面特征 > 点特征

什么是“面”？——白色的、封闭的区域。

⚠️ 提示：黑色不是面。全黑块、粗实心图形里面的黑色区域，一律不算面。
易错提醒：属性里的对称性优先级最高，很多同学一看到“图形被分割”就冲去数面，结果丢了对称分。记住顺序：先属性，后数量。
2. 考点一 · 面数量：基础考法（面的数量、九宫格面的运算）

命题者作图特点（看到这些特征，直接锁定“面”）：

  • ① 图形被分割（外框被内部线条切成多块）；
  • ② 封闭面明显（一块一块的封闭区域很扎眼）；
  • ③ 生活化（图标、汉字、字母、数字）。

解题路径：图案不同 → 属性 → 数量 → 面。基础考点只有两个：面的数量 与 面的运算。

生活化图形 → 优先数面；
生活化（汉字、字母、数字）→ 优先数面（数封闭区域，不是笔画数！）；
九宫格 → 优先想“面运算”。
九宫格运算思维：① 两数相加得第三个数（2+3=5）　② 三数之和为定值（2+3+5=10 或 每行/列/对角线和相等）
“面的数量”是数量规律里最基础、出场率最高的一个考点。数面时一条铁律：闭合区域要封口才算一个面，虚线、开口区域、黑色块都不算。

7. 考点二 · 线数量：直线、曲线与线的运算

什么是直线？直线是由无数个点构成、向两端无限延长的线。什么是曲线？曲线是动点运动时，方向连续变化所成的线。

怎么数线？看是否有明显的拐点（方向是否变化）。一条线从拐点处断开就应分成两条线；“一条直线被折一下”就变成两条。
  • 命题者作图特点：① 单一线条　② 都有曲线　③ 多边形（外框）；
  • 解题思路：图案不同 → 属性（对称、曲直、开闭）→ 数量 → 线；
  • 基础考点：线的数量、线的运算（相减、倍数、相加）。
图形特征：线特征 > 面特征

“线的运算”主要从这几组特征里做文章：曲线 / 直线、横线 / 竖线、外框 / 外框；命题者还会用曲直、内外、横竖、黑白、外框来作图。

实战思维：看到“单一线条、都有曲线、多边形外框”，背诵后直接定位“线数量”。特别是图形里有明显外框（多边形轮廓）时，马上想“外框与内部线条的运算”。

1. 数量规律总纲：先看属性，再数数量

刘义恒「图推命题思维」第五节讲数量规律，本节落到三个高频考点：笔画、元素、直角（考点体系：①面 ②线 ③点 ④笔画 ⑤元素 ⑥角）。

  • 命题者作图特点：每幅图图案不同。图案不一样，说明它在"换样子"，这时优先想属性。
  • 解题思路：每幅图图案不同 → 先看属性（对称性（规则）、曲直性（曲线））→ 属性无规律再转数量（线条数量、笔画、元素、直角）。
  • 宏观思维：①先属性、后数量，且属性规律中的对称性优先最高；②背诵数量规律中图形特征，直接定位；③极端情况，优先考虑"图形关系"。
  • 什么是"笔画"？在不能重复的情况下，能够一笔画成（提示："点"可以重复"走"）。
图推不是"越多越好"，一定要学会"减法""区分"。数量规律的第一步不是数，而是判断"这道题该数什么"——图案不同看属性，属性无解才回数量。
基础考点：识别一笔画、两笔画、三笔画。老版本靠"日、田、五角星、圆相交"认脸；新趋势靠"多端点、面特征、生活化"认脸。
2. 奇点数：一笔画与多笔画的判定

判断笔画只认两件事：连通和奇点。这是本节最核心的口诀。

  • （1）线条之间连通——图形必须是连在一起的一整块（不连通时要分开算）。
  • （2）奇点数为 0 或 2——奇点数为 0 或 2 个时，才能一笔画成。
  • 什么是奇点？以一个点为中心，发射出奇数条线，这个点就是奇点。
  • 端点也是奇点，不要忘记数！凡是"线头"（只连 1 条线的点）都是奇点。
  • 多笔画：笔画数 = 奇点数 ÷ 2（奇点数一定是偶数，不可能是奇数）。
  • 不连在一起的，记得相加——分成几块就连几笔相加。
笔画数 = 奇点数 ÷ 2
经典例图记忆（理论速记·笔画）：
① 笔画概念：在不能重复的情况下，能够一笔画成；
② "一笔画"需要同时满足两个条件：1. 线条之间全部连通；2. 奇点数为 0 或 2 个；
③ 多笔画：连通图笔画数 = 奇点数 ÷ 2（任何图形的奇点总数一定是偶数）；
④ 命题者作图特点——旧版本：五角星、日、田、圆相交；新版本：多端点、面、生活化。
口算示范："日"字——上下两条横线把竖直边框分成 4 段，中间横线与左右竖边相交处各为 3 度（奇点），共 2 个奇点 → 一笔画；"田"字——4 条边的中点都是 3 度 → 4 个奇点 → 两笔画；五角星外轮廓（不加内线）0 个奇点 → 一笔画。

3. 笔画的"小心思"与"去外框法"

笔画题看着复杂，是因为出题人给图形加了个"外框"。加外框不改变笔画数，只让图形变复杂——这就是"小心思"。

  • 旧版本质特征：五角星、日、田、圆相交——看到这些"脸熟"的图形，先想笔画。
  • 最新趋势：多端点、面特征、生活化（生活化图形难度升级，会考 2 笔画 / 3 笔画）。
  • "加外框"陷阱："外框"不影响笔画数，却让图形复杂。
  • "解密"办法：可以尝试"去外框"看。
去外框法（理论速记·新增）：
① 外框：从一个点出发，回到原点，路径不唯一；
② 优先去最外面的框，再去剩下的，更清晰；
③ 去完后没有图案，还是一笔画；

4. 元素：种类与数量

7. 部分数与"黑白块"分堆

  • 怎么数部分数？边与边相连算一部分，角与角相连（只顶点相接）算两部分。
  • 为什么数部分数？生活化图形（黑脚印、太极图……）；提示：部分数数"黑色"，面数数"白色"。

① 命题者作图特点：分堆且堆数较少；
② 怎么数部分数：边与边相连算一部分，角与角相连算两部分；
③ 考点：=2 堆 → 每堆个数的变化；>2 堆 → 黑色部分数、白色部分数、黑色与白色的运算；
④ 部分数没有规律，考虑黑球个数。

第三组 · 立体图形 ▼
1. 六面体总览：先记住「答题思路三步」

六面体（正方体纸盒）问题，本质是「把展开图折起来，再和选项对照」。老师开篇就强调两条底层原则：

  • 如果靠想象力：注意折叠方向（相对位置易搞反）。
  • 如果靠技巧：所有的方法都是排除错误选项用的——单一技巧都有缺点。
  • 技巧不是越多越好，而是越熟悉越好、适用范围越大越好。

答题思路（三步）

第一步：观察题干与选项，出现「相对面」直接排除；

第二步：有「唯一边或点」，优先用「箭头法」解题（备选「画边法」）；

第三步：没有「唯一边或点」时——（1）2 个面近、1 个面远，优先用「公共边」；（2）3 个面近，优先用「公共点」。

讲义中的技巧排序（含适用边界）：相对面 → 箭头法 → 公共边 → 公共点 → 画边法 → 「1-4-1」变形（2-3-1 / 3-3 / 2-2）。「相邻比较」贯穿始终；立体的「外部轮廓」只用于定方向，判断仍要靠相邻关系。
2. 相对面：最快的一招，也是最容易漏的一招

什么是相对面？折叠成正方体后面对面（不能同时被看见）的两个面，出现即排除。

基础模型：「1-4-1」展开图。中间一行 4 个面绕一圈围成侧面，上、下各 1 个面分别是「上面」和「下面」。

1-4-1 展开图：同列相隔一个面 → 相对面

「相对面」快速记忆（讲义原话）：

  • ① 同行或同列相隔一个面——是相对面；
  • ② 「Z 字形」两端（紧邻 Z 字中线的面）——是相对面。
  • 速记：中间隔 1 个，或隔 1 列，都是相对面。
真实测评：优点——很快、不用动脑；缺点——实战出现少，只能排除个别选项（所以只能当第一步）。

3. 箭头法：找唯一，定方向
口诀：找唯一，定方向
  • ① 结合选项，找一个唯一点或唯一边；
  • ② 以唯一点或唯一边作为参照物，画出箭头方向。

怎么找「唯一」？（都是针对选项里的面去找）

  • 唯一点：某个面上有独一无二的点/角（如黑三角的尖、直角交点）；
  • 唯一边：某个面上有独一无二的边（如唯一的斜边）；
  • 理解升级：公共边 → 唯一边；两个面各自都有图案时可用「双箭头」（同时画两个箭头，一次锁定两个面）。
  • 可以转动讲义（试卷），让箭头正上方，更好对比；
  • 思维：优先看直接靠在一起的面（好画、好看）；
  • 思维：位置居中的面优先——周边更好看、难度更低。

真实测评：优点——上下左右大致方位，区分很快；缺点 1——图案都在右边时容易忽略细节（用「双箭头」解决）；缺点 2——没有直接靠着时需要移动（用「公共边」解决）。

4. 公共边：两个面共用同一条边

什么是公共边？公共边是两个图形共同拥有的边。

口诀：构成直角的两条边是同一个边 / 一列（行）连着 4 个面，两端是同一条边 / 「直角边」随便「滚」

「公共边」快速记忆：

  • ① 构成直角的两条边——折起后是同一条边；
  • ② 一列/一行连着 4 个面的两端——是同一条边；
  • ③ 「直角边」随便「滚」（1-4-1 里，直角处的边可以沿圈滚动着找）。
真实测评：优点——公共边周边图案，区分很快；缺点——两边的图案一样时，左右容易混淆（搭配箭头法可以解决）。
因此得出结论：箭头法（主）+ 公共边（辅），五星推荐。

7. 画边法 与「1-4-1」变形（2-3-1 / 3-3 / 2-2）

什么是画边法？（专治方向问题）

  • ① 结合选项，找一个唯一点或唯一边；
  • ② 顺时针方向描边标号（描同一个面）；
  • ③ 题干与选项对应面不一致 → 排除。
注意：必须是同一个面、同一个点（或同一条边）、同一方向。
真实测评：优点——能解决方向问题、细节问题（既可以看点，也可以看边）；缺点——① 速度偏慢；② 左右细节问题需要关注。

「1-4-1」变形怎么办？先把变形图「滚」回 1-4-1 再判断。四种基础模型：

1-4-1 ｜ 2-3-1 ｜ 3-3 ｜ 2-2
  • 2-3-1 模型：上排 2 格、中排 3 格、下排 1 格，逐排错位（由 1-4-1「平移 1 格」变形而来）；
  • 3-3 模型：两排各 3 格，错开 2 格（只共用 1 列）；
  • 2-2 模型：2 格 + 2 格（+2 格）阶梯状，一格一格往上爬；
  • 变形图判断的核心仍是：相对面（同行/同列隔一个、Z 字两端）+ 公共边（直角边、一列四面的两端）。

8. 四面体：只有 4 个面，比六面体更好「一眼看穿」

答题思路（两步）

第一步：有「唯一边或点」，优先用「箭头法」解题（备选「画边法」）；

第二步：没有「唯一边或点」，优先用「公共边」。

  • 箭头法（口诀：找唯一，定方向）：① 结合选项找唯一点/唯一边；② 以它作参照物画箭头。
  • 左右混淆怎么办？——四面体最容易出「左右镜像」陷阱，用箭头法/画边法就能区分（画边法：① 找唯一点或唯一边；② 顺时针描边标号（描同一个面）；③ 对应面不一致 → 排除）。

七、三视图 + 截面
第三组 · 立体图形 ▼
1. 三视图是什么：三个观察方向 + 四个难点

三视图指的是从三个固定方向观察同一个立体图形所得到的平面图形：

  • 主视图：从正面看
  • 俯视图：从头顶向下看
  • 左视图：从左侧看

记牢四个「难点」，它们是所有三视图题的坑：

  • （1）观察到的三视图都是平面图（"立体感"要自己脑补）；
  • （2）原图有线，选项不一定有线；原图没线，选项一定没线——前者是"同一平面压平"，后者是"无中生有"；
  • （3）当被遮挡住时，看不见被遮挡部分（视图=你看得见的轮廓与棱）；
  • （4）曲面会变成直线（圆柱、圆锥的母线在视图里是直线）。
答题思路：外部轮廓定方向，内部线条定选项（轮廓定"从哪看"，线条定"选哪个"）。
易混：三视图 vs 视图？"视图"任意角度都可以看（含仰视、右视、斜看）；"三视图"只指正、俯、左三个固定方向。
2. 出题者的"小心思"：线条画不画 & 空间还是平面

小心思一：该不该有线？三视图题真正的分水岭不在外轮廓，而在内部那几条线。老师给的判定流程：

口诀：原图无线 → 一定不画；原图有线 → 压平到同一平面就不画，不同平面才要画。

小心思二：这题考的是"空间"还是"平面"？同一个九宫格，可以是空间题（三视图），也可以是平面题（面数量）。区分办法：

  • 考查平面：每个图案是独立的"平面图形"，图案之间的关联度低（如【2023上海】全部—面数量）；
  • 考查空间：图案之间是同一立体的不同观察结果，关联度高（如【2025联考】三视图）。
反过来用：看到"圆、方、梯形"混在一个九宫格里，先问自己——它们像不像同一个东西的三个视角？像 → 空间（三视图）；不像 → 平面（面数量）。
3. 正方体截面形状大全（15 种）
切割原则（先记这 3 条，不然全会想歪）：①一刀切；②刀无限大；③不能拐弯——截面一定是"一个平面"与立体表面的交线围成的图形。解密思路：复杂立体 → 拆成常见立体图形。

正方体（六面体）能切出的全部形状，考试就这 15 种，必须一眼认出：

由此可以直接背出三个高频结论：

  • Q1：能否切出"直角三角形"？→ 不能。（连等腰直角三角形、钝角三角形也切不出）
  • Q2：斜切能切出"正方形"？→ 能。
  • Q3：六面体最多能切出"几边形"？→ 6。规律：经过几个面，就切几边形（正方体只有 6 个面）。
数截面边数的通用办法：数与切面相交的面（平面）有几个，就是几边形——这也是后面"挖孔类截面"的判题主线。
4. 曲面立体的截面：圆柱 / 圆锥 / 圆台

曲面体的截面规律只有一条主线：看切面与"轴"的关系——横切出圆、斜切出椭圆、切到底面就是"曲线+直线"、过轴切出三角形/矩形/梯形。

  • Q1：完整图形能否切出"半圆"？考试多数情况给的都是"半椭圆"，别硬当正圆；
  • Q2：圆柱能否切出"梯形"？不能（圆柱侧面是直母线，只能切出矩形/鼓形）；
  • Q3：切"圆形和椭圆"的区别在哪里？就是横切和斜切的区别。
"能不能出圆/椭圆"，只看切面是平行于底面（圆）还是斜着切（椭圆）。

圆柱想切出"半圆"，必须同时满足：

  • ① 确定圆柱底面的圆心和半径长度；
  • ② 以直径为半圆的一切；
  • ③ 在侧面上找到一点，确保该点到圆心最短距离为底面半径的长度；
  • ④ 从该点出发，裁至（垂直切到）地面直径所在直线处。
结论：圆柱的高必须等于底面圆的直径，才能截出一个完整的半圆；考试多数情况考的其实是"半椭圆"。
"极端情况"不考：切面无限接近外表面（比如贴着底面去切一个正圆）这种极限操作，选项里一般不算"能截出"。
5. 三视图精讲：先定方向，再定选项（例题 1~5）
本块统一答题思路：外部轮廓定方向，内部线条定选项；外部轮廓拿不准时——外部轮廓：找特殊（找最有特征的那一块、那一个角）。

8. 截面拔高：三点确定一个面（例题 14~15）+ 小结

考试新趋势：三点确定一个面——题干给出三个顶点，问切面（或截面）是哪个。解密口诀：

  • 连接两点，再通过第三点画平行线（如"连接 ab，再通过 c 画 ab 的平行线"/"连接 PQ，再通过 R 画 PQ 的平行线"）；
  • 切面在立体表面走，凡是从同一方向切过去的边，在切面上是一组平行边；
  • 数每一排的个数、看每一排的颜色（若方块有深浅），切面图就出来了。

1. 立体拼合的思想准备与做题次序

立体拼合是空间题里最"劝退"的一类。刘义恒老师开篇就把它定性为思维题而不是技巧题：考题不会重复，靠背题型没用，靠的是稳定的观察顺序和空间想象力。

  • 淡化技巧，强化思维。题目不会重复，没听懂先标记、跟着思路走；空间思维完全可以后天培养。
  • 猜测也要有技巧，但在考场上放弃要更果断——立体拼合性价比低，能数出来就选，数不出来就蒙一个走人。
  • 调整心态：知识点本身就是难点，不焦虑不浮躁，静下心、平常心。
  • 集中注意力：一起做题，不单独做题；课下再复盘、做笔记。
做题次序（第一步：看选项，选方法）
  • 1. 选项个数有差别 → 优先考虑数个数；
  • 2. 选项分层明显或每层个数不一样 → 优先考虑分层拼 / 分层数；
  • 3. 考虑找特殊，即找题干中最大或抽象的方块，优先代入。
速记口诀：① 个数　② 层数　③ 特殊
易错点：这三步是"看选项选方法"，不是三件事都做一遍。选项个数明显不同就只数个数；个数一样才去看分层形状。顺序反了，时间就耗光了。
2. 第一步：数个数——选项个数有差别，优先考虑数个数

只要四个选项的块数不一样，本题多半就是一道"加法题"：题干大图形的总块数 = 已给出的几块之和 + 所求的一块。这时不用看形状，数一遍就能定答案。

什么时候需要数？
  • 打算猜，可以数——快速算术，能秒杀就秒杀；
  • 打算做，先不数——如果准备认真拼形状，先别急着数，免得被数字带偏；
  • 选项 3 个一致，尽量不数——四个选项里三个块数相同，说明考点不在个数上。
📝 例题1 · 数个数（"立体拼合-常规"五件套）
左边的立体图形由 22 个小正方体组成，① 5 块、② 6 块、③ 5 块，则 ④ 应为下面哪一个？
解析：先看选项：A 4 块、B 5 块、C 5 块、D 6 块——个数有差别，直接数个数。题干大图形共 22 块，已给出 ①5 + ②6 + ③5 = 16 块，所以 ④ = 22 − 16 = 6 块。四个选项中只有 D 是 6 块，不需要再比对形状。
答案：D　（五件套加法题，讲义 p9-11）
3. 第二步：分层数与分层拼——每层个数不一样，数层数性价比最高

当四个选项的块数差不多、但分层明显（比如都能看出上、中、下三层）时，就换成"数每层个数"。' 把目标图形（正方体 / 长方体 / 题干大图形）按层拆开，逐层做减法，看哪个选项的三层个数刚好补上缺口。

  • 数每层个数，优先考虑不旋转的情况——先按原方位试，能对上就别转。
  • 每层个数不一样，数层数性价比最高——一眼就能排除几个选项。
  • 每层个数一致的选项，正确可能性更高——如果某个选项的三层个数和缺口完全一致，它多半就是答案。
  • 层数做完还分不出来，就把选项转换成平面图（每层画成九宫格），逐格比对。
易错点："层"要按同一个方向数。题干按上→下数，选项也必须上→下数；不要题干从上数、选项从下数，那样层数全是错的。
同型四连（国考"正视图 + 后视图"类，共 4 道）：讲义 p64-100 连排了四道结构完全相同的题——20 国考（难度 73%）、21 国考（58%）、22 国考（36%）、20 国考（40），题干都是"给出正视图和后视图，问①②③中哪一块能填入问号处"。解法与上面两步完全一致：先数个数、再分层数，都排不掉就找最特殊的那一块优先代入（讲义在这四道题上分别标注答案 B、C、D、D）。它们的关键动作是铅笔涂黑——把代入的那一块涂黑，再看剩下的缺口长什么样。

4. 第三步：找特殊——题干中越大或越抽象的方块，位置的局限性越大

个数、层数都排不掉选项时，就进入最关键的一步：找特殊。题干里往往有几块碎片（①②），' 要判断先代入哪一块——判断标准是谁的位置局限性最大。

  • ①抽象：形状奇怪、凹凸不平的那一块，能放的位置极少，先代它；
  • ①最大：块数最多的那一块，同样位置局限性大，先代它；
  • 题干里越大或越抽象的方块，位置的局限性越大——先代它，能一次性排掉很多选项。
  • 提示：代入①之后如果发现②不好代，可以先代"选项"（把选项当第三块，反推②的位置）。
  • 还有一条对称思考：题干给的是几个一样的方块时，优先想对称性（能否切成完全相同的小块）。

5. 黑块类：接触面 → 找特殊 → 合理分割

题干里出现灰色 / 黑色小方块时，就换成黑块类的思路：依次确定 3 个黑块的位置。

黑块类答题思路（依次确定 3 个黑块位置）
  • 方法 1：黑块与白块的接触面总数（猜测）——每个黑块周围贴着几个白块，是这道题的"指纹"；选项里黑块的接触面数小于题干的，一定错。
  • 方法 2：考虑找特殊——黑块本身就是最特殊、最抽象的方块，优先代入。
  • 方法 3：合理分割——看黑块跟几个白块相连是否合理（分割后每块必须连成一体、不能凭空断开）。
快速记忆：① 接触面　② 找特殊　③ 合理分
提示：代入①后如果发现②不好代，可以先代"选项"；题干是正、反两面直观图时也一样——先把最特殊的黑块定位，剩下的用分割合理性排错。

7. 四个小结与易错清单
小结一：层数（数层数什么时候用）
  • 每层个数不一样，数层数性价比最高；
  • 每层个数一致的选项，正确可能性更高——个数和缺口完全对上时，基本就是它；
  • 数每层个数，优先考虑不旋转的情况；分不出来就把选项转换成平面图逐格比对。
小结二：找特殊（谁的位置局限性最大）
  • 抽象（形状怪）→ 优先代入；
  • 最大（块数多）→ 优先代入；
  • 选项本身更大、结构一致时，也可以先代选项；
  • 题干给的是几个一样的方块 → 立刻想对称性。
小结三：接触面（黑块类）
  • 先数黑块与白块的接触面总数（猜测）；选项接触面个数小于题干的，直接错；
  • 再找特殊，把黑块位置最特殊的一块优先代入；
  • 最后用合理分割检查：黑块跟几个白块相连，分割后每块是否连成一体。
小结四：几个一样
  • 总数 ÷ 3 先定块数；
  • 再找特殊，直接代入选项，用旋转 / 平移验证能否完全重合。
易错清单
  • 只数个数不看选项：选项个数一致时不要数，白费时间；
  • 数层方向不统一：题干从上往下、选项也要从上往下；
  • 看到黑块就慌：黑块题反而是最好定位的，它是天然的"特殊块"；
  • 忘了旋转：立体拼合允许旋转、不允许翻转镜像，但讲义也提示"数每层个数时优先考虑不旋转的情况"——先按原方位试，能对上就别转。
第一步看选项定方法：① 个数　② 层数　③ 特殊；黑块类：① 接触面　② 找特殊　③ 合理分

1. 不规则图形（多面体展开图）：先看选项差异，再抓题干特殊

「不规则」指的是：题干给一个不规则立体图形（长方体、多面体、带缺口的立体），要求选它的外表面展开图；或者反过来给展开图，问能折成哪个立体。广东、山东、江苏、联考、浙江、四川、上海等地的事业单位和公务员考试都在考，是必须拿分的"技巧题"。

老师的核心提醒：这类题别在脑子里把整个立体折一遍。命题人只在"某一条公共边"或"某一个特殊面"上动手脚，所以只需抓住这两个突破口。

技巧一：对比选项找差异，用公共边做排除（公共边长度相等）。

技巧二：题干找特殊（最大的面、标记物），看它周边。

  • 公共边法：立体折好后，相邻两个面共用同一条棱，这条棱在两个面上必须一样长。选项之间往往只差"某个面接在哪条棱上"，直接比公共边长度就能排除。
  • 找特殊法：题干立面上必有一块最大的面或带标记的面（黑块、斜线阴影、记号），它在立体中的位置以及周围四个面的顺序、朝向是唯一确定的。
  • 易错点：（1）只看单个面像不像就选；（2）忘了公共边长度必须等于那条棱；（3）只核对一个面，不"看周边"。
考场顺序：① 先横看四个选项，找出差异（通常只有 1～2 处不同）；② 回题干找最大面／标记物；③ 用公共边长度复核一遍。整套流程不需要想象完整的三维折叠。
2. 不规则 · 用公共边做排除

这一类题型的选项长得都很像，差异集中在"某一块面接在横排的第几格""接着的面边长是多少"。把相邻两面的公共边长度逐一核对，不等长的直接排除。

4. 平面拼合（平移型）：出题人怎么画，我们就怎么拆

出题者怎么出"平面拼合"？先画好一个图形，把它复制粘贴，再切割成几块。所以反过来做题：就是把几块"拼回去"。

基本原则：图形只能通过上、下、左、右平移，不能旋转、翻转（多数考试都这么限定，题干里一定会写明）。

解密：① 特殊线条（唯一的长线或横竖线）② 等长的线 ③ 拆分选项

  • 特殊线条：四块小图里如果只有一块含"最长的直线段"，选项里也必须出现一条等长的直线段，否则排除。
  • 等长的线：两块的边要拼在一起，必须有一条等长的边；题干中的长边长度在选项里要能一一对上。
  • 拆分选项：反过来把选项按缺口拆成几块，看能不能与题干四块一一对应（题目问"哪个能拼成"时好用）。
  • 易错点：忘了题干"只能平移"的条件，选了需要旋转／翻转才能拼出来的选项。

5. 平面拼合 · 黑白面：本质是"区分旋转与翻转"

出题者怎么出"黑白面"？四张纸片，每张纸片一面是黑色，另一面是白色。所以拼合的时候，"翻面"会把颜色翻过来——这就是命题人专门留的判断点。

基本原则：可以平移、旋转、翻转（多数考试）。

解密：旋转 → 颜色一致；翻转 → 颜色变化。本质就是区分旋转和翻转。

方法回顾 · 时针法：找一块有特征的图形（黑块、尖角、缺口），从"同一起点"沿"同一路径"走到"同一终点"，看三个点在题干和选项中的顺时针／逆时针方向是否一致：方向一致 = 只旋转；方向相反 = 被翻转过。

注意"三个同一"：同一起点、同一路径、同一终点。三个点一旦变了，时针方向就没有可比性。

考场思维：先看其他选项——B、C 两个选项里"2、3 号纸片"的结构是一样的（同构），不可能出现"一个能拼、一个不能"，所以答案只能在 A、D 中。
再用时针法核对 A、D 中黑块与白块的时针方向：A 与题干一致（只经过旋转）；D 中黑块的时针方向与题干相反，属于必须"翻转"才能得到的情形，与黑白面的颜色关系矛盾（题干的纸片翻面后颜色要变，D 中颜色没有相应变化）⇒ D 不能拼成。
答案：D

7. 折叠：本质上考查"对称性"

折叠题怎么来的？把一张纸对折、再对折，剪一刀，展开后是什么？——纸上的折痕就是对称轴，剪口会被"镜像"复制若干次。

解密：本质上考查对称性。

  • 数清折了几次：折 n 次，剪口就被复制 2ⁿ 份（四折就是 4 份），出现的位置关于折痕对称。
  • 看清剪在哪儿：剪在"纸边"上，展开后缺口就在轮廓上（窗花边缘断开）；剪在"纸中间"，展开后是内部的镂空。（这是选项之间最常见的差异）
  • 对称轴方向：折痕是横的、竖的还是斜的，决定了展开后图案的对称方向。
  • 易错点：只看图的"像不像"，不数折痕／不看剪口是否落在纸边。

下列 4 张纸条，沿折痕能折断出如图所示图形的是：

1. 3+3 体系总纲：一句话记住图推
总口诀：拿到一道图推，先问自己一句——“图形像不像？”
· 像（有一样的图案） → 看 位置 / 样式 / 标记（3 类）
· 不像（没有一样的图案） → 看 属性 / 数量 / 图形间位置（3 类）
“3+3”= 两条大道，六个路口，三十多个考点。
  • 有一样的图案（3类）：完全一样 → 【1】位置（平移 / 旋转·翻转）；部分一样 → 【2】样式（运算）（黑白运算 / 加减同异）；【3】标记。
  • 没有一样的图案（3类）：【1】属性（对称性 / 曲直性 / 开闭性）；【2】数量（面 / 笔画 / 点 / 线 / 元素 / 直角）；【3】图形间位置。
  • 两条分支的“分水岭”只有一个动作：先比——相邻两图有没有“一样的图案”。有 → 走左边；没有 → 走右边。
2. 分支速查表 ①：位置（“完全一样”走这里）
规律什么题眼优先看什么易错点
平移 图形完全一样；宫格类黑块/元素个数一样 内部有规律 → 内外分开看（如 16 宫格“内部相等”）
内部无规律 → 常规平移：上下左右、斜线移动（方向可变）		 步长会变（±2 步长）；方向会变；非缺黑平移要“16 宫格横分 2 部分”
旋转 / 翻转 图形完全一样，但朝向变了 技巧：①特殊图案（大区域）②对折法、箭头法 旋转 ≠ 翻转，翻转会“镜像”；方向与度数要看准
非宫格类（隐藏线条） 线条藏在图里；“离形”：三角形、正方形、菱形 思维：就近原则 + 找特殊（先找隐藏线条/隐藏图形） 只顾找线条，忘了找“特殊的那个图形”
相邻比较 相邻两幅图长得很像 黑块-相邻比较 / 矩形-相邻比较 / 小球-相邻比较 必须与相邻图比，不能跳着看（跳着看是另一条规律）
宫格拆分 16 宫格一格一格看不出规律 拆成 2 部分：①分割 2 部分 ②大面积图案 拆错就全错；16/25 宫格与蜂窝类的运动方向要分清
主流宫格类型 16 宫格 / 25 宫格 / 蜂窝类 先看运动方向，再看是“整体走”还是“内外分开走” 蜂窝类方向容易看反
3. 分支速查表 ②：样式（运算）与标记（“部分一样”走这里）
规律什么题眼优先看什么易错点
黑白运算 ①两明图 ②九宫格 ③相同区域 技巧：相同区域 / 对比选项——先把“相同的区域”找出来，再看颜色怎么变 相同区域判断错；题型创新（颜色创新、位置对应）
加减同异 图形部分一样；先看第 1 组与第 2 组之间的线条 有相同 → 先运算（可能图3动）
无相同 → 先旋转：1-2 样 → 图2动；2-3 样 → 图1动		 难点在拆分思维；搞不清到底谁在动（图1/图2/图3）；九宫格还有“纵向”规律
标记（小圆圈/小图案） 图上有小圆圈、小图案标记 固定顺序：位置（上、下、左、右、内、外）→ 点（曲直性、引发的线条数量）→ 线（直线/曲线、最长线/最短线、线的位置）→ 图形（直角/锐角/钝角、最大角/最小角）→ 面（单独面/相交面、相同区域/不同区域、形状、属性、面积）→ 多个标记 多个标记时，要看“标记物之间的比较”，或“连线后与原图的关系”
样式的一个高价值结论：“图形由线条组成”的题，先看“第 1 组和第 2 组之间的线条像不像”——像就先运算，不像就先旋转。
4. 分支速查表 ③：属性与数量（“没有一样的图案”走这里）
规律什么题眼优先看什么易错点
对称性 图形规整、美观（规律、美观 → 对称性） 先识别（轴对称？中心对称？）→ 后细化：1 条轴对称 → 看方向；2 条相交 → 看与图形间的位置；多条对称 → 数数量 “细节挖坑”：对称轴穿过几个点/几个小球；多个规则图形还要“内外拆分-识别”
曲直性 1/2、2/3 是曲线 整幅图是曲线、直线，还是曲线+直线（复合） 曲线占多少比例；曲直与“开闭”混
开闭性 生活化图形 全封闭 / 半封闭
拓展【生活化思维】：面、部分数、属性、笔画		 生活化图形上来就数面，忘了先想开闭性、部分数
面 封闭区域明显；框内面 面数量 → 细化：形状（每个面形状一样）、三角形（图形由三角形/矩形组成）、大小（明显大面/小面 → 形状、属性、面积）、相同面（有一样的面） 框内面 vs 框外面；面数量与笔画混
笔画 强特征：五角星、日、田、圆相交；多端点 数奇点：0 或 2 个奇点 = 一笔画；去外框后再数 外框要去掉；多个独立图形要分开算再加
点 线条交叉多；都有曲线 曲直交点、切点、框点（多边形）、框内面/线
【特殊】圆形相交 → 笔画 → 点		 框上点（3 或 4）vs 框内点；切点别漏数
线 大量线条；斜线、相似三角形 曲直、横竖、框；平行线；贪吃蛇：无小球 → 首尾（方向、平行/垂直、之间的线条数）+ 数量（直角、平行线）；有小球 → 内部相同则内外分开、分 2 堆显则看每堆个数 → 穿过小球个数
内外分图：内外分离/部分/个数		 首尾线方向看反；2 种线要运算（曲线/直线、横线/竖线）
元素 多个独立小图形；强特征“独立” =2 种元素 → 先运算后换算（公式：图1 + 图3 = 两倍图2）
>2 种元素 → 找相同（自己 / 邻居）；无相同 → 看属性		 元素相同看相邻比较；元素不同看位置/运算，别混
直角 强特征：五角星或三角形、十字架、矩形（外框） 数直角个数（常递增/递减）；再看直角的位置变化 直角数完了忘了看位置；外框直角要算进去

6. 解题决策流程：拿到一道题按这个顺序试
核心心法：先分类（像不像），后排序（先属性后数量），最后验证（相同区域 + 对比选项）。
  1. 第 1 步｜整体扫一眼，问“像不像”。把题干相邻两图比一比：有没有“一样的图案”。
  2. 第 2 步｜完全一样 → 位置。先数个数、看黑块/元素是否一样 → 平移（找方向、步长）→ 不行再旋转/翻转（对折法、箭头法）。宫格类记得“内外分开看”。
  3. 第 3 步｜部分一样 → 样式（运算）或标记。先看“第 1 组与第 2 组之间的线条”：有相同先运算，无相同先旋转；有标记就先按“位置→点→线→图形→面→多个标记”过一遍。
  4. 第 4 步｜不一样 → 先属性。对称性 → 曲直性 → 开闭性。约 30 秒没有结果，立即转数量。
  5. 第 5 步｜数量按固定顺序数：面 → 笔画 → 点 → 线 → 元素 → 直角。每个考点都要带上“细化考点”（面看形状/大小/相同；点看切点/框点/框内面；线看首尾、贪吃蛇、平行线）。
  6. 第 6 步｜图形都是 2 个 → 图形间位置。相离/包含/相交，再看“点—线—面”三个层次；复杂题找“共同图案”。
  7. 第 7 步｜黑白块/黑白球 → 走专项五连：对称 → 位置 → 黑白运算 → 部分数 → 图形关系/面积/相邻比较/笔画-周长。
  8. 第 8 步｜锁定后必验证。用“相同区域”快速排除，用“对比选项”找差异——选项之间往往只差一个细节，那就是考点。

📝 例题6 · 综合（立体截面，2025 国考执法卷 81 题）
左边为给定的多面体，现用经 P、Q、R 三点的平面对其进行切割，问哪个选项是其切面？
解析：立体截面题仍走“先分类、后验证”的路子：先看这个多面体是个“阶梯状”的方块组合（高的一块 + 矮的一块），再想经 P、Q、R 三点的平面切下去会切到哪些面。 经 P（左侧底角）、Q（正面底边中点）、R（右侧面）三点作截面，切面必然“从左侧竖直面进入 → 经过台阶的竖直立面 → 从右侧面切出”，所以切面轮廓应是：上部一块较宽的矩形 + 下部偏左伸出一个方形小凸角。 B、C 的凸角位置不对（B 在右下、C 在下方且上部带斜边），D 的图形被拆成了两块（不可能是一刀切出的连通切面），只有 A 与推理吻合。
答案：A
