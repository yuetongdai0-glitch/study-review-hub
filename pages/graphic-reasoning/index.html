总

解题总框架：3+3 体系

先看图形「像不像」，再进对应分支。这是刘义恒笔记的核心骨架，做题第一反应必须从这里出发。

1
第一步：看整体像不像

图形间有没有「一样的图案」（完全相同 / 部分相同 / 带标记符号）？有 → 左侧三分支；没有 → 右侧三分支。

像
有相同图案 → 三个方向

① 位置：图形完全一样 → 平移、旋转、翻转
② 样式：部分一样（黑白块、线条重复）→ 遍历、加减同异、黑白运算
③ 标记：有黑点 / 箭头 / 小圈 → 看标在哪（上下左右、点线面角）

不像
无相同图案 → 三个方向

① 属性：整体特点 → 对称、曲直、开闭（先看属性，对称优先）
② 数量：数 面 / 线 / 点 / 角 / 素 / 笔画
③ 图形间位置：相离、相交（交面/交线/交点）、包含、相切

💡 黄金顺序：数量题先看属性（对称优先）；图形规整美观 → 先想对称；极端情况（如某图形非常特殊）→ 优先考虑图形间关系。
🎯
先看像不像 → 像：位置·样式·标记；不像：属性·数量·图形间位置
总口诀
1

位置规律

0/9

特征：各图形构成完全相同（外形、数量完全一致），只变位置。口诀：基本相同看位置，再看元素往哪儿走。

位置

平移：有哪两大考法方向？

▶
  • 内外分开看：图形分内外两层时，内外元素分别移动（内层走内层、外层走外层）——高频易错点。
  • 常规平移：上下、左右、斜向运动；步数可恒定 / 递增 / 循环。
  • 技巧①特殊图案优先：锁定一个特殊小元素，追踪它的移动路径最省力；技巧②数个数：统计移动格数找规律。
📌 特征词：图形完全相同 + 有格子/宫格 + 小元素在动
  • 步数：恒定（高频）、递增，递减较少 ——「确定方向」是难点。
  • 出题形式：除「分组分类」外都可 —— 平移不考分组！
平移

宫格类平移：9 / 16 / 25 宫格各自怎么定方向？

▶
  • 9 宫格：直线运动（横向/纵向）或绕圈运动（顺/逆时针）。
  • 16 宫格：先数每行 / 每列的个数——横向黑块数量相同 → 横向运动；纵向相同 → 纵向运动。也可数内部个数，内部相等则考虑「内外分开看」。
  • 25 宫格：比 16 宫格多 1 圈，斜线运动空间更大；黑块由单个运动 → 整体运动（与 16 宫格底层逻辑一样：内外、常规）。
  • 蜂窝类：与 25 宫格底层逻辑一样，方向可变（横、左斜、右斜）。
  • 「走到头」两种走法：循环走（从头开始）／ 反弹走（直接弹回）。
📌 口诀：识别考点看「数个数」，定方向靠「数每行每列」或「找大区域（特殊图案）」。
位置

旋转：怎么快速判断？

▶
  • 看顺/逆时针方向，再看旋转角度（45° / 90° / 180° 等，常呈等差或循环）。
  • 整体旋转不好观察时，盯住一条特征线或一个特征角。
口诀：顺逆时针先绕圈，再看角度找答案。
位置

翻转：横竖轴怎么翻？和旋转怎么区分？

▶
  • 横轴对称 → 上下翻（图形上下颠倒）；竖轴对称 → 左右翻（左右镜像）。
  • 区分技巧：在图形上画一个「带方向的箭头」，旋转不改变手性、翻转改变手性（镜像翻转后像照镜子，永远无法通过旋转重合）。
口诀：横轴对称上下翻，竖轴对称左右翻。
位置

常见陷阱与观察技巧

▶
  • 图形完全一样时优先位置，别急着数数量。
  • 可用相邻比较：只看相邻两幅图的变化，快速锁定移动方向。
  • 遇到「2、3」直接看两幅图即可判断是平移 / 旋转 / 翻转（翻转观察点：图案的左右/上下是否镜像）。
心法：位置规律特征最明显——「一模一样，只动位置」。
位置

旋转与翻转：方向、角度怎么定？

▶
  • 作图特点：每幅图图案相同；在重合情况下，图案数量会减少。
  • 旋转方向：① 顺时针　② 逆时针。
  • 旋转步数（角度）：30° / 45° / 60° / 90° / 180° —— 90°、180° 是高频。
  • 翻转：
    （1）左右翻转 = 竖轴对称
    （2）上下翻转 = 横轴对称
📌 口诀：左右翻转变左右，上下翻转变上下，全都变 = 180° 旋转。
位置

旋转翻转的「箭头法」「时针法」怎么用？

▶
  • ① 箭头法（找唯一，定方向）：找一个唯一点 / 唯一边作参照物画箭头 —— 适用于方向性强的图形（如 ↑、A、T、三角形、梯形）。
  • ② 时针法：要求「三个同一」—— 同一起点、同一路径、同一终点；在题干与选项上分别标注，比较顺 / 逆时针是否一致。
  • 对比选项：图形较乱时，直接逐项对比选项差异再回题干验证。
⚠️ 两个提醒：
① 图案一样 + 分组分类题型 → 不考位置规律（旋转翻转）
② 黑球不好看 → 看白色部分；但这些技巧不一定适用所有题型。
位置

「相邻比较」是什么？两个判定信号怎么认？

▶
相邻比较 = 只比「相邻两幅图」之间发生了什么变化，而不是盯着一整行找规律。
  • 两个判定信号（笔记原话，看到就用它）：
    ① 有黑块不动（图里有一部分图案原地没动）
    ② 平移没规律（按常规平移怎么数都对不上）
  • 作图特点：图案相同，但相邻两图之间有元素保持不动；而普通位置规律是所有元素都在动。
  • 操作：把第 1 图与第 2 图叠着比 → 看哪几个没动、哪几个动了 → 再看第 2、3 图是否重复同样变化。
  • 配套技巧：① 特殊图案（大区域）优先追踪；② 数个数（统计移动格数）。
⚠️ 易错提醒：相邻比较是「位置规律专属」的思路。样式规律、数量规律不要用它，会走偏。
总纲

图推的「出题形式」有哪几类？出题人偏好什么？

▶
  • 横排形式：一组图（4~5 个 + 问号）；两组图（前一组给规律，后一组照做）。
  • 宫格形式：九宫格（最常考，喜欢考"运算"）。
  • 空间类：给立体图形，选对应视图 / 拼合。
  • 分组分类：给 6 个图形，分成两组（①②③ / ④⑤⑥）。
出题人偏好（笔记原话）：
① 平移、相邻比较 → 不出"分组分类"
② 样式 → 以"两组图""九宫格"为主
③ 九宫格 → 喜欢"运算"
🧭
基本相同看位置，再看元素往哪儿走 / 顺逆时针先绕圈，再看角度找答案 / 横轴对称上下翻，竖轴对称左右翻 / 有黑块不动、平移没规律 → 用相邻比较

样式规律

0/3

特征：图形部分相似（线条重复、黑白块、轮廓相同）。三大考法：遍历、加减同异、黑白运算。

样式

遍历：什么意思？

▶
  • 相同元素反复出现，但每一行/每一组缺一个 → 缺啥补啥（形状 / 颜色 / 方向都要看全）。
  • 常与位置结合：元素种类齐全但摆放位置轮换。
口诀：元素重复看遍历，缺啥你就补个啥。
样式

加减同异：三种运算是什么？

▶
  • 求同：保留两图相同线条；求异：去掉相同、保留不同；叠加：全部线条相加。
  • 注意结合位置：先旋转/翻转再运算，或运算后整体移动（常考组合）。
口诀：线条重复求同异，结合位置别忘记。
例题 · 三种运算一起练（求同 / 求异 / 叠加）

题干：已知图1、图2，按「求同 / 求异 / 叠加」三种规则分别运算，图3 应各是什么样子？先自己画一遍，再对照下图。

答案：① 求同 → 只剩两图共有的方框（水平中线、竖直中线各自独有，被去掉）；② 求异 → 去掉共有的方框，只剩水平中线 + 竖直中线（一个"十"字）；③ 叠加 → 方框 + 水平中线 + 竖直中线全部相加（一个"田"字）。判别口诀：先看两图哪些线条重复——重复的保留是求同、去掉是求异、不管重不重复全保留是叠加。

样式

黑白运算：什么时候用？怎么验证？

▶
  • 特征：轮廓完全相同、黑白颜色数量不相同（黑块数在变）→ 优先黑白运算。
  • 规则如 黑+白=黑、白+黑=白、黑+黑=白、白+白=黑，每道题规则都要现场推，用第一组图形推、第二组验证、第三组应用。
  • 相同位置做验证：逐格对应，不能错位。
口诀：颜色数量不相同，轮廓相同看运算。
⚠️ 区分：黑块数量相同 → 位置移动（平移）；黑块数量不同 → 黑白运算。
🧩
元素重复看遍历，缺啥你就补个啥 / 线条重复求同异，结合位置别忘记 / 颜色数量不相同，轮廓相同看运算

标记规律（功能元素）

0/2

特征：图形里混着小黑点、白圈、箭头、小三角等与图形无关的小符号 —— 符号本身不重要，重要的是它标在哪。

标记

功能元素：重点看标记的哪些位置？

▶
  • 标在点/线上：交点（曲直交点、线线交点）、切点、边上 → 看交线特征、边的长短。
  • 标在面里：封闭面内/外 → 看面的大小（最大面/最小面）、形状、对称性、面积。
  • 标在角里：直角 / 锐角 / 钝角 → 分清角度类型。
  • 标在上下左右：图形本体的方位关系。
本质：把「标记」当探针，指向图形的点 / 线 / 面 / 角特征。
标记

两个黑点 / 箭头型标记怎么考？

▶
  • 两黑点：看两点的连线方向（横/竖/斜）、连线经过什么（点/线/面/空白）、两点是否同面同区域。
  • 箭头：看指向（上/下/左/右）、与图形线条的关系（平行/垂直/重合）。
  • 对称图形中，标记位置还常与对称轴结合（在轴上/不在轴上、两侧对称分布）。
📍
相同元素每图有，看看标记在哪里 —— 点上标看交线，边上靠看长短，面里放看大小，角里搁看锐钝
标记口诀
4

属性规律

0/4

特征：元素组成不同、不相似、数量特征不明显 → 先看属性。三大属性：对称性（最常考）、曲直性、开闭性。

属性

轴对称：考什么细节？

▶
  • 识别：等腰元素（等腰三角形、等边图形、箭头形）、规则图形 → 画出对称轴看。
  • 细化考法：①对称轴数量（1条/2条/多条，递增或分组）；②对称轴方向（横/竖/斜，旋转变化）；③对称轴与线条关系（与图形线条重合 or 垂直）；④对称轴是否经过特定元素（点/面）。
口诀：规则图形看对称，轴和中心要分清；等腰元素别放过，轴画出来更清晰。
属性

中心对称 & 轴+中心：怎么判断？

▶
  • 中心对称：图形原地旋转 180° 能与原图重合。特征图形：N、Z、S 形、平行四边形。
  • 轴对称 + 中心对称：有两条垂直的对称轴（如正方形、正六边形、圆）→ 轴和中心都可行。
  • 注意：某些图形只是轴对称（如正五边形），别误判。
口诀：N形Z形S形，还有平行四边形，原地旋转180，中心对称就是它；有种图形很贪心，两条垂直对称轴。
属性

曲直性：三种情况 + 内外组合

▶
  • 全直线：单一直线多边形（属性不行可转数直线）；全曲线：圆、弧（优先考虑曲直性）；曲直混合：有曲有直。
  • 内外曲直：外直内曲 / 外曲内直 / 外直内直 / 外曲内曲 —— 分层看。
口诀：单一线条看曲直，曲直共存别忘记；单一直线多边形，全直是它的属性；单一曲线圆和弧，优先考虑曲直性。
例题 · 曲直性三种情况归类

题干：把下面三个图形分别归入「全直线 / 全曲线 / 曲直混合」中的哪一类？

答案：① 三角形只有直线 → 全直线；② 圆只有曲线 → 全曲线；③ 半圆由一段弧和一条弦组成，既有曲线又有直线 → 曲直混合。口诀：单一线条看曲直，曲直共存别忘记——先看一个图形里到底有没有曲线、有没有直线，两类都占就是混合。

例题 · 内外曲直组合判别

题干：下面四个图形都是「有内有外」的组合，请分别说出它们属于「外直内曲 / 外曲内直 / 外直内直 / 外曲内曲」中的哪一种。

答案：① 外直内曲（方框 + 圆）；② 外曲内直（圆 + 三角形）；③ 外直内直（方框 + 三角形）；④ 外曲内曲（圆 + 圆）。做法：分层看、先外后内——第一步只看外轮廓是直线还是曲线，第二步再看内部图形，两步就能锁定。

属性

开闭性：何时才考虑？

▶
  • 全开放（大门敞开）、全封闭（全部关门）、半开半闭（有缺口的图形）。
  • 重要：半开半闭「很淘气」，别的不行才考虑 —— 开闭性整体考频较低，作为兜底规律。
口诀：遇到开口看开闭，全开封闭都可行；半开半闭很淘气，别的不行才考虑。
🪞
规则图形看对称，轴和中心要分清 / 单一线条看曲直，曲直共存别忘记 / 遇到开口看开闭，全开封闭都可行
属性3连
5

数量规律

0/7

特征：元素凌乱、各不相同 → 数量类。六个数点：面、线、点、角、素、笔画。顺序：先属性后数量，用特征图锁定考点。

数量

面的考点：「6+6」记忆口诀是什么？

▶
6 + 6 口诀：所有，大小，相同　+　形状，属性，面积
三个角度 × 三个属性维度 = 面的全部考法
  • 所有面：分割后每个面的形状（三角形、四边形……）。
  • 大小面：最大面 / 最小面 —— 看形状、属性（对称性）、面积。
  • 相同面：大小、形状都一样的面 —— 数个数、分组数。
口诀：多个窟窿入眼帘，数面考点灵光现；数完无解别放弃，面的形状全考虑；多胞胎面一出现，就要考虑相同面；图形明显大小面，关注形状和属性。
数量

线的考点：直线 / 曲线 / 平行线

▶
  • 直线数：单一直线多边形，属性不行数直线。
  • 曲线数：单一曲线圆和弧，属性不行数曲线。
  • 平行线：出现大量平行线段时数平行线组数；也考内外线条数、线条加减。
  • 笔画数：见下方专项（一笔画）。
数量

点的考点：交点 / 切点 / 曲直交点 / 框上框内

▶
  • 线条交叉多（大树杈） → 优先数交点。
  • 有曲有直、交叉明显 → 优先数曲直交点。
  • 圆与直线相切多 → 数切点。
  • 图形有外框（金刚罩）→ 数框上、框内、框外的交点。
口诀：大树杈子非常多，别忘交点数起来；图形有曲又有直，曲直交叉很明显；图形都有金刚罩，围绕外框想考点。
数量

角的考点：直角为主

▶
  • 横平竖直、垂直结构多 → 数直角（最常见）。
  • 折线折出多个角 / 留缺口 → 数角；也考锐角、钝角（较少，结合功能元素考）。
口诀：折线折出多个角，留了缺口别忘角；横平竖直多垂直，直角数量来试试。
数量

素的考点：种类 / 个数 / 部分数 / 换算

▶
  • 多个小图形出现 → 先数种类和数量（两种元素优先分开数，两种以上一起数）。
  • 生活化图形 / 粗线条 / 汉字 → 数部分数（连在一起的算一部分）。
  • 元素换算：两三种小元素数量没规律但排列整齐 → 常为换算关系（如 1 大 = 2 小）。
  • 实在不行找相同：每幅图中相同元素的个数。
口诀：外框形状要牢记，多个小图形出现，先数种类和数量；生活化或粗线条，部分数量经常考。
数量

笔画数：奇点判定（必考高频易错）

▶
奇点：从该点引出的线条数为奇数的点。
连通图中：奇点数 = 0 或 2 → 一笔画；笔画数 = 奇点数 ÷ 2。
  • ⚠️ 端点也是奇点，数的时候千万别漏。
  • ⚠️ 奇点一定成对出现（2、4、6…），数出奇数个说明数错了。
  • 特征图：五角星、日字及其变形、田字及其变形、切圆、多端点图形、汉字「中」。
  • 多笔画一般不超过三笔，常考一笔 vs 两笔分组。
口诀：一根线条画到底，首尾特别要注意（端点即奇点）。
数量

数量规律怎么快速锁定考点？

▶
  • 特征图 → 考点：窟窿多→数面；线条交叉多→数点；有曲有直→曲直交点；多端点/五角星/日田→笔画；横平竖直→直角；生活化→部分数；单一直线/曲线→数线。
  • 弱特征 vs 强特征：特征明显（强）直接对应考点；特征弱时按 属性→数量 顺序试探，先对称再数数。
  • 数量规律常考等差、循环、恒定、和相等（每行之和相等）。
🔢
多个窟窿数面，交叉成堆数点，曲直交叉数曲直点，日田五角星数笔画，横平竖直数直角，生活图形数部分

图形间位置关系（特殊规律）

0/3

特征：多个独立图形 + 封闭空间明显；或图形间有明显「接触关系」。考频中上，记住分类即可得分。

关系

图形间五大关系是什么？

▶
  • 相离：多个图形独立站，互不接触 → 相离关系。
  • 相交：交于点 / 交于线 / 交于面（交面是重头戏）。
  • 包含：一个图形完全包住另一个。
  • 相切：内切 / 外切（圆与圆、圆与线切点）。
口诀：封闭空间很明显，图形关系成考点；多个图形独立站，相离关系是答案；多个图形交于点，或者彼此一线牵。
例题 · 图形间五大关系一眼认

题干：下面五个图形分别体现了两图形之间的哪种关系？（相离 / 交于点 / 交于线 / 交于面 / 相切）

答案：① 相离：两个图形独立站、互不接触；② 交于点：只在角上碰了一个点；③ 交于线：共用一条边，相交部分是一条线段；④ 交于面：相交部分是一个"面"（这是重头戏，接下来要看这个面的形状、大小、对称性）；⑤ 相切：圆与圆只碰一个点。

例题 · 相切的三种切法

题干：下面三个图形都属于"相切"，请分别说出是哪一种切法。

答案：① 圆与圆外切：两圆在外部相碰，切点夹在两圆之间，圆心距 = 半径之和；② 圆与圆内切：小圆在大圆内部相碰，圆心距 = 半径之差；③ 圆与直线相切：圆心到直线的距离正好等于半径，垂足就是切点。相切题只需盯住"只碰一个点"，再判断切点在内还是在外。

例题 · 分组分类实战（相离 vs 相交）

题干：把下面六个图形分成两类，并说明分类依据。

答案：①②③ 为一类——两个图形互不接触，属于 相离；④⑤⑥ 为一类——两个图形有重叠区域，属于 相交（都交于面）。这类题只要抓住"图形挨不挨着"：不挨着就是相离；挨着再细分交于点 / 交于线 / 交于面。

关系

「相交」还能怎么细化？

▶
  • 交于面：看相交部分的形状、大小、属性（对称）、面积、边数 —— 相交面是重头戏。
  • 交于线：看相交线的数量（1条/2条）、长短。
  • 交于点：看交点数量、位置（内部/边缘）。
  • 两个图形相交于面 → 优先看面的特征属性（对称性等）。
口诀：两个图形面交叉，相交面是重头戏；形状大小和属性，全部都是得分地。
关系

图形拼接怎么考？

▶
  • 连接方式：点连接 vs 线连接（分类常考）。
  • 公共边数量：两个图形拼接有几条公共边（1条/2条……）。
  • 拼接后看：整体边数、周长、封闭区域变化。
口诀：多个图形线相连，相交直线是关键；边长边短与边数，样样考虑拿分数。

黑白块专项（26版）

刘义恒黑白块完整框架：对称 / 非对称 / 明显 三大类。黑白块 = 换装的位置+样式+数量，先分类再定位考点。

黑白

黑白块总框架：三大类怎么分？

▶
  • 对称类：图形整体明显对称 → 先识别对称类型，再细化对称轴。
  • 非对称类：看不出对称 → 位置移动 / 黑白运算 / 部分数（三大高频考法）。
  • 明显类：有明显特征（黑块占一半、连成线、分堆、黑块多且密）→ 图形关系 / 面积占比 / 相邻比较 / 笔画周长。
记忆钩子：先看对不对称，再问数量变不变（变→运算；不变→平移），都不行走「明显特征」路线。
例题 · 黑白块三大类一眼认

题干：下面三个黑白块图形分别属于「对称 / 非对称 / 明显」三大类中的哪一类？

答案：① 对称类——黑块排成一列，整体明显轴对称（左右、上下都对称），先识别对称类型、再细化对称轴；② 非对称类——看不出对称，改问"黑块数量变不变"：数量变 → 黑白运算，数量不变 → 平移；③ 明显类——黑块连成一条斜线，属于"明显特征"，直接数笔画 / 看面积占比。

例题 · 非对称类三选一怎么定

题干：下面三组都是"非对称类"黑白块（图1 → 图2），请分别说出该用哪种考法（位置移动 / 黑白运算 / 部分数）。

答案：① 黑块数量相同（都是 2 个）、轮廓相同 → 位置移动（平移）：盯住任意一个黑块，看它每步走几格；② 黑块数量由 3 个变成 4 个、轮廓相同 → 黑白运算：在相同位置逐格推规则；③ 黑块从"连成一片"变成"分成两堆" → 部分数：数黑色部分数和白色部分数，还可能考部分数运算。

黑白

对称类：怎么细化？

▶
  • 先识别：轴对称 / 中心对称 / 轴+中心。
  • 再细化：对称轴数量、方向；对称轴是否切割黑白块（左右/上下黑白分布是否一致）。
  • 黑块排列成等腰 → 对称规律别忘记；黑块不行看白块，白块也是重要的。
口诀：黑块排列成等腰，对称规律别忘记；黑块不行看白块，白块也是重要的。
黑白

非对称类：三选一怎么定？

▶
  • 位置移动：黑块数量相同 → 平移（内外分开看、斜向移动、非常规移动路径）。
  • 黑白运算：黑块数量不同、轮廓相同 → 推导运算规则。
  • 部分数：黑球分堆 / 黑块连成片 → 数黑色部分数、白色部分数，甚至部分数运算（黑-白、黑÷白）与个数变化（每部分的小块数）。
口诀：黑球分堆图中现，部分数量来考虑；黑球白球都重要，实在不行做运算。
黑白

明显类：还有什么花活？

▶
  • 面积占比：黑块占整体一半 / 1/4 / 网格面积比较（黑块被分割有网格 → 看面积）。
  • 相邻比较：两图之间只有 1~2 处不同 → 逐对比。
  • 笔画 / 周长：所有黑块连成线 → 数笔画；黑块周长 10 / 12 分组。
  • 图形间关系：黑面与白面相交线数量、黑面与白面个数、黑面与外框的关系。
口诀：所有黑块连成线，笔画数量是考点；黑块图中占一半，先看黑块的面积；黑块形状较丰富，黑块种类数一数。

空间重构：六面体 + 四面体

0/6

核心心法：所有方法都是排除法；技巧不是越多越好，越熟越好。最推荐组合：箭头法（主）+ 公共边（辅）。

空间

六面体解题「三步走」是什么？

▶
第一步：出现相对面 → 直接排除
第二步：有唯一边或唯一点 → 优先箭头法（备选画边法）
第三步：无唯一边/点 → 2个面近、1个面远 → 公共边；3个面都近 → 公共点
  • 六面体四个基础模型：1-4-1、2-3-1、3-3、2-2。
空间

相对面：两条识别口诀？

▶
  • 同行或同列，相隔一个面（中间隔1个 / 隔1列都是相对面）。
  • Z字形两端（紧邻 Z 字中线的两个面）。
  • 相对面不能同时被看见 → 用于快速排除选项。
口诀：中间隔1个，或隔1列，都是相对面。
空间

箭头法：口诀 + 操作步骤？

▶
口诀：找唯一，定方向
  • 结合选项，找一个唯一点或唯一边作为参照物，画出箭头方向。
  • 唯一点：图形中独特的点；唯一边：公共边即唯一边；升级版 → 双箭头（解决「都在右边忽略细节」问题）。
  • 技巧：把试卷/讲义转过来，让箭头正上方，更好对比；优先看直接靠一起的、位置居中的面（好观察）。
  • 能区分：上下左右大致方位；缺陷：无直接相邻需移动（用公共边补）。
空间

公共边：快速记忆三条？

▶
  • ① 构成直角的两条边，折合后是同一条边。
  • ② 一列/行连着 4 个面，两端是同一条边。
  • ③ 「直角边」随便「滚」（1-4-1 结构中，上下两个面沿一排面滚动）。
  • 优点：公共边周边图案区分快；缺点：一样的图案左右易混淆（配箭头法解决）。
公共边 = 两个图形共同拥有的边。多个立方体组合时：公共边两边颜色保持一致。
空间

公共点 & 画边法：什么时候用？

▶
  • 公共点：相邻三个面的公共点是唯一的；折叠前后，公共点引出的线/图形保持不变。用于「无唯一 + 三面近」的情形。
  • 画边法：找唯一点/唯一边 → 顺时针描边标号（描同一个面）→ 题干与选项对应面不一致即排除。
  • 画边法关键：同一个面、同一个点、同一方向（或同边同方向）；缺点：偏慢，用来查方向细节。
空间

四面体 + 特殊题型怎么办？

▶
  • 四面体流程：有唯一边/点 → 箭头法（备选画边法）；无唯一 → 公共边。
  • 四面体公共边两条规则：①展开图中构成一条直线的两条边折合后是同一条边；②平行四边形两端的两条边是同一条边。
  • 6个面都一样 → 找「特殊关系」（特殊图形/特殊线）。
  • 同一立方体不同视角 → 位置关系不变，箭头法+公共边，代入选项。
  • 组合展开图（4部分拼成）→ 找「唯一」；判断相对面 → 斜线/特征线与目标面相邻且出现多次。
  • ⚠️ 极端情况：无限接近外表面 → 不考虑。
核心秘密：箭头法熟悉后 = 你有了「想象力」。
🧊
找唯一，定方向（箭头法）/ 相对面：同行同列隔一个、Z字两端 / 公共边：直角两条、四连两端、直角边随便滚

空间：三视图与截面

0/5

补自刘义恒 91 页笔记第七节（P56）。这里是三视图的判定、画线规则与截面的高频考法，原页面此前缺失。

三视图

三视图指的是什么？怎么与「视图」区分？

▶
  • 主视图：从正面看　｜　俯视图：从头顶向下看　｜　左视图：从左侧看。
  • 三视图 vs 视图：三视图只指主视、俯视、左视这三个固定方向；视图则是任意角度看。题目问「三视图」时，就锁定这三个方向。
📌 题型判定：① 给出立体图形，问"符合的俯视图/左视图是哪一项"；② 给一组视图，问"选哪项填入问号处使其呈现规律"。
三视图

画三视图的 4 个注意点是什么？（最易错）

▶
  • (1) 观察到的三视图都是平面图。
  • (2) 原图有线，选项不一定有线；原图没线，选项一定没线。（判断要不要画线时先回到原图找依据）
  • (3) 当被遮挡住时，看不见的被遮挡部分 —— 虚线表示「能看见的边被挡」／不画线表示「本来就看不见」。
  • (4) 曲面会变成直线图。
⚠️ 核心口诀：原图没线 → 选项一定没线。这一条能直接排除一批选项。
截面

截面题有哪两条高频结论？

▶
  • 正方体截面：可以截出三角形（锐角三角形）、四边形（矩形/梯形/平行四边形）、五边形、正六边形（过六条棱的中点）；截不出直角三角形和钝角三角形。
  • 圆柱截面：横切 → 圆；斜切（不过底面）→ 椭圆；竖切 → 矩形。
📌 做截面题先想「刀怎么下」：横着切、竖着切、斜着切，各能得到什么形状。
三视图

三视图与立体图形的「转换思维」怎么用？

▶
  • 做法：把视图还原成平面网格（每格代表一个"高/宽"单位），再把网格与选项的立体图形逐个比对。
  • 技巧：先数方块的层数 / 个数，用"数字网格"确定每处高度，再验证哪一项能拼出这个网格。
📌 立体拼合与三视图常连考：先转成平面图，把三维问题降成二维计数问题，正确率会明显提升。
三视图

做三视图题的「答题思路」是什么？

▶
核心一句话：外部轮廓定方向，内部线条定选项。
  • 第一步：看外部轮廓 —— 先根据俯视/左视的外轮廓锁定方向（这一步能干掉一批明显不符的选项）。
  • 第二步：看内部线条 —— 再用内部线条的有无、位置在剩余选项里定选。
  • 找不到特殊图形时：看线条是否平行、是否被遮挡（遮挡处不画线）。
  • 图形较乱时：直接对比选项差异，再回题干验证。
📌 真题经验（25 广东）：判断俯视图时，逐条线问自己「这条线俯视能看见吗」，能看见才画。
📐
三视图 = 主视 · 俯视 · 左视（固定三向）；原图没线选项一定没线；正方体截不出直角/钝角三角形

立体拼合 & 选修场景

0/8

补自刘义恒 91 页笔记第八节（空间：立体拼合）与第十节（立体空间：不规则、平面拼合、折纸）。后者属选修内容，部分省份已升温，值得了解。

立体拼合

「看选项，选方法」的速记口诀是什么？

▶
速记口诀：① 个数　② 层数　③ 特殊
  • 1. 选项个数有差别 → 优先考虑「数个数」。打算猜也可以数个数；打算做，先不数（时间留给更稳的方法）。选项里 3 个一致 → 尽量不数。
  • 2. 选项分层明显或每层个数不一样 → 优先考虑「分层拼 / 分层数」。数层数性价比最高；每层个数一致的选项，正确可能性更高。数每层个数时，优先考虑不旋转的情况。
  • 3. 考虑「找特殊」：即找题干中最大或最抽象（不规则）的方块优先代入。题干中越大或越抽象的方块，位置的局限性越大。
立体拼合

例题：怎么从「分层数」快速选出答案？

▶
  • 题干要求"能与左侧图形组合成立方体" → 先看选项是否分层明显（是 → 用分层数）。
  • 把题干图形转换成平面图（标出每格的层数），再与各选项逐层相加，凑成完整立方体。
📌 思想：选项分层明显或每层个数不一样 → 优先考虑分层拼 / 分层数。
选修

不规则图形：最实用的排除技巧是什么？

▶
① 选项找差异，公共边做排除（公共边长度相等）
  • 口诀：选项找差异 —— 先比选项之间的不同，再看这些不同点在题干里能不能成立。
  • 公共边长度必须相等；长度不等的直接排除。这条在"不规则展开图"里几乎必用。
② 题干找特殊（最大的、标记物），看周边
  • 找题干里最大的面或带标记的部分，重点看它周围有几个面、都是什么面。
  • 示例：某题干最大面周围应出现三个灰面；选项里哪个能对上就用哪个。
  • 另一类：最大的面右端应是白色长方形面 → 直接排除不符项。
平面拼合

「只有白色面」的平面拼合：原理与解法？

▶
  • 出题者怎么画：画一个图之后，先复制粘贴，再切割 → 所以每块碎片其实来自同一个图形。
  • 基本原则：图形只能上、下、左、右平移，不能旋转、翻转。
  • 解密三步：① 找特殊线条（唯一的长线或横竖线）② 找等长的线 ③ 必要时拆分选项。
📌 核心思路：既然碎片是「复制后切割」出来的，就一定能拼回原图 —— 所以盯住特有的边和角即可。
平面拼合

「黑白面」的平面拼合：为什么能旋转翻转？

▶
  • 出题者怎么出：给四张纸片，每张纸片一面黑色、一面白色（翻过来颜色就变）。
  • 基本原则：可以平移、旋转、翻转（与"只有白色面"不同！）
  • 解密关键：旋转 → 颜色一致；翻转 → 颜色变化 —— 本质就是区分旋转和翻转。
⚠️ 对比记忆：
只有白色面 → 只能平移，不能旋转翻转
黑白面 → 可以平移、旋转、翻转（靠颜色变化判断是否翻转）

折纸（折叠）类怎么做？

  • 技巧：先找唯一的长边或角定位，再逐条验证相邻关系；必要时对比选项差异反推。

立体拼合

技巧性：为什么「优先考虑不旋转」？

▶
  • 优先考虑不旋转的情况：多数题目图形只平移、不旋转，先按不旋转验证，能省大量时间。
  • 数层数时：每层个数不一样 → 数层数性价比最高。
  • 合理凑数：优先代入局限性大的那一块（越大或越不规则，可放的位置越少）。
📌 例题：左边立方体由①②③组成，求问号块 —— 每层个数不一样 → 数层数，逐层相加凑齐。
立体拼合

「找最大或最抽象的方块」具体怎么做？

▶
  • 做法：把题干图形用铅笔涂黑分层 → 找出最大或最抽象的那一块 → 优先代入验证。
  • 为什么：越大或越抽象的方块，位置局限性越大，可放的位置少，试错成本低。
  • 必要时再考虑旋转（旋转后仍要满足层数一致）。
📌 出题者提示：①②③ 中优先代入「找最大的②」，能快速排除选项。
🧩
立体拼合：看选项选方法 —— ①个数 ②层数 ③特殊；不规则：选项找差异，公共边做排除

选修一：平面图推思维导图串讲

0/3

补自刘义恒 91 页笔记选修第一节（P75–P85） —— 用思维导图把前六节的平面考点串成一张网，适合二轮复习时快速过一遍。

串讲

平面图推怎么「一张图串起来」？

▶
串讲主线：先看"像不像"→ 再按 6 大规律逐层排查
  • 有相同 → 位置规律（平移 / 相邻比较 / 旋转翻转）、样式规律（加减同异 / 黑白运算）、标记
  • 无相同 → 属性规律（对称 / 曲直 / 开闭）→ 数量规律（面线点角素笔画）→ 图形间关系
  • 串讲的作用：把分散的考点按"看到什么特征 → 想哪个考点"重新连起来，形成条件反射。
串讲

串讲里的高频易错点有哪些？

▶
  • 考点会混：位置（都一样）vs 样式（部分一样）—— 先数"图形是否完全相同"再定方向。
  • 数量规律要按顺序试：面 → 线 → 点 → 角 → 素 → 笔画，别跳着试。
  • 属性优先于数量：图形规整美观先想对称；极端特殊优先想图形间关系。
串讲

二轮复习怎么用它？

▶
  • 先不看答案把思维导图默写一遍（考点名称 + 判定特征）。
  • 默写不出来的地方，回到对应章节重看卡片。
  • 配合"考点 → 特征"反向记忆：看到什么图形特征，就该想到哪个考点。
🕸️
有相同：位置·样式·标记；无相同：属性→数量→图形间关系。二轮用思维导图默写复盘

▶

考场实战策略

0/3

把知识变成分数，靠的是解题顺序和节奏。

实战

万能破题顺序是什么？

▶
看元素组成 → 相同看位置；相似看样式；不同 → 先属性（对称→曲直→开闭）再数量（面线点角素笔画），最后图形间关系
  • 特征图优先：对称图→对称；线条交叉→点；窟窿多→面；五角星日字田字→笔画。
  • 简单规律不行 → 考虑复合考点（对称+曲直、数量+属性、位置+样式）。
  • 空间重构：用排除法，不硬想。
实战

四大高频易错点

▶
① 一笔画奇点判定：端点也是奇点，别漏；奇点必成对。
② 对称轴考法：数量 + 方向 + 是否与线条重合/垂直，全都要看。
③ 黑白叠加运算：规则现场推，第一组推、第二组验证、第三组应用。
④ 内外平移：内外层分开移动，别整体看。
实战

时间管理：30 秒原则

▶
  • 30 秒没思路立刻跳过，做完其他模块再回头看 —— 图推切忌死磕。
  • 遇到难题：先排除明显错的选项（相对面、明显不对的），提升蒙对概率。
  • 图推没有玄学只有规律，规律用熟了 80% 以上的题都能拿下。
考前提醒：熟记特征图 + 口诀，比刷更多题更重要。
⚡
像→位置样式标记；不像→属性数量关系；规整→对称；交叉→点；窟窿→面；五角星日田→笔画；30秒无解→跳过
