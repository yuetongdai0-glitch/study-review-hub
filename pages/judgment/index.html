总纲 · 两个要求，一个核心词

THE GOLDEN RULES
这是程意逻辑判断的第一节课内容，是整套必然性推理的底层操作系统——解决「生活与逻辑相混淆」的问题。

要求一 · 严谨性

说什么是什么，没说不知道。

  • 题干没说的，一律当作不知道，不脑补、不联想生活经验。
  • 例：「如果你上岸了，我就给你买辆法拉利」——只说明「上岸→买法拉利」，没说上岸后买什么颜色、没说没上岸会怎样。
  • 例：「程意是会跑的动物，所有会跑的动物是妖怪」→ 虽然荒诞，但只要形式正确，推出的「程意是妖怪」在逻辑上成立。

要求二 · 形式性

关注形式，只要符合推理规则，推出来的就是对的。

  • 逻辑只研究推理形式，不研究内容真伪。
  • 例：A是B，所有B是C → 则A是C。形式对就对，内容多荒诞都成立。
  • 做题时把题干「翻译成符号」，只在符号层面推理，摆脱生活直觉干扰。

核心词 · 有些（= 至少有一个）

  • 逻辑学中「有些」= 至少有一个，数量不限定，1 个也叫有些，全部也是「有些」（含于其中）。
  • 「有些是」为真，「有些非」的真假不确定；反之亦然——两者是下反对关系，可以同真，不能同假。
  • 例：题干「有些同学考上了」为真，不能推出「有些同学没考上」，也不能推出「所有同学都考上了」。
✏️ 记忆
「凡、都」都是「所有」的意思;「至少有一个」是「有些」的意思。「有些」很狡猾:知道「有些是」真,别的都不确定。
例 · 核心词「有些」
已知「有的同学通过了考试」为真。据此,以下哪项一定为假?
A. 所有同学都通过了考试　B. 张同学通过了考试　C. 所有同学都没通过考试　D. 李同学没通过考试
思路(程意式):「有些是」为真 → 只知道至少有一个通过,其余都不确定。一定为假 = 找矛盾:「有些是」的矛盾是「所有非」→ 选 C。A、B、D 都是「不确定真假」,不能选。

模块一 · 必然性推理（逻辑判断）

NECESSARY REASONING
特点：侧重知识点的记忆、识别、使用；难易度中等，个别内容偏上。学会了用熟了，正确率和速度都能明显提升。通用流程：识别题型 → 翻译符号 → 套用规则 → 选出答案。

1.1 直言命题（第 1 次课）

含义：直言命题就是含有一个断定的语句，类似汉语的单句。如「所有中国运动员都赢得了奖牌」。

六种分类（量项 × 联项）

量项联项形式示例
所有（全称）是所有A是B所有学生都是党员
非所有A非B所有学生都不是党员
有些（特称）是有些A是B有些学生是党员
非有些A非B有些学生不是党员
某个（单称）是某个A是B张三（这个学生）是党员
非某个A非B张三（这个学生）不是党员

注意「凡、都」都是「所有」的意思；「至少有一个」是「有些」的意思。

矛盾关系（重点）

矛盾关系 = 针对相同事物的两个命题永远满足一真一假。

  • 找矛盾方式一：加「并非」（了解即可，考得少）。
  • 找矛盾方式二：变形式——「所有 ↔ 有些」「是 ↔ 非」互换，「某个」不变。
原命题矛盾命题
所有A是B有些A非B
所有A非B有些A是B
某个A是B某个A非B

对当关系（补充：上反对 / 下反对 / 从属）

关系双方性质
矛盾所有是 ↔ 有些非；所有非 ↔ 有些是；某个是 ↔ 某个非一真一假，必有一真一假
上反对所有是 ↔ 所有非不能同真，可以同假
下反对有些是 ↔ 有些非可以同真，不能同假
从属所有是 → 某个是 → 有些是；所有非 → 某个非 → 有些非全称真则单称/特称真；特称假则单称/全称假
例 · 直言矛盾应用（知真求假）
「有的运动员竞技状态不好。」根据上述断定为真，以下断定可以确定为假的是：
A. 有的运动员竞技状态好　B. 运动员甲竞技状态好　C. 所有运动员竞技状态都不好　D. 所有运动员竞技状态都好
思路（程意式）：知真求假 → 直接找矛盾。「有些A非B」的矛盾是「所有A是B」→ 选 D。注意 A、B、C 都是「不确定真假」，不能选。
1
真假话问题四步走（找矛盾 → 定位置 → 变假为真 → 筛选答案）：① 在题干几句话里找矛盾关系，确定真话/假话必在其中；② 由题目给的真话/假话数量，推出其余句子的真假；③ 把假的变真（取其矛盾/反面）；④ 代入选项选出答案。
例 · 真假话问题（四步走）
某次税务检查后，四个工商管理人员有如下结论：
甲说：所有个体户都没纳税。　乙说：服装个体户陈老板没纳税。
丙说：个体户不都没纳税。　丁说：有的个体户没纳税。
如果四人中只有一人断定属实，则以下哪项为真？
思路（程意四步走）：① 找矛盾：甲「所有个体户都没纳税」（所有非）与丙「个体户不都没纳税」=「有些个体户纳税了」（有些是）是矛盾关系，真话必在甲、丙之间；② 定位置：只有一真 → 乙、丁必假；③ 变假为真：丁假 →「有的个体户没纳税」为假 → 其矛盾「所有个体户都纳税了」为真；④ 筛选答案：所有人都纳税 → 陈老板纳税、甲假、丙真。答案选「个体户陈老板纳税了」。

1.2 联言命题：p 且 q（第 2 次课）

含义：断定多种情况同时为真的命题，表达为 p 且 q。

提示信息（识别）

类型连接词例句
并列词且、和、与、既……又……小李学了资料和判断
递进词而且小李不但上课认真听讲，而且下课做作业
转折词但是、然而、却虽然学习很辛苦，但一定会有收获

真假性：全真才真，有假则假

p（米饭）q（馒头）p 且 q
✓✓✓
✓✗✗
✗✓✗
✗✗✗

推理规则

  • 已知 p 且 q 为真 → p 真，q 真（分解）。
  • 已知 p 且 q 为假 → 肯一推否一：补充「p 真」可推出「q 假」；补充「q 真」可推出「p 假」。

矛盾命题（知真求假 / 知假求真直接找它）

p 且 q 的矛盾 = 非p 或 非q
例 · 推理规则
「小王是足球明星并且小李是网球明星。」如果上述判断为假，并且小李确实是网球明星，则以下哪项为真？
思路：p 且 q 为假 + q 真 → 肯一推否一 → p 假，即「小王不是足球明星」。
例 · 联言矛盾（知假求真）
「小王既会唱歌又会跳舞」这一判断为假。据此，以下哪项一定为真？
思路：p 且 q 为假 → 找矛盾「非p 或 非q」→ 一定为真的是「小王不会唱歌 或 不会跳舞」。注意：不能推出「小王一定不会唱歌」或「一定不会跳舞」，只能推出「至少有一个不会」。
✏️ 口诀
联言「且」：全真才真，有假则假；整体为假，肯一推否一；找矛盾：且变或、各加非。

1.3 选言命题：p 或 q（第 2 次课）

（一）相容选言命题（重点）

  • 含义：断定多种情况至少有一真，可以同真，表达为 p 或 q。
  • 提示信息：……或……；或者……或者……；至少有一种。
p（米饭）q（馒头）p 或 q
✓✓✓
✓✗✓
✗✓✓
✗✗✗
  • 已知 p、q 独立情况 → 整体：有真则真，全假才假。
  • 已知 p 或 q 整体为真 → p、q：否一推肯一（否定一个能推出另一个真，即「或」命题否定一个支命题，可以推出另一个支命题成立）。
p 或 q 的矛盾 = 非p 且 非q　　等价转换：p 或 q = 非p → q = 非q → p

（二）不相容选言命题（低频，了解即可）

  • 要么 p，要么 q：有且只有一个真。
  • 矛盾：要么 p 且 q，要么非p 且非q。
例 · 相容选言推理（否一推肯一）
已知「小明去 或 小红去参加志愿活动」为真，且小明不去。由此可以推出：
思路：p 或 q 整体为真 + 否定 p → 否一推肯一 → q 真，即小红一定去。若题干把「或」换成「要么……要么……」（不相容），结论相同也是小红去，但推理依据是「有且只有一个真」。
✏️ 口诀
选言「或」：有真则真，全假才假；整体为真，否一推肯一；找矛盾：或变且、各加非。要么A要么B：一真一假；同真同假才是矛盾。

1.4 假言命题（第 2 次课 · 重中之重）

翻译推理是整套逻辑的地基，后面的综合推理、朴素逻辑全都要用到。核心就两步：先翻译，后推理。

第一步 · 翻译（背熟对应关系）

关联词翻译口诀
如果A，那么B；只要A，就B；A是B的充分条件A → B如果就，前推后
只有A，才B；除非A，否则不B；A是B的必要条件B → A只有才，后推前
除非A，否则B非A → B除非否则，否前推后
A当且仅当BA ↔ B充要互推
✏️ 翻译口诀
「如果就，前推后；只有才，后推前；除非否则不，后推前；除非否则，否前推后；充分必要别搞混，充前必后记心间。」

第二步 · 推理（三大规则）

① 逆否等价：A → B = 非B → 非A（王道规则）
② 递推：A → B，B → C，可得 A → C
③ 有效形式：肯前必肯后，否后必否前；否前、肯后推不出确定性结论
例 · 逆否等价
古人云：「不到长城非好汉。」以下哪项与古人表达的意思一致？
① 到了长城的人就一定是好汉　② 如果是好汉，他一定到过长城　③ 只有好汉，才到过长城
思路：翻译：「非长城 → 非好汉」。逆否等价 → 「好汉 → 长城」，即②。①③都翻译成「长城 → 好汉」，错了。选②。

矛盾与等价（连接命题部分的关键）

A → B 的矛盾 = A 且 非B（最强否定，反驳它直接找这个）
A → B 等价于 非A 或 B（「或」与「推」互转，为综合推理奠基）
例 · 假言矛盾（知假求真）
「如果明天下雨，那么运动会取消」为假。据此可以推出：
思路：A → B 的矛盾 = A 且 非B → 推出「明天下雨 且 运动会没有取消」。注意别选「明天不下雨」——那是「否前」，从假言为假推不出。

知真求假 / 知假求真类：直接找矛盾（汇总）

命题矛盾命题
联言：p 且 q非p 或 非q
相容选言：p 或 q非p 且 非q
不相容选言：要么p，要么q要么p且q，要么非p且非q
假言：p → qp 且 非q
✏️ 口诀
「逆否等价是王道，否后必否前牢牢记」；「真假判断看矛盾，A且非B一招毙」；「或且转化德摩根，去括号时分负号」。德摩根：非(A且B) = 非A或非B；非(A或B) = 非A且非B。

1.5 综合推理（第 3 次课 · 母题三、四、五）

识别：题干涉及假言（→），问法「知真求真」，选项多为事实判断。核心思想：母题三到母题五的思路是递进的——先用确定性，再数量限定，最后假设法、二难推理。

母题三：有确定信息 → 从确定信息破题

1
找到题干中确定的事实信息（直接给的事实/算出的事实），把它作为推理起点。
2
沿着与该信息相关的条件依次推理（找相关：跟它出现在同一条假言里的内容）。
3
注意题目是推结论（13-15 题式）还是推前提（16 题式），别推反方向。

母题四：有数量限定 → 通过数量限定破题

1
题干出现数量限定（如「最多X个」「至少Y个」）→ 先把数量算出来，可直接得到部分选项。
2
把算出的数量当作确定信息，代入假言命题作「肯前」或「否后」触发推理。

母题五：确定信息、数量限定都用不上 → 假设法 + 二难推理

1
假设起点：优先假设「前真（后假）」，即假设 A→B 中的 A 为真（或 B 为假）。
2
推演找冲突：①看单条假言内部是否有冲突；②把多条假言「串串」找冲突。
3
冲突点常考：(1) 与题干已有信息冲突（尤其数量限定）；(2) 推出相冲突的信息。
二难推理：A → B；非A → B 　⇒　 B 恒真
例 · 二难推理
某教授说：「如果你们按时完成作业，我就给你们加平时分；如果你们没有按时完成作业，我也给你们加平时分。」由此可以推出：
思路（程意式）：翻译：按时 → 加分；非按时 → 加分。无论「按时」还是「非按时」总有一个成立，而两者都能推出「加分」→ 教授一定会给你们加平时分（B 恒真）。这就是「非黑即白，殊途同归」的二难推理。
例 · 综合推理（2024 广东）
如果某地不禁止在鱼类繁衍季节捕鱼，当地的鱼类资源就会枯竭。如果鱼类资源枯竭了，当地渔民的渔业生涯就会终结。只有鱼类资源良性循环，渔民的收入才能得到保障。由此可以推出：
思路：翻译：① 非禁止 → 枯竭；② 枯竭 → 生涯终结；③ 收入保障 → 良性循环。选项 C「渔业生涯没有终结 → 当地一定禁止在鱼类繁衍季节捕鱼」= ②逆否（非生涯终结 → 非枯竭）+ ①逆否（非枯竭 → 禁止），正确。其余选项都是「肯后/否前」的错误形式。
⚠️ 易错点
  • 肯后推不出：如「收入得到保障 → 资源良性循环」是③的肯后，推不出。
  • 否前推不出：「禁止捕鱼 → 收入有保障」是①的否前，推不出。
  • 综合推理先整体翻译，再按「确定信息 → 数量限定 → 假设法/二难」顺序找破题口。

1.6 三段论（第 4 次课）

定义：由包含着一个共同项的两个性质判断为前提，推出一个新的性质判断为结论的推理形式。

所有A是B，所有B是C 　⇒　 所有A是C
  • 结构：大项 P（结论中的谓项）、中项 M（前提中出现、结论中不出现，起桥梁作用）、小项 S（结论中的主项）。
  • 秒杀核心：找中项 B——B 是连接 A 和 C 的桥梁，在前提中出现两次，与「所有」相连。

三段论规则（违反即错）

规则内容
① 三个概念一个三段论中只能有三个不同的项（防偷换概念）
② 中项周延中项在前提中至少周延一次
③ 不周延不扩大前提中不周延的项，在结论中也不得周延
④ 否定前提两个否定前提不能得出结论
⑤ 否定与结论前提中有一个否定，结论必否定；前提都肯定，结论必肯定
✏️ 口诀
「所有」和「否定」是周延的；「有的」和「肯定」是不周延的。画图法：用集合关系（圆圈）验证，快速排除。
例 · 三段论补前提（找中项）
有些导演留大胡子，因此，有些留大胡子的人是大嗓门。要使上述推理成立，必须补充以下哪项作为前提？
思路（程意秒杀）：中项是「导演」（前提出现、结论不出现）。结论「有些留大胡子的人是大嗓门」= 有些B是C；已知前提「有些导演留大胡子」= 有些A是B → 缺的是「所有A是C」即「所有导演都是大嗓门」。口诀验证：中项「导演」要在前提中周延一次，只能由「所有」提供。

1.7 朴素逻辑（第 5 次课 · 解题思路及秒杀技巧）

总思路：先判断有序型（排序/位置）还是无序型（分组/对应），突破口永远两个词：确定性、关联性。

（一）题型与突破口

类型突破口说明
有序型（排序）占位多的条件（注意平铺与交叉）被提及最多的元素先放
有序型（排序）捆绑元素「A紧挨B」整体处理
有序型（排序）相对先后顺序「A在B前」画箭头、标区间
无序型（分组）二选一原则条件只给两种可能时，分情况讨论
无序型（分组）占位不定位只确定在某组，不急着定具体位置
通用确定性 + 关联性先找最确定的，再找关联最多的

（二）秒杀技巧（程意课堂重点）

⚡ 技巧 1 · 数独题型
解题思路：① 排除；② 从行、列、交集最多的格子入手。
⚡ 技巧 2 · 3+2 分组
从 2 个角度把人分成 3+2：相同归大，去排除。
⚡ 技巧 3 · 4人中 4+3+2
① 找 3 人条件中被孤立的那个人；② 找他在 2 人条件中的伙伴。
⚡ 技巧 4 · 问最多、最少
最多：两个分类做加和。最少：两个分类选数大的。注意：去除包含的数量。
⚡ 技巧 5 · 不等式推理
A>B；C>D。AB 是矛盾的，CD 是矛盾的。只可得 AC > BD（取各自较大/较小组合比较）。
例 · 最多最少
某单位有 30 名党员，其中 18 人参加了党课培训，15 人参加了业务竞赛。问：两项都参加的最多有多少人？最少有多少人？
思路（程意口诀）：最多 = 两个分类取小者 = 15 人（≤15 那个）。最少 = 两个分类加和减总数 = 18 + 15 − 30 = 3 人。（「选数大的」指两类人数中较小的重叠上限；本质用容斥原理：两项都参加 ≤ min(18,15)=15；最少 = 18+15−30=3。）
例 · 确定性 + 关联性（职业对应）
甲、乙、丙三人中，一人是律师，一人是教师，一人是医生。已知：① 甲比医生的年龄大；② 教师比乙的年龄小；③ 丙和教师不同岁。问：三人各是什么职业？
思路（程意式）：突破口 = 确定性 + 关联性。②「教师比乙小」→ 乙不是教师；③「丙和教师不同岁」→ 丙不是教师 → 剩下的甲一定是教师。再由②：教师（甲）比乙小，即甲比乙小；① 甲比医生大 → 甲比医生大又比乙小 → 乙不是医生 → 乙是律师，丙是医生。推理链条：先确定唯一位置（教师），再顺藤摸瓜。

1.8 一拖N（第 6 次课）

介绍：一般由一个题干 + 多个小题组成，题干整体类似朴素逻辑。用时目标：一拖二 2-3 分钟（保 3 争 4）；一拖五 5 分钟（7-8 分钟内，保 4 争 5）。

第一步 · 分析题干信息（一拖五约 1-2 分钟）

1
分析背景：明确题干属于有序型还是无序型（分组型），有几类元素、每类几种。
2
题干信息整合：突破口 = 确定性、关联性。排序中注意：占位多的条件、捆绑元素、相对先后顺序、间隔占位信息、数量限制。
3
符号表达：形成自己的符号系统（见下），把文字翻译成符号。
符号含义
ABA 在 B 左，且紧挨着
A BA 在 B 左边，不确定是否紧挨
A□BA 在 B 左，且 AB 之间有一个东西
⇄位置可互换（箭头）

第二步 · 解题与代入判断

  • 通过整合题干得到的信息，可用于所有题目（一拖N的第一价值）。
  • 有补充条件：从补充条件入手，结合已知条件推理，推完排除选项，不行再代入。
  • 通过问法判断是否适合代入：
    问法处理
    可能为真可以代入：代入选项，若能满足题目所有已知信息，可选
    不可能真可以代入：代入选项，若与题干已知确定信息冲突，可选
    一定为真 / 可以推出建议正推，不适合代入；如必须代入，注意是「一定真」还是「可能真」

秒解技巧 & 蒙猜技巧

⚡ 秒解

  • 关注选项信息异同：选项全面的（直接列出完整安排），直接排除/验证。
  • 最后 2 个题可能直接运用之前题目的结论。
  • 代入时优先代入能结合已知信息推理的选项。
  • 排序题：前有 N 个人，则不能在前 N；后有 N 个人，则不能在后 N。

🎲 蒙猜（时间不够用）

  • 问「可能」→ 优先选含有「题干限制信息中未提及的元素」的选项。
  • 问「不可能」→ 排除出现「同质元素」的选项。
  • 问 A 和 B 最多隔几排 → 优先验证选项中的最大数字。
  • 问 A 和 B 最少隔几排 → 优先验证选项中的最小数字。
例 · 排序型（2025 天津事业单位改编）
某边防哨卡每日必须有士兵站岗，每天从 A、B、C、D、E、F、G 七位士兵中选择一位站岗，每位士兵每周只站岗一次。已知：① B 必须在周二，E 必须在周四；② A 在 D 前面站岗，且中间恰好隔一位；③ F 和 G 在相邻两天站岗。问：C 排在周一，则以下哪项一定为真？
思路（程意式）：有补充条件（C 周一）→ 从补充条件入手。画 1-7 位置：周一C，周二B，周四E；A□D 占位 + F、G 相邻 → 逐步排除，推出结论。
例 · 代入判断（可能为真）
某次会议有 5 位代表，分别来自浙江、江苏、山东、广东、四川。已知：① 浙江代表不在第 1 位；② 江苏和山东代表相邻；③ 广东代表在四川代表之前且中间恰好隔一位。问：以下哪项可能是五位代表的正确顺序？
A. 浙江 江苏 山东 广东 四川　B. 山东 江苏 广东 四川 浙江　C. 四川 广东 江苏 山东 浙江
思路（程意式）：问「可能为真」→ 直接代入验证。A：浙在第 1 位，违反① ✗；B：苏鲁相邻 ✓、粤川中间隔一位 ✓、浙不在第 1 ✓ → 选 B；C：粤在川前但紧挨（没隔一位），违反③ ✗。注意「可能为真」只找一个能满足所有条件的即可，不必是唯一排列。

模块二 · 可能性推理（加强削弱）

POSSIBLE REASONING
特点：不考公式记忆，考「读题 → 理结构 → 预设答案 → 比选项」。基础能力（第7课）→ 因果类（第8课）→ 论证模型秒杀（第9课）→ 前提/解释/结论/评价（第10课）。

2.1 加强削弱 · 基础能力（第 7 次课）

标准化流程：读问题 → 理结构 → 预设思路

1
读问题，辨题型：是加强还是削弱？是「最能加强/削弱」还是「不能加强/削弱」？看清再动笔。
2
理清题干结构：找出结论（标注 ☆）和论据。问自己：论据是什么？结论是什么？中间缺了什么？
3
预设思路：先想「正确选项大概长什么样」——加强/削弱的力度从强到弱排好，再去选项里找对应表达。

常见迷惑选项（看见先警惕，往往不选）

🚫 与题干论证无关型

  • 对象不一致：偷换讨论对象/范围
  • 概念不一致：偷换核心概念
  • 时间不一致：时间点/段对不上
  • 选项与不相关事物做比较
  • 题干有趋势，选项无趋势
  • 诉诸无知（注意：不是完全无关，但力度弱）：「尚不清楚」「无法证明」
  • 表述不明确：说得很模糊，无法判断影响方向

🚫 因果类设错（题干讨论因果关系时）

  • 选项只有因 或 只有果（不完整，不构成削弱）
  • 因果关系错位：把因说成果、果说成因方向不对
  • 因导致其他果：承认因存在但指向别的结果
  • 果的果：在结果上再叠结果
  • 因的因：在原因前再找原因（≠另有他因，小心区分）

力度比较（选答案时的优先序，要记住）

✏️ 力度排序
本质 > 现象；全面 > 片面；确定 > 可能；量大 > 量小（无需背，理解即可）。
✏️ 常见加强方法
解释因果、有因有果、无因无果（加强三件套）。
例 · 力度比较与迷惑选项
某调查发现，坚持长期喝茶的老人更长寿。研究者据此认为：喝茶能延年益寿。以下哪项最能削弱上述结论？
A. 有些从不喝茶的老人也很长寿　B. 目前尚无法证明喝茶与长寿之间存在因果关系　C. 喜欢喝茶的老人大多注重饮食健康、经济条件也较好　D. 茶中含有茶多酚等有益物质
思路（程意式）：结论「喝茶 → 长寿」，削弱依次比较：A 是反例（有因无果的反面），但样本个别、力度弱；B 是诉诸无知（「尚无法证明」），力度弱；C 提出「注重饮食健康」这一另有他因，从本质上解释长寿另有原因，力度最强，选 C；D 在加强。口诀：本质 > 现象，确定 > 可能。

2.2 因果类题型（第 8 次课）

因果论证两大类题干形式，对应两套处理思路：

形式一：题干给事实 A、B，推测 A、B 之间有因果关系

1
普适性思路：把题干调整为一个实验，看哪个选项能成为实验的「变量」。
2
简便方法：① 正确选项的「因」常体现为与题干已给的因同主体；② 当题干论据以「同时发生」形式出现时，选项补充的「因」还要与论据中的 2 件事同时间。

形式二：题干给事实 A，推测原因是 B

1
关注题干的「果」是什么。
2
直接给果找他因即可（另有他因）。
  • 另有他因通用标准：选项补充的「因」，要与题干的「果」有一定的关系。
  • 另有他因的要求：引入的因可能影响结果（例：小郑跑步+游泳→瘦，A「小郑还常游泳，游泳能瘦」✓；B「小郑还常游泳」（没说能瘦）✗；C「小郑每天背5个单词」✗）。

常见削弱方法（因果类，按力度排列）

方法含义说明
因果倒置颠倒因果关系/颠倒时序力度强，出现直接选
另有共因题干：A导致B；选项：C导致A和B力度强，出现直接选
有因无果 / 无因有果有因却无果；无因却有果注意：无果 = 果的反面，无因 = 因的反面
否定此因原因不成立 / 原因不起作用力度强，出现直接选；若论据已明确「因」是事实，别选「原因不成立」
另有他因引入新原因，证明可能不是题干原因导致结果最常考；引入的因要可能与结果相关
⚠️ 另有他因的两类题干
  • 给事实 A、B，推测 A、B 之间有因果（易出难题）：小郑跑步→瘦，小华不跑步→不瘦，推测跑步使人瘦。削弱 A：小郑还常游泳（同主体补他因）；B：游泳也能使人瘦（不同主体也能削弱，力度弱于同主体）。
  • 给事实 A，推测原因是 B：小郑瘦了，推测因为跑步。削弱：他最近节食/生病等。
例 · 因果倒置（力度最强，出现直接选）
某调查发现，经常使用社交媒体的青少年更容易焦虑。研究者据此认为：使用社交媒体导致了青少年焦虑。以下哪项最能削弱上述结论？
A. 感到焦虑的青少年更倾向于通过刷社交媒体来缓解情绪　B. 使用社交媒体时间较少的青少年中也有焦虑者　C. 社交媒体上也有大量积极向上的内容　D. 该调查的样本主要集中在城市
思路（程意式）：题干：社交媒体 → 焦虑。A 说其实是「焦虑 → 沉迷社交媒体」，把因和果颠倒了，是因果倒置，力度最强，直接选；B 是反例但样本个别；C 无关；D 质疑样本，力度弱。口诀：因果倒置、另有共因，出现直接选。

2.3 八大论证模型秒杀技巧（第 9 次课）

核心思想：判断出模型 → 答案就已经预判出来了。题干长相固定，答案形式固定。读完题干先判断模型，再按模型预判答案，最后到选项中找对应表达。

模型 1 · 求异论证

根据两组实验对象的差异，得出 A 是 B 的原因。

  • 加强：两组实验对象的相关相同点；解释因果
  • 削弱：两组实验对象的相关不同点

模型 2 · 双观点

原观点：A 是 B 的原因；反对者：C 是 B 的原因。

  • 削弱反对者：A 是 C 的原因
  • 削弱原观点：C 是 B 的原因（即支持反对者）

模型 3 · 实践论证

采取方案 A，达到目的 B。

  • 加强：方案 A 可实现；采取方案 A 能达到目的 B
  • 削弱：方案 A 不可实现；采取方案 A 也达不到目的 B

模型 4 · 类比论证

由两个对象相似，推出某结论。

  • 加强：找根本相同属性
  • 削弱：找根本不同属性

模型 5 · 枚举归纳

由部分样本推出整体结论。

  • 加强：样本具有代表性
  • 削弱：样本不具有代表性

模型 6 · 缺桥论证（搭桥/拆桥）

论据说 B，结论说 C，中间缺桥。

  • 加强：建立 B 和 C 之间的联系（搭桥）
  • 削弱：切断 B 和 C 之间的联系（拆桥）

模型 7 · 数据论证

论据往往包含数字（分子部分）。

  • 通过找到数字的分母部分（基数/总量），从而加强或削弱

模型 8 · 结论有比较

结论涉及比较关系（谁比谁强/多/快）。

  • 优先选有比较的选项（选项也在做同类比较才扣题）
例 · 求异论证（经典题）
某研究将两组小鼠置于相同环境，实验组喂高脂饲料、对照组喂普通饲料，结果实验组更易肥胖。结论：高脂饲料导致肥胖。以下哪项最能削弱？
思路：求异论证 → 削弱找「两组实验对象的相关不同点」，如「实验组小鼠本身携带肥胖基因」。
例 · 双观点
原观点：全球变暖是二氧化碳排放导致。反对者：是太阳活动导致。以下哪项最能削弱反对者？
思路：双观点削弱反对者 = 「A 是 C 的原因」= 「二氧化碳排放是太阳活动的原因」。
例 · 实践论证（方案与目的）
某市为缓解市中心交通拥堵，计划向进入市中心的车辆征收拥堵费。以下哪项最能削弱该方案？
A. 征收拥堵费后，部分车主会改乘公共交通　B. 市中心公共交通运力严重不足，且该方案实施成本高昂　C. 其他城市征收拥堵费后，市民满意度有所下降　D. 拥堵费收入将用于改善公共交通
思路：实践论证 = 「方案 A → 目的 B」。削弱 = 方案不可实现 / 达不到目的。B 同时指出方案不可行（成本高）且达不到目的（运力不足，收钱也缓解不了），力度最强，选 B；A、D 在加强；C 是无关比较（满意度≠拥堵），且「其他城市」类比力度弱。
例 · 枚举归纳（样本代表性）
为了解全市市民对垃圾分类的看法，调查员只在某高档小区门口随机采访了 100 位居民，绝大多数表示支持。于是得出结论：全市市民普遍支持垃圾分类。以下哪项最能削弱该结论？
A. 高档小区居民的环保意识和收入水平较高　B. 支持者中年轻人居多　C. 采访时间都选在周末上午　D. 100 人的样本量偏小
思路：枚举归纳（样本 → 整体）。削弱 = 样本不具有代表性。A 指出样本集中在高档小区、不能代表全市，直接削弱，选 A；D 虽提及样本量小，但没有说明样本偏差，力度弱于 A。
例 · 数据论证（找分母）
某市去年共发生交通事故 5000 起，其中夜间发生的占 40%。据此有人认为：夜间行车比白天更危险。以下哪项最能削弱该结论？
A. 该市夜间通行的车辆约占全天总车流量的 40%　B. 夜间发生的多为轻微刮蹭事故　C. 白天事故数量为 3000 起　D. 夜间司机大多更加谨慎
思路：数据论证 → 找到数字背后的分母。分子：夜间事故占 40%；A 给出分母：夜间车流量也占 40% → 事故率（事故数/车流量）与白天持平，并无更危险，选 A。这就是程意说的「数据题找分母，分子孤零零没有说服力」。

2.4 前提 / 解释 / 结论 / 评价型（第 10 次课）

① 前提型（假设/前提）

  • 识别：问「上述论证基于以下哪项前提/假设」「需要补充哪项」。
  • 思路：找论据与结论之间的跳跃概念，答案 = 把两者连起来（搭桥）。
  • 验证法：把选项否定后代入，若题干论证坍塌，则该选项是必要前提。
  • 注意：前提必须保证题干论证成立；搭桥是前提型最常考答案。

② 解释型

  • 识别：题干给出一个看似矛盾的现象，问「以下哪项最能解释」。
  • 思路：找一个条件/原因，让两个矛盾现象同时成立、不再矛盾（补充条件式解释）。
  • 原则：解释要能同时兼顾矛盾双方，不能只解释一半；优先选客观原因。

③ 结论型（日常结论）

  • 识别：问「由此可以推出」「可以得出以下哪项」。
  • 思路：严格依据题干，能推出什么选什么，不推理过度。
  • 慎选：绝对化表述（一定/必然/所有）、无中生有、偷换概念、与题干相反的选项。
  • 优选：语气较弱的「可能」「有些」「未必」等从题干能推出的表述。

④ 评价型

  • 识别：问「以下哪项与题干论证方式/逻辑错误最为相似」。
  • 思路：只看论证形式，不看内容。把题干翻译成符号（如 A→B），找选项里形式一致或错误类型一致的。
  • 常见逻辑错误：偷换概念、以偏概全、诉诸权威、因果倒置、循环论证等。
例 · 前提型（搭桥）
某市号召市民多乘坐地铁，理由是：地铁能减少碳排放。要使该论证成立，必须基于以下哪项前提？
A. 市民愿意放弃私家车改乘地铁　B. 地铁运行本身产生的碳排放相对较低　C. 碳排放是导致气候变暖的主要原因　D. 私家车的碳排放高于公交车
思路（程意式）：论据「坐地铁」→ 结论「减排」，中间有跳跃：坐地铁为什么能减排？需要搭桥「地铁本身的碳排放低」→ 选 B。A 是方案可行性（成立还需要它，但不是最核心的跳跃点）；验证法：否定 B（地铁碳排放很高），论证立刻坍塌，说明 B 是必要前提。
例 · 解释型（兼顾矛盾双方）
某品牌牛奶今年的销量大幅增长，但该品牌的广告投放量却明显减少了。以下哪项最能解释这一看似矛盾的现象？
A. 该品牌口碑好，老顾客自发向亲友推荐　B. 广告减少后，该品牌节省了大量成本　C. 其他乳业品牌今年的销量普遍下滑　D. 该品牌今年更换了广告公司
思路：要解释「广告少了但销量涨了」两个事实同时成立。A 用「口碑推荐」说明不靠广告也能拉动销量，同时兼顾双方，选 A；B 只解释成本、没解释销量；C 与题干无关；D 换广告公司 ≠ 投放量减少，解释不了。
例 · 评价型（只看形式）
题干：所有爱看书的人都有耐心，小明很有耐心，因此，小明爱看书。以下哪项与题干的论证方式最为相似？
思路（程意式）：把题干翻译成符号：A → B，B（小明有耐心），推 A。这是典型的「肯后」错误形式。选项里找同样「A→B，B ⇒ A」结构的——如「所有参加过培训的人都能通过考试，小李通过了考试，因此小李参加过培训」✓。评价型只看形式不看内容，把每个选项符号化再比对。
三

模块三 · 定义判断（第 20 次课）

DEFINITION
题干字数多、阅读量大。做题核心：「理解题干 + 对比选项」。三大突破点：① 学会不同情况下的读题方法；② 学习多定义题目做题方法；③ 明确选项分析原则。

3.1 底层能力 · 读懂定义，关注核心要点

要点含义提示词
主体行为或事件的发起者（一般在定义内容最前面）……的（机构/人/组织）
客体行为或事件的承受者对……；向……
目的行为目标和预期结果为了……；为达到……；确保……
方式/行为所采取的方法和具体行为以……为手段；采取……方法；通过……
条件限制性信息在……情况下；在……条件下；当……时
原因行为发生的原因由于……；因为……
结果行为造成的结果（结果比原因更常考、更重要）造成……；导致……；因而……
性质定义的本质属性（一般在句尾）……的（+名词）
✏️ 核心原则
① 先读问题，优先找与问题相关的定义，看清楚「属于/不属于」；② 对关键词敏感；③ 比较原则：优中选优——排除最不像的，剩下的比细节；④ 补充说明（括号里的）必须读，常常是考点；⑤ 「且/或」等和关系注意区分。
例 · 单定义（抓核心要点）
工作记忆是指个体在执行认知任务的过程中，对信息进行暂时性加工和存储的记忆系统。根据上述定义，下列属于工作记忆的是：
A. 小明能熟练背诵小学时学过的古诗　B. 小红记下服务台电话号码后立即拨打，拨完就忘了　C. 老李清楚地记得自己年轻时支边的经历　D. 小张能复述出昨天会议的主要内容
思路（程意式）：划关键词：执行任务过程中 + 暂时性加工和存储。A、C、D 都是长期记忆（永久存储），与「暂时性」矛盾 ✗；B「记下号码→立即拨打→拨完就忘」完全符合「暂时存储」→ 选 B。排除顺序：先排「长期记忆」这种明显违背性质的，再比对细节。

3.2 解题流程 & 多定义题目 & 选项分析

标准化流程

1
读问题：问的是「属于/不属于」「符合/不符合」，对应选项关注点不同。
2
读定义：划出主体、方式、目的、条件、结果、性质等关键词；括号补充信息必读。
3
对比选项：逐项与关键词比对，排除明显不符 → 剩两个比细节 → 优中选优。
4
不确定时：回到定义本身用「常识 + 被定义项」（定义词本身的意思）辅助判断。

题干设置的两种常见结构

  • 一个定义有限分类：定义给出后分了几个类别 → 选项与类别一一对应。
  • 一个定义后重点解释关键词：优先通过关键词排除，不必完全读懂定义。

多定义题目（题干给出 2 个及以上定义）

  • 先读问题，锁定问的那个定义，只读相关定义，其他定义可略读。
  • 两个定义常是「对立/包含」关系，可通过对比记忆（如「亲社会行为 vs 反社会行为」）。
  • 选项常「张冠李戴」：A 定义的行为套到 B 定义上，注意主体和行为匹配。

选项分析原则

  • 主体不符 → 一定不选（最优先排除）。
  • 方式/目的/结果不符 → 不选；只有个别细节不确定的，可以保留比较。
  • 两个选项都像时：哪个更全面地满足关键词，选哪个（优中选优）。
  • 不要因为选项「举的例子我没见过」就排除——比对的是结构不是内容。
例 · 多定义（先锁定问的定义）
亲社会行为是指个体做出的有利于他人和社会的行为；反社会行为是指危害他人和社会正常秩序的行为。根据上述定义，下列属于反社会行为的是：
A. 公交车上主动给老人让座　B. 在电影院里大声喧哗、随意走动　C. 同事生病时帮忙代班　D. 路见不平挺身而出
思路（程意式）：先读问题，锁定「反社会行为」= 危害他人和社会秩序。A、C、D 都是亲社会行为（利他）✗；B「大声喧哗、随意走动」扰乱公共秩序，符合危害性 → 选 B。多定义题技巧：两个定义常是对立关系，选项容易张冠李戴，注意「主体 + 行为」和定义严格对应。
四

模块四 · 论证评价（综应 C 类常考）

ARGUMENT EVALUATION
《综合应用能力 C 类》的必考大题，本质是批判性评价材料——在给定材料中「找出论证错误 + 说明理由」。与判断推理同源（都练逻辑），故附于本页。全模块骨架只有四类：概念不明确 · 判断不准确 · 推理不严谨 · 论据不充分。框架整理自超格程意「事业单位-论证评价」专项 + 中公/华图官方教研 + 历年联考真题。

4.1 题型认知 & 考情

是什么：给一篇 300~600 字的短文（材料），要求指出其中存在的若干处论证错误，并分别说明理由。

本质：源于管理类联考的「论证有效性分析」，既测查逻辑思维，也测查文字表达。

材料篇幅
300~600 字，3~6 段（4~5 段居多）
材料话题
自然科学类、社科类为主 —— 科技文献、报刊评论、社会现象
错误数量
一般 4~5 处（题干会明确给出数量）
作答格式
A 处：错误表现 + 错误类型（≤75 字）
B 处：理由（≤50 字）
分值
36~50 分
命题趋势
2016 年 5 月前题干明确给出四大错误类型；之后不再提示，更强调「错在哪 + 为什么」
评分标准（四条）
① 判断准确——准确找错并说出错误类型　② 理由充分——结合材料与常识解析
③ 表达精炼——抓住重点、简洁表述　④ 条理清晰——分条作答
⚠️ 两个变化趋势
  • 近年弱化「错误类型」的判断，更强调说清「错误在哪」并「阐明理由」——所以不必死抠类型名称，说清逻辑问题更关键。
  • 材料常含数据、百分比、平均数，要警惕数字陷阱（见 4.6）。

4.2 论证结构 & 做题四步

先认清三个要素

论点
论述的话题 + 得出的结论
标志词：因此、所以、可见、由此可见、据此判断、这说明
论据
支持论点的依据
标志词：因为、由于、根据、调查研究（显示）、例如
论证
用论据证明论点的推理过程（隐藏的链条）
重点看「论据 → 论点」这一步跳得合不合理
核心心法
论证评价题本质就是拆论证结构：把「论点、论据、论证」三段拆开， 看哪一环不符合逻辑 —— 错的一定是「论据推不出论点」的那一步。

做题四步

1
审题：确定要找几处错误、每处写多少字、A/B 分别是「错误」还是「理由」。
2
拆结构：逐段划出论点、论据，用箭头画出「论据 → 论点」的推理链条。
3
找错误：沿链条逐句比对，看哪一步跳得太快 / 概念变了 / 因果不成立，归入对应错误类型。
4
写答案：A 处「由……推出……，存在论证错误，属于××」；B 处「因为……（应补充什么 / 二者无必然联系）」。
万能句式
A 处：第 X 段由「……（论据）」推出「……（结论）」存在论证错误。
B 处：……（论据）与……（结论）之间没有必然联系 / 概念不同 / 样本不具代表性，属于××。

4.3 四大逻辑错误类型（官方分类）

题干若给出错误类型提示，就锁这四类：① 概念不明确　② 判断不准确　③ 推理不严谨　④ 论据不充分。四类下面共 15 个小类，每个都有定义和例子 —— 不求全背，但求看到能认出来。

1概念不明确
前后说的不是同一个东西
偷换概念 · 转移论题 · 稻草人谬误
2判断不准确
结论本身不成立，或前后打架
过度推断 · 可能推必然 · 自相矛盾
3推理不严密
论据到结论这一步跳错了
强加因果 · 因果倒置 · 单因谬误 · 类比谬误 · 选择性论证 · 平均数谬误
4论据不充分
论据太少 / 太偏，撑不起结论
论据错误 · 以偏概全 · 诉诸情感
1概念不明确前后说的不是同一个东西
偷换概念
在论证过程中把一个概念偷偷换成另一个，前后说的不是同一件事。
例 材料说「转基因技术是安全的」，结论却说「转基因食品是安全的」—— 技术与食品不是同一个概念。
转移论题
用另一个话题替换原本要论证的话题（答非所问、跑题）。
例 领导问「你为什么迟到？」，小张答「这是我第一次迟到」—— 问的是原因，答的是次数。
稻草人谬误
歪曲、夸大甚至凭空捏造对方的观点，做成一个「稻草人」，再攻击这个假观点 —— 这样打起来很轻松，但打的根本不是对方。
例 小明说「国家应该多投钱发展教育」，小红回击「想不到你这么不爱国，居然想减少国防开支、让外国有机可乘」。
小明从没说要减国防开支，这是小红臆造的观点。
2判断不准确结论本身不成立，或前后打架
过度推断
由有限的论据推出更深、更广的结论，结论超出了论据能支撑的范围。
例 国家很重视学前教育 →「教育行业会得到很好的发展」—— 把范围从"学前"扩大到了整个教育。
可能推必然
论据只支持「可能」，结论却说成「一定 / 必然」。
例 材料说「月亮并不是每个望月都进入地球阴影」→ 推出「望月与会不会月食丝毫关系都没有」—— 有关系但非必然，被说成了完全无关。
自相矛盾
论据与结论相矛盾，或对同一对象做出两个互相矛盾的断定。
例 「月食是月亮被地球阴影遮掩、日食是太阳光被月球遮住，所以说月食和日食的成因一样」—— 前面刚说成因不同，后面却说一样。
3推理不严密论据到结论这一步跳错了
强加因果
把本无因果的两件事强行联系起来，在中间建立「导致关系」。
例 「B 市通过引水增加了水体循环自净能力」→ 推出「再生水回用促进了水资源循环利用」—— 两件事没有必然因果关系。
因果倒置
把原因和结果搞反了，或二者本就是「共同结果」而非因果。
例 「90% 的富翁每天喝咖啡，所以喝咖啡能致富」—— 更可能是「有钱才喝得起 / 二者都是成功的结果」。
单因谬误
复杂结果只有一个原因造成的 —— 忽略其他因素。
例 「小王成绩下降，一定是因为打游戏」—— 可能还有身体、家庭、兴趣等多种原因。
类比谬误（不当类比）
把表面相似、本质不同的两类事物放一起比较，并推出结论。
例 「大脑和计算机都可计算，计算机能删除文件，所以大脑可删除记忆」—— 二者本质不同。
选择性论证
只挑对自己有利的证据，回避不利证据。
例 只说「某药治好 30 人」，却不说「还有 100 人无效」—— 只呈现一部分事实。
平均数谬误
把平均数概念套到单独个体身上（数字陷阱）。
例 家里月收入 3 万、三个劳动力 → 推出「每人月收入 1 万」—— 很可能一人挣 3 万、另外两人没收入。
4论据不充分论据太少 / 太偏，撑不起结论
论据错误
论据本身就是错的或假的，地基不稳。
例 「因为吸烟有益健康，所以我们应该吸烟」—— 前提本身就是假的。
以偏概全
由少数、个别的例子，推出普遍性的结论。
例 「来自 A 市的小张是骗子，可见 A 市的人都是骗子」—— 样本太小且特殊。
诉诸情感
用操纵感情（恐惧、怜悯、同情等）代替逻辑论证。
例 「你怎么可以吃狗肉？小狗多么可爱，就像小朋友一样，你忍心伤害朋友吗？」—— 用情感代替了论证。
💡 怎么用
  • 先找错、再归类：近年趋势是「不给类型提示」，所以重点是说清哪里错，类型名说不上来也别慌。
  • 归类时抓关键：概念问题看「是不是同一个词」；判断问题看「结论本身对不对」；推理问题看「因果关系 / 类比关系」；论据问题看「样本够不够、代不代表」。

4.4 十二类常见逻辑谬误（程意 12 讲）

这张表是「找错」的弹药库 —— 12 类背熟，考场逐条比对，看到错就能叫出名字。

① 以偏概全
仅根据很少的、个别的例子，就推出普遍性的结论。
例 我的一个四川朋友爱吃甜食，所以四川人都爱吃甜食。
② 不当类比
把表面相似、本质不同的事物放在一起比较论证并得出结论。
例 大脑和计算机都可计算，计算机可以删除文件，所以大脑可删除记忆。
③ 滑坡谬误
使用连续的因果推论，却夸大了每个环节的因果强度，得到不合理结论。
例 丢了一颗马蹄钉 → 丢了一个马掌 → 折了一匹战马 → 损了一位国王 → 输了一场战争 → 亡了一个帝国。
④ 偷换概念
在一个论证过程中把概念偷偷换掉（前后不是同一个东西）。
例 甲问："我能用蓝墨水写出红字，你信吗？"乙答："不信。"甲提笔在纸上写了一个"红"字。
⑤ 转移话题
用另一个话题去替换原来所论证的话题（答非所问）。
例 领导："你为什么迟到？"小张："这是我第一次迟到。"
⑥ 诉诸无知
因某事物未被证明是错的就断定它对；因未被证明是对的就断定它错。
例 尚无证据证明上帝存在，因此上帝不存在。
⑦ 诉诸权威
单纯靠权威性来加强论点或反驳论点，对论证本身不做讨论。
例 因为亚里士多德认同"地心说"，所以"地心说"一定是正确的。
⑧ 自相矛盾
论据与结论矛盾，或对同一对象做出两个互相矛盾的断定。
例 我认为你做的都对，但是第二个步骤不对。
⑨ 强加因果
把没有直接因果联系的两件事强行联系起来，在中间建立「导致关系」。
例 我已经工作了 20 年，所以这次问题不可能是我造成的。
⑩ 因果倒置
把原因和结果相互颠倒（其实两者是「共同结果」或方向反了）。
例 90% 的富翁每天喝咖啡，所以喝咖啡能致富。
⑪ 绝对表述
把可能性的关系，用绝对化的语言进行表述。
例 新闻报道很多人辞职创业成功了，所以辞职创业一定能成功。
⑫ 非黑即白
认为只有 2 种情况，忽略其他情况（非此即彼）。
例 老师说：不要留长头发。学生说：那我只能剃光头了？
记忆分组（12 类打包背）
概念类（3）：偷换概念 · 转移话题 · 自相矛盾
论据类（4）：以偏概全 · 诉诸无知 · 诉诸权威 · 绝对表述
推理类（3）：强加因果 · 因果倒置 · 滑坡谬误
关系类（2）：不当类比 · 非黑即白

4.5 三大题型 & 解题思路

类型一 · 考查逻辑错误

  • 识别 ①（看问法）：以下哪项表述最为准确地指出了题干 ×× 论证的错误？／ 下列与题干中的逻辑错误最相似的是？
  • 识别 ②（看选项）：问法没有提示时，关注选项 —— 选项在评判题干的逻辑错误。
  • 解法：先把题干的论证链条拆出来、判定它的错，再去选项找同款错误（同类比对）。
例 · 类型一（评估"最不相关"）
某杂志文章称，让奶牛听舒缓的音乐，其产奶量会提高 30%。内蒙古某奶制品企业连续五年的奶牛产奶结果证实，听舒缓的音乐不仅能提高产奶量，奶中蛋白质含量也更高。相关学者表示，舒缓的音乐不仅能改善奶牛的消化吸收系统，还能改善奶牛的心情。
以下哪一个问题的回答对评估上述文章的真实性最不相关？
A. 学者的解释是否具有可靠的理论支持
B. 听舒缓音乐的奶牛与不听舒缓音乐的奶牛的其他饲养条件是否完全相同
C. 该方法是否具有大面积推广的可行性
D. 没听舒缓音乐的奶牛的产奶量是否也提高了
思路：问「最不相关」→ 找与「真实性」无关的。A 影响论据可靠性 ✅关键；B 控制变量（其他条件相同才能归因）✅关键；D 反向验证（不听音乐的也提高则说明与音乐无关）✅关键。C 是「能不能大面积推广」，属于可行性，与"文章是否真实"无关 → 选 C。
⚠️ 做题提示：注意区分「真实性（论证对不对）」与「可行性（能不能做）」—— 这是高频陷阱。

类型二 · 两面验证类

  • 识别 ①（看问法）：为了对上述断定做出评价，回答以下哪项最重要 / 最关键 / 最相关？
  • 识别 ②（看选项）：选项是两面项（是否、能否……），或者选项本身就是一个问题。
  • 例：关于生活态度，"不佛系"与"佛系"哪个会导致更不利的结果？
  • 解题思路：回答正反两面能分别削弱和支持题干 → 则该项是影响题干论证的关键问题。
    （注意：若出现明确无关项，不需要验证，直接排除）

类型三 · 考查对于论证过程的理解

分两个子类，解法都是「指哪打哪」—— 题目问谁，就只看谁说的那句话。

  • （一）直接评价 ×× 的话
    【例】对于小王的言论，评价正确的是 → 选「在证据不足、缺乏严谨论证的情况下，仅凭个人经验或偶然性的例子就匆忙得出结论」
    【例】以下哪项最为准确地概括了正方反驳反方第一个观点所使用的论证方法 → 选「通过构造一个类比论证来反驳对方的观点」
  • （二）评价 ×× 对于其他人话的作用（削弱 / 加强；具体削弱、加强了结论还是论据）
    【例】下列选项中，对网友的论述评价正确的是 → 选「网友 7——不支持任何一方的观点，提出了一种相关的新观点」
    【例】对丁的言论评价正确的是 → 选「直接反驳了丙论证的理由」
例 · 类型三（识别论证方法）
以下是一场关于"大学生兼职利大于弊还是弊大于利"的辩论中正、反方辩手的发言。
正方：第一，对方辩友的失误在于将"兼职会使学习成绩下降"归咎于兼职，但我认为这些现象并不是兼职导致的，而是兼职者本身造成的 —— 蛀牙吃苹果导致牙疼，怎么能把责任归在苹果身上呢？第二，对方辩友认为大学生兼职会抢走全职员工的饭碗，我方认为，如果按对方这个逻辑推理下去，那我们大学四年毕业后最好不要找工作，因为这样就不会影响任何人的饭碗，这成立吗？
反方：对方辩友的观点是错误的，因为我们大学四年毕业后当然要找工作，不找工作我们不就白读四年大学了吗？
以下哪项最为准确地概括了正方反驳反方第一个观点所使用的论证方法？
A. 指出了对方论证中的因果关系存在倒置
B. 通过构造一个类比论证来反驳对方的观点
C. 提出了一个反例来反驳对方的一般性结论
D. 指出对方在一个关键概念的运用上自相矛盾
思路（指哪打哪）：题目问「正方反驳反方第一个观点」 → 只看正方第一句话。正方用「蛀牙吃苹果导致牙疼，不能怪苹果」来类比「成绩下降不是兼职导致、而是兼职者本身」→ 构造类比论证 → 选 B。
A「因果倒置」不对（正方说的是"另有原因"，不是颠倒因果）；C「反例」不对（没举反例）；D「自相矛盾」不对（正方没指出对方前后矛盾）。
例 · 类型三（评价各人发言）
遇到暴雨、大风等恶劣天气，该不该点外卖？这一话题引发网友热议。有网友呼吁：恶劣天气下配送的外卖小哥人身安全得不到保障，因此应抵制在恶劣天气点外卖；也有网友持反对意见。
网友 2：我和我身边的人都是反对恶劣天气点外卖的，没有人会支持这种行为吧。
网友 4：经常吃外卖对身体健康会产生不利影响。
正方（恶劣天气下可以点外卖）：
网友 7：与其担心是否应该在恶劣天气点外卖，不如在提高外卖小哥安全意识、完善配送应急机制、保障外卖小哥权益等问题上多下功夫。
网友 8：不论何种天气，消费者有是否点外卖的自由，外卖小哥有是否接单的自由。
下列选项中，对网友的论述评价正确的是（　）
A. 网友 2——协调双方的观点，并给出了一个解释的理由
B. 网友 4——支持一方而反对另一方
C. 网友 7——不支持任何一方的观点，提出了一种相关的新观点
D. 网友 8——提出了一个与争论双方无关的问题
思路：网友 7 没有站队，而是把话题转向「保障外卖小哥权益」这个相关的新方向 → 选 C。
A 网友 2 只是重复己方立场（还带点"人多即对"的味道），并没有"协调"；B 网友 4 谈的是"吃外卖伤身"，与"恶劣天气该不该点"是另一个话题，不算支持/反对某一方；D 网友 8 说的是"双方都有自由"，与争论直接相关（实质支持可以点）。

4.6 易混考点辨析（最容易判错）

① 以偏概全　VS　过度推断

以偏概全

本质由少数 / 粗略事实 → 普遍性结论

特征样本小、少数例子、特殊样本

提示词一个、极少数、某、典型、个别

例 来自 A 市的小张是骗子 → A 市的人都是骗子

过度推断

本质论据不足 → 结论，结论更深、更广

特征扩大了范围、程度

提示词可见、由此可知、一定、必然

例 国家很重视学前教育 → 教育行业会得到很好发展

一句话区分
以偏概全看「样本够不够」；过度推断看「结论是不是被放大了」。

② 平均数谬误（数字陷阱）

把平均数概念放到单独个体身上。

例
某家庭每月的收入为 3 万元，家里有三个劳动力，得出结论：每个人的月收入为 1 万元。
错在：「家庭月均收入 3 万」是平均数，不等于「每个劳动力各自 1 万」—— 很可能一人挣 3 万、另两人没收入。

③ 机械类比（时间维度）

把同一事物在不同时间段进行类比。

例
由过去三年 6~8 月气温逐年上升，推出今年 6~8 月气温会比过去三年都高。
错在：过去趋势不代表今年延续；不同年份的条件不同，不能机械外推。

④ 必要条件　VS　充分条件（形式谬误）

例
材料称"身高是入行的关键标准"，进而推出"只要身高达标，就能进入一些对身材有特殊要求的职业"。
错在：「关键标准」= 必要条件（没它不行），却被论证成了充分条件（有它就够）。混淆了条件关系 → 形式谬误。

⑤ 其他两条「一句话」辨析

  • 因果倒置 vs 强加因果：倒置 = 因果方向反了（可能互为因果）；强加 = 二者本无因果。
  • 偷换概念 vs 转移话题：偷换 = 论证中概念变了；转移 = 直接换了个话题聊。

4.7 历年真题演练（含 A/B 参考答案）

按「A 处写错误 + B 处写理由」的格式感受真题。做题时先自己找，再对照答案。

真题 1 · 2021 湖北事业单位联考（再生水）
材料（节选）：……近年来，M 市仅企业单位和居民小区就建设单体再生水利用设施 56 座，每座日均处理回用能力达 2000 吨，也就是说这些企业单位和居民小区每天使用了总量达 11.2 万吨的再生水。另有一些城市再生水推广利用尚处在起步阶段，多数市民不了解什么是再生水及其回用。例如，某研究机构在 N 市做了一次问卷调查，其中设置了对再生水"很了解""基本了解""不了解"三个选项，结果显示：选择"很了解"的有 19 人，"不了解"的有 89 人。
作答要求：指出其中存在的 4 处论证错误并分别说明理由。
1. A：第二段由"A 市 2018 年用水的占比"推出"大力发展再生水回用可在一定程度上缓解供水紧缺"存在论证错误。
B：论据中举了"A 市 2018 年"的特例，不具有代表性，推不出一般性结论，属于以偏概全。

2. A：第二段由"B 市通过引水增加了水体的循环自净能力"推出"再生水回用促进了水资源循环利用"存在论证错误。
B："引水增加水体的循环自净能力"与"再生水回用促进水资源循环利用"没有必然的因果联系，属于强加因果。

3. A：第三段由"每座日均处理回用能力达 2000 吨"推出"每天使用了总量达 11.2 万吨的再生水"存在论证错误。
B：论据中"日均处理回用能力"与结论中"每天使用再生水的总量"概念不同"能力"不等于"实际用量"，属于偷换概念。

4. A：第四段由"'很了解'的有 19 人、'不了解'的有 89 人"推出"多数市民不了解再生水及回用"存在论证错误。
B：问卷三个选项只给出两个，未给出"基本了解"的人数，推不出"多数市民不了解"，属于论据不充分。
真题 2 · 2020 湖北事业单位联考（火星生命）
材料（节选）：……火星大气密度不到地球的 1%，所以火星上即使有生命，也是非常低级的微生物。地球生命在这样的恶劣环境中都不可能存活，因此在火星地表不可能有生命存在。研究小组在火星土壤中没有发现检测水的标记颗粒，可见火星上不曾有液态水。弗雷格博士是著名的天体演化研究专家，其研究成果发表在顶级期刊上，因此其研究结果是非常可靠的。
作答要求：指出其中存在的 4 处论证错误并分别说明理由。
1. A：由"火星大气密度不到地球的 1%"推不出"火星上即使有生命也是非常低级的微生物"。
B：大气密度与生命高低级没有必然联系，论证者强行构建了联系，属于强加因果。

2. A：由"地球生命在恶劣环境中都不可能存活"推不出"在火星地表不可能有生命存在"。
B：火星生命存在的条件可能与地球不同，不能机械类比，属于类比不当。

3. A：由"没有发现检测水的标记颗粒"推不出"火星上不曾有液态水"。
B：用无法证明（未发现）作为论据去推出确定结论，属于诉诸无知。

4. A：由"弗雷格博士是著名专家、成果发表在顶级期刊"推不出"其研究结果非常可靠"。
B：研究结论是否可靠与研究者是否著名、期刊是否顶级无关，属于诉诸权威。
真题 3 · 江苏事业单位（M 国研发投入）
材料（节选）：2015 年 M 国研发总支出 2500.3 亿美元，同比增长超过 10%，占 GDP 达 8%，可见其占 GDP 的比重保持着惊人的增长速度。2015 年 M 国研发总投入中约 75% 的经费来自私营企业，私营企业研发中心达 1.2 万个，可见私营企业已成为 M 国研发成果的主要贡献者。2002~2016 年 SCI 收录的该国论文由 2 万余篇增至 171026 篇，平均每年增加 1 万余篇，可以预见 2017 年该国被 SCI 收录的论文将超过 18 万篇。
作答要求：指出其中存在的 4 处论证错误并分别说明理由。
1. A：由"2015 年研发占 GDP 达 8%"推不出"其占 GDP 的比重保持着惊人的增长速度"。
B：仅知道 2015 一年的比重，没有以往年份的数据，无法说明"增长速度"，属于论据不充分。

2. A：由"约 75% 经费来自私营企业"推不出"私营企业已成为研发成果的主要贡献者"。
B：投入经费 ≠ 参与研发，更不等于产出成果，把"研发资金"与"研发成果"混淆，属于概念不明确。

3. A：由"外国直接投资比重的增长"推不出"外国直接投资在 M 国科技创新体系中的作用正在改善"。
B：论据只给了"比重和金额"，但是否投入科技创新体系并不明确（可能投向其他领域），属于判断不准确。

4. A：由"2002~2016 年平均每年增加 1 万余篇"推不出"2017 年将超过 18 万篇"。
B："平均每年增加"不代表每年固定增加，每年情况不确定，推不出 2017 年一定超过，属于推理不严密。
真题 4 · 月食与日食（自相矛盾 / 可能推必然 / 偷换概念 / 以偏概全）
材料（节选）：月食形成的原因是月亮运行到地球背着太阳的阴影区域内时被地球阴影遮掩；日食的形成是地球运行到月亮背着太阳的阴影区域、太阳光被月球遮住。所以说，月食和日食的成因一样。……由于地球公转轨道面和月亮公转轨道面不在同一平面上，月亮并不是每个望月都进入地球阴影，因此望月与会不会月食丝毫关系都没有。……月偏食时月亮始终只有一部分进入地球阴影锥，因此仔细观测就可发现，月偏食时月亮整体并不是完全黑暗的。……2014 年 7 月 22 日上午发生的日全食，全食时间最长可达 6 分 39 秒，那么由此推出，实际上发生的日全食的全食阶段不过 7 分半。
1. A：第一段"月食和日食的成因一样"结论与原文不符，属于自相矛盾。
B：月食是月亮被地球阴影遮掩，日食是太阳光被月球遮住，二者成因并不相同。

2. A：第二段"望月与会不会月食丝毫关系都没有"存在可能推必然的错误。
B：材料说"月亮并不是每个望月都进入地球阴影"，说明有关系但非必然，不能推出"丝毫无关"。

3. A：第三段"月偏食时月亮整体并不是完全黑暗的"混淆了"月偏食"和"月全食"的概念，属于偷换概念。
B：由材料可知是月全食时月亮整体并非完全黑暗，而非"月偏食"。

4. A：第四段"实际上发生的日全食的全食阶段不过 7 分半"属于以偏概全。
B：仅凭 2014 年一次日全食（6 分 39 秒）推不出所有日全食都"不过 7 分半"，样本不具代表性。
真题 5 · 转基因食品（概念不明确）
材料：关于转基因食品的安全问题，绝大多数研究成果表明转基因技术是安全的，我本人也吃转基因食品，并没有出现什么不适。同时，对国际上近年来有关转基因农作物的 9333 篇科技论文进行的分析和追踪表明，所有得出"转基因食品不安全"结论的论文，最后均被证明是错误的。所以，转基因食品是安全的。
错误：属于概念不明确。
理由：论据说的是"转基因技术是安全的"，结论说的是"转基因食品是安全的" —— 二者不是同一概念，论证中把概念偷换了，因此推不出结论。
💡 一个句子抓住：技术安全 ≠ 食品（产品）安全。
真题 6 · 身高与职业（一题四错）
材料（节选）：身高是入行的关键标准，只要身高达标，就能进入一些对身材有特殊要求的职业。一名身高 1 米 5 的女孩，小学时没能参加演讲比赛、初中时没能参加辩论赛，可见身高太矮的孩子参加不了任何比赛。使用生长激素后，有的孩子为了长高可能会增加运动量，运动增多时甚至可致跛行，可见使用生长激素会导致孩子走路一瘸一拐。亲人表现出的身高否定对孩子的自尊心、自信心伤害更大，孩子必定会变得越来越不自信。
1.「关键标准」是必要条件，却被说成「只要……就……」的充分条件 → 形式谬误（混淆条件关系）。
2.一名矮个孩子、两类比赛只是个例 → 推出"参加不了任何比赛" → 以偏概全。
3.使用激素 → 可能增加运动量 → 可能致跛行，一连串偶然叠加推出"会导致走路一瘸一拐" → 滑坡谬误。
4.论据只说"可能变得不自信"，结论却用"必定" → 绝对表述（极端化）。
论证评价 · 答题口诀
先拆论点论据，再沿链条找错；A 处说清「由谁推出谁、属于哪类」，B 处补上「为什么推不出」。
高频四坑：概念偷换、样本太小、因果乱安、以偏概全。

口诀速记卡

CHEAT SHEET
全部口诀汇总，冲刺期每天过一遍。考前 10 分钟专背这一块。
总纲
两个要求，一个核心词：严谨性（说什么是什么，没说不知道）+ 形式性（符合规则就对）+ 核心词「有些」（=至少有一个，知道有些是真的，别的都不确定）。
翻译口诀
如果就，前推后；只有才，后推前；除非否则不，后推前；除非否则，否前推后；充前必后别搞混。
推理口诀
逆否等价是王道，否后必否前；肯前必肯后；否前、肯后推不出。递推：A→B，B→C ⇒ A→C。
真假判断
知真求假/知假求真，直接找矛盾：且↔或、或↔且（各加非）；A→B 的矛盾是 A 且非B；要么A要么B ↔ 要么A且B，要么非A且非B。
直言矛盾
所有↔有些，是↔非，某个不变：所有是 ↔ 有些非；所有非 ↔ 有些是；某个是 ↔ 某个非。上反对（所有是/所有非）不能同真；下反对（有些是/有些非）不能同假。
三段论
找中项（前提出现两次的桥）；「所有」和「否定」周延，「有的」和「肯定」不周延；两个否定前提无结论；前提有否定，结论必否定。
朴素逻辑
突破口：确定性 + 关联性。数独：排除 + 交集最多处入手；3+2：相同归大去排除；最多=加和、最少=取大（去包含）。
一拖N
有序画箭头（紧挨/不紧挨/隔1），无序看分组。可能真→代入可行可选；不可能真→代入冲突可选；一定真→正推。问最多验证最大数、问最少验证最小数。
加强削弱
读问题辨题型 → 理结构（结论☆论据）→ 预设答案。力度：本质>现象、全面>片面、确定>可能、量大>量小。因果削弱：因果倒置、另有共因、有因无果/无因有果、否定此因、另有他因。
论证模型
求异（削：不同点；加：相同点）→ 双观点（削反对者=A是C的原因）→ 实践论证（方案可不可实现）→ 类比（根本同/异）→ 枚举（代表性）→ 缺桥（搭桥/拆桥）→ 数据（找分母）→ 有比较（选有比较的）。
定义判断
主体（发起者）、客体（承受者）、方式（手段）、目的（为了）、条件（限制）、结果（导致）、性质（句尾）。括号必读；先排主体不符；多定义先锁定问的定义；优中选优。
论证评价
先拆论点论据，再沿链条找错；A 处「由谁推出谁 + 属于哪类」，B 处「为什么推不出」。四类错误：概念不明确 / 判断不准确 / 推理不严密 / 论据不充分。高频四坑：概念偷换、样本太小、因果乱安、以偏概全。

阶段任务目标
基础阶段跟课 + 背口诀 + 做课后作业；笔记当天整理（思维导图 + 题目解析 + 做题步骤）打扎实基础，重点在「学会」

套题冲刺掐时间整套刷，复盘每道题的考点归属；用「知识点复习表 + 默写表」查缺补漏固化解题反射，控制时间预算

每日复习小贴士

  • 图推：每天 10-15 道，只判断「考哪类规律」，45 秒/道，练识别速度。
  • 逻辑：每天把翻译口诀默写一遍，直到不用想就写出来。
  • 类比：边做题边积累常识，整理自己的「常识小本」（时辰、节气、别称等）。
  • 定义：练习划关键词，训练「一眼抓住主体、方式、结果」。
  • 复盘：错题不是看答案，是回看「我应该用哪个考点/哪一步想错了」。

「过程或许有点难，但结果会是好的。」母题二、三、四难，基础阶段学不会很正常——学会多少都是进步，刷题阶段会带你重点攻克。
