总纲 · 两个要求，一个核心词

THE GOLDEN RULES
这是程意逻辑判断的第一节课内容，是整套必然性推理的底层操作系统——解决「生活与逻辑相混淆」的问题。

要求一 · 严谨性

说什么是什么，没说不知道。

  • 题干没说的，一律当作不知道，不脑补、不联想生活经验。
  • 例：「如果你上岸了，我就给你买辆法拉利」——只说明「上岸→买法拉利」，没说上岸后买什么颜色、没说没上岸会怎样。
  • 例：「程意是会跑的动物，所有会跑的动物是妖怪」→ 虽然荒诞，但只要形式正确，推出的「程意是妖怪」在逻辑上成立。

要求二 · 形式性

关注形式，只要符合推理规则，推出来的就是对的。

  • 逻辑只研究推理形式，不研究内容真伪。
  • 例：A是B，所有B是C → 则A是C。形式对就对，内容多荒诞都成立。
  • 做题时把题干「翻译成符号」，只在符号层面推理，摆脱生活直觉干扰。

核心词 · 有些（= 至少有一个）

  • 逻辑学中「有些」= 至少有一个，数量不限定，1 个也叫有些，全部也是「有些」（含于其中）。
  • 「有些是」为真，「有些非」的真假不确定；反之亦然——两者是下反对关系，可以同真，不能同假。
  • 例：题干「有些同学考上了」为真，不能推出「有些同学没考上」，也不能推出「所有同学都考上了」。
✏️ 记忆
「凡、都」都是「所有」的意思;「至少有一个」是「有些」的意思。「有些」很狡猾:知道「有些是」真,别的都不确定。
例 · 核心词「有些」
已知「有的同学通过了考试」为真。据此,以下哪项一定为假?
A. 所有同学都通过了考试　B. 张同学通过了考试　C. 所有同学都没通过考试　D. 李同学没通过考试
思路(程意式):「有些是」为真 → 只知道至少有一个通过,其余都不确定。一定为假 = 找矛盾:「有些是」的矛盾是「所有非」→ 选 C。A、B、D 都是「不确定真假」,不能选。

模块一 · 必然性推理（逻辑判断）

NECESSARY REASONING
特点：侧重知识点的记忆、识别、使用；难易度中等，个别内容偏上。学会了用熟了，正确率和速度都能明显提升。通用流程：识别题型 → 翻译符号 → 套用规则 → 选出答案。

1.1 直言命题（第 1 次课）

含义：直言命题就是含有一个断定的语句，类似汉语的单句。如「所有中国运动员都赢得了奖牌」。

六种分类（量项 × 联项）

量项联项形式示例
所有（全称）是所有A是B所有学生都是党员
非所有A非B所有学生都不是党员
有些（特称）是有些A是B有些学生是党员
非有些A非B有些学生不是党员
某个（单称）是某个A是B张三（这个学生）是党员
非某个A非B张三（这个学生）不是党员

注意「凡、都」都是「所有」的意思；「至少有一个」是「有些」的意思。

矛盾关系（重点）

矛盾关系 = 针对相同事物的两个命题永远满足一真一假。

  • 找矛盾方式一：加「并非」（了解即可，考得少）。
  • 找矛盾方式二：变形式——「所有 ↔ 有些」「是 ↔ 非」互换，「某个」不变。
原命题矛盾命题
所有A是B有些A非B
所有A非B有些A是B
某个A是B某个A非B

对当关系（补充：上反对 / 下反对 / 从属）

关系双方性质
矛盾所有是 ↔ 有些非；所有非 ↔ 有些是；某个是 ↔ 某个非一真一假，必有一真一假
上反对所有是 ↔ 所有非不能同真，可以同假
下反对有些是 ↔ 有些非可以同真，不能同假
从属所有是 → 某个是 → 有些是；所有非 → 某个非 → 有些非全称真则单称/特称真；特称假则单称/全称假
例 · 直言矛盾应用（知真求假）
「有的运动员竞技状态不好。」根据上述断定为真，以下断定可以确定为假的是：
A. 有的运动员竞技状态好　B. 运动员甲竞技状态好　C. 所有运动员竞技状态都不好　D. 所有运动员竞技状态都好
思路（程意式）：知真求假 → 直接找矛盾。「有些A非B」的矛盾是「所有A是B」→ 选 D。注意 A、B、C 都是「不确定真假」，不能选。
1
真假话问题四步走（找矛盾 → 定位置 → 变假为真 → 筛选答案）：① 在题干几句话里找矛盾关系，确定真话/假话必在其中；② 由题目给的真话/假话数量，推出其余句子的真假；③ 把假的变真（取其矛盾/反面）；④ 代入选项选出答案。
例 · 真假话问题（四步走）
某次税务检查后，四个工商管理人员有如下结论：
甲说：所有个体户都没纳税。　乙说：服装个体户陈老板没纳税。
丙说：个体户不都没纳税。　丁说：有的个体户没纳税。
如果四人中只有一人断定属实，则以下哪项为真？
思路（程意四步走）：① 找矛盾：甲「所有个体户都没纳税」（所有非）与丙「个体户不都没纳税」=「有些个体户纳税了」（有些是）是矛盾关系，真话必在甲、丙之间；② 定位置：只有一真 → 乙、丁必假；③ 变假为真：丁假 →「有的个体户没纳税」为假 → 其矛盾「所有个体户都纳税了」为真；④ 筛选答案：所有人都纳税 → 陈老板纳税、甲假、丙真。答案选「个体户陈老板纳税了」。

1.2 联言命题：p 且 q（第 2 次课）

含义：断定多种情况同时为真的命题，表达为 p 且 q。

提示信息（识别）

类型连接词例句
并列词且、和、与、既……又……小李学了资料和判断
递进词而且小李不但上课认真听讲，而且下课做作业
转折词但是、然而、却虽然学习很辛苦，但一定会有收获

真假性：全真才真，有假则假

p（米饭）q（馒头）p 且 q
✓✓✓
✓✗✗
✗✓✗
✗✗✗

推理规则

  • 已知 p 且 q 为真 → p 真，q 真（分解）。
  • 已知 p 且 q 为假 → 肯一推否一：补充「p 真」可推出「q 假」；补充「q 真」可推出「p 假」。

矛盾命题（知真求假 / 知假求真直接找它）

p 且 q 的矛盾 = 非p 或 非q
例 · 推理规则
「小王是足球明星并且小李是网球明星。」如果上述判断为假，并且小李确实是网球明星，则以下哪项为真？
思路：p 且 q 为假 + q 真 → 肯一推否一 → p 假，即「小王不是足球明星」。
例 · 联言矛盾（知假求真）
「小王既会唱歌又会跳舞」这一判断为假。据此，以下哪项一定为真？
思路：p 且 q 为假 → 找矛盾「非p 或 非q」→ 一定为真的是「小王不会唱歌 或 不会跳舞」。注意：不能推出「小王一定不会唱歌」或「一定不会跳舞」，只能推出「至少有一个不会」。
✏️ 口诀
联言「且」：全真才真，有假则假；整体为假，肯一推否一；找矛盾：且变或、各加非。

1.3 选言命题：p 或 q（第 2 次课）

（一）相容选言命题（重点）

  • 含义：断定多种情况至少有一真，可以同真，表达为 p 或 q。
  • 提示信息：……或……；或者……或者……；至少有一种。
p（米饭）q（馒头）p 或 q
✓✓✓
✓✗✓
✗✓✓
✗✗✗
  • 已知 p、q 独立情况 → 整体：有真则真，全假才假。
  • 已知 p 或 q 整体为真 → p、q：否一推肯一（否定一个能推出另一个真，即「或」命题否定一个支命题，可以推出另一个支命题成立）。
p 或 q 的矛盾 = 非p 且 非q　　等价转换：p 或 q = 非p → q = 非q → p

（二）不相容选言命题（低频，了解即可）

  • 要么 p，要么 q：有且只有一个真。
  • 矛盾：要么 p 且 q，要么非p 且非q。
例 · 相容选言推理（否一推肯一）
已知「小明去 或 小红去参加志愿活动」为真，且小明不去。由此可以推出：
思路：p 或 q 整体为真 + 否定 p → 否一推肯一 → q 真，即小红一定去。若题干把「或」换成「要么……要么……」（不相容），结论相同也是小红去，但推理依据是「有且只有一个真」。
✏️ 口诀
选言「或」：有真则真，全假才假；整体为真，否一推肯一；找矛盾：或变且、各加非。要么A要么B：一真一假；同真同假才是矛盾。

1.4 假言命题（第 2 次课 · 重中之重）

翻译推理是整套逻辑的地基，后面的综合推理、朴素逻辑全都要用到。核心就两步：先翻译，后推理。

第一步 · 翻译（背熟对应关系）

关联词翻译口诀
如果A，那么B；只要A，就B；A是B的充分条件A → B如果就，前推后
只有A，才B；除非A，否则不B；A是B的必要条件B → A只有才，后推前
除非A，否则B非A → B除非否则，否前推后
A当且仅当BA ↔ B充要互推
✏️ 翻译口诀
「如果就，前推后；只有才，后推前；除非否则不，后推前；除非否则，否前推后；充分必要别搞混，充前必后记心间。」

第二步 · 推理（三大规则）

① 逆否等价：A → B = 非B → 非A（王道规则）
② 递推：A → B，B → C，可得 A → C
③ 有效形式：肯前必肯后，否后必否前；否前、肯后推不出确定性结论
例 · 逆否等价
古人云：「不到长城非好汉。」以下哪项与古人表达的意思一致？
① 到了长城的人就一定是好汉　② 如果是好汉，他一定到过长城　③ 只有好汉，才到过长城
思路：翻译：「非长城 → 非好汉」。逆否等价 → 「好汉 → 长城」，即②。①③都翻译成「长城 → 好汉」，错了。选②。

矛盾与等价（连接命题部分的关键）

A → B 的矛盾 = A 且 非B（最强否定，反驳它直接找这个）
A → B 等价于 非A 或 B（「或」与「推」互转，为综合推理奠基）
例 · 假言矛盾（知假求真）
「如果明天下雨，那么运动会取消」为假。据此可以推出：
思路：A → B 的矛盾 = A 且 非B → 推出「明天下雨 且 运动会没有取消」。注意别选「明天不下雨」——那是「否前」，从假言为假推不出。

知真求假 / 知假求真类：直接找矛盾（汇总）

命题矛盾命题
联言：p 且 q非p 或 非q
相容选言：p 或 q非p 且 非q
不相容选言：要么p，要么q要么p且q，要么非p且非q
假言：p → qp 且 非q
✏️ 口诀
「逆否等价是王道，否后必否前牢牢记」；「真假判断看矛盾，A且非B一招毙」；「或且转化德摩根，去括号时分负号」。德摩根：非(A且B) = 非A或非B；非(A或B) = 非A且非B。

1.5 综合推理（第 3 次课 · 母题三、四、五）

识别：题干涉及假言（→），问法「知真求真」，选项多为事实判断。核心思想：母题三到母题五的思路是递进的——先用确定性，再数量限定，最后假设法、二难推理。

母题三：有确定信息 → 从确定信息破题

1
找到题干中确定的事实信息（直接给的事实/算出的事实），把它作为推理起点。
2
沿着与该信息相关的条件依次推理（找相关：跟它出现在同一条假言里的内容）。
3
注意题目是推结论（13-15 题式）还是推前提（16 题式），别推反方向。

母题四：有数量限定 → 通过数量限定破题

1
题干出现数量限定（如「最多X个」「至少Y个」）→ 先把数量算出来，可直接得到部分选项。
2
把算出的数量当作确定信息，代入假言命题作「肯前」或「否后」触发推理。

母题五：确定信息、数量限定都用不上 → 假设法 + 二难推理

1
假设起点：优先假设「前真（后假）」，即假设 A→B 中的 A 为真（或 B 为假）。
2
推演找冲突：①看单条假言内部是否有冲突；②把多条假言「串串」找冲突。
3
冲突点常考：(1) 与题干已有信息冲突（尤其数量限定）；(2) 推出相冲突的信息。
二难推理：A → B；非A → B 　⇒　 B 恒真
例 · 二难推理
某教授说：「如果你们按时完成作业，我就给你们加平时分；如果你们没有按时完成作业，我也给你们加平时分。」由此可以推出：
思路（程意式）：翻译：按时 → 加分；非按时 → 加分。无论「按时」还是「非按时」总有一个成立，而两者都能推出「加分」→ 教授一定会给你们加平时分（B 恒真）。这就是「非黑即白，殊途同归」的二难推理。
例 · 综合推理（2024 广东）
如果某地不禁止在鱼类繁衍季节捕鱼，当地的鱼类资源就会枯竭。如果鱼类资源枯竭了，当地渔民的渔业生涯就会终结。只有鱼类资源良性循环，渔民的收入才能得到保障。由此可以推出：
思路：翻译：① 非禁止 → 枯竭；② 枯竭 → 生涯终结；③ 收入保障 → 良性循环。选项 C「渔业生涯没有终结 → 当地一定禁止在鱼类繁衍季节捕鱼」= ②逆否（非生涯终结 → 非枯竭）+ ①逆否（非枯竭 → 禁止），正确。其余选项都是「肯后/否前」的错误形式。
⚠️ 易错点
  • 肯后推不出：如「收入得到保障 → 资源良性循环」是③的肯后，推不出。
  • 否前推不出：「禁止捕鱼 → 收入有保障」是①的否前，推不出。
  • 综合推理先整体翻译，再按「确定信息 → 数量限定 → 假设法/二难」顺序找破题口。

1.6 三段论（第 4 次课）

定义：由包含着一个共同项的两个性质判断为前提，推出一个新的性质判断为结论的推理形式。

所有A是B，所有B是C 　⇒　 所有A是C
  • 结构：大项 P（结论中的谓项）、中项 M（前提中出现、结论中不出现，起桥梁作用）、小项 S（结论中的主项）。
  • 秒杀核心：找中项 B——B 是连接 A 和 C 的桥梁，在前提中出现两次，与「所有」相连。

三段论规则（违反即错）

规则内容
① 三个概念一个三段论中只能有三个不同的项（防偷换概念）
② 中项周延中项在前提中至少周延一次
③ 不周延不扩大前提中不周延的项，在结论中也不得周延
④ 否定前提两个否定前提不能得出结论
⑤ 否定与结论前提中有一个否定，结论必否定；前提都肯定，结论必肯定
✏️ 口诀
「所有」和「否定」是周延的；「有的」和「肯定」是不周延的。画图法：用集合关系（圆圈）验证，快速排除。
例 · 三段论补前提（找中项）
有些导演留大胡子，因此，有些留大胡子的人是大嗓门。要使上述推理成立，必须补充以下哪项作为前提？
思路（程意秒杀）：中项是「导演」（前提出现、结论不出现）。结论「有些留大胡子的人是大嗓门」= 有些B是C；已知前提「有些导演留大胡子」= 有些A是B → 缺的是「所有A是C」即「所有导演都是大嗓门」。口诀验证：中项「导演」要在前提中周延一次，只能由「所有」提供。

1.7 朴素逻辑（第 5 次课 · 解题思路及秒杀技巧）

总思路：先判断有序型（排序/位置）还是无序型（分组/对应），突破口永远两个词：确定性、关联性。

（一）题型与突破口

类型突破口说明
有序型（排序）占位多的条件（注意平铺与交叉）被提及最多的元素先放
有序型（排序）捆绑元素「A紧挨B」整体处理
有序型（排序）相对先后顺序「A在B前」画箭头、标区间
无序型（分组）二选一原则条件只给两种可能时，分情况讨论
无序型（分组）占位不定位只确定在某组，不急着定具体位置
通用确定性 + 关联性先找最确定的，再找关联最多的

（二）秒杀技巧（程意课堂重点）

⚡ 技巧 1 · 数独题型
解题思路：① 排除；② 从行、列、交集最多的格子入手。
⚡ 技巧 2 · 3+2 分组
从 2 个角度把人分成 3+2：相同归大，去排除。
⚡ 技巧 3 · 4人中 4+3+2
① 找 3 人条件中被孤立的那个人；② 找他在 2 人条件中的伙伴。
⚡ 技巧 4 · 问最多、最少
最多：两个分类做加和。最少：两个分类选数大的。注意：去除包含的数量。
⚡ 技巧 5 · 不等式推理
A>B；C>D。AB 是矛盾的，CD 是矛盾的。只可得 AC > BD（取各自较大/较小组合比较）。
例 · 最多最少
某单位有 30 名党员，其中 18 人参加了党课培训，15 人参加了业务竞赛。问：两项都参加的最多有多少人？最少有多少人？
思路（程意口诀）：最多 = 两个分类取小者 = 15 人（≤15 那个）。最少 = 两个分类加和减总数 = 18 + 15 − 30 = 3 人。（「选数大的」指两类人数中较小的重叠上限；本质用容斥原理：两项都参加 ≤ min(18,15)=15；最少 = 18+15−30=3。）
例 · 确定性 + 关联性（职业对应）
甲、乙、丙三人中，一人是律师，一人是教师，一人是医生。已知：① 甲比医生的年龄大；② 教师比乙的年龄小；③ 丙和教师不同岁。问：三人各是什么职业？
思路（程意式）：突破口 = 确定性 + 关联性。②「教师比乙小」→ 乙不是教师；③「丙和教师不同岁」→ 丙不是教师 → 剩下的甲一定是教师。再由②：教师（甲）比乙小，即甲比乙小；① 甲比医生大 → 甲比医生大又比乙小 → 乙不是医生 → 乙是律师，丙是医生。推理链条：先确定唯一位置（教师），再顺藤摸瓜。

1.8 一拖N（第 6 次课）

介绍：一般由一个题干 + 多个小题组成，题干整体类似朴素逻辑。用时目标：一拖二 2-3 分钟（保 3 争 4）；一拖五 5 分钟（7-8 分钟内，保 4 争 5）。

第一步 · 分析题干信息（一拖五约 1-2 分钟）

1
分析背景：明确题干属于有序型还是无序型（分组型），有几类元素、每类几种。
2
题干信息整合：突破口 = 确定性、关联性。排序中注意：占位多的条件、捆绑元素、相对先后顺序、间隔占位信息、数量限制。
3
符号表达：形成自己的符号系统（见下），把文字翻译成符号。
符号含义
ABA 在 B 左，且紧挨着
A BA 在 B 左边，不确定是否紧挨
A□BA 在 B 左，且 AB 之间有一个东西
⇄位置可互换（箭头）

第二步 · 解题与代入判断

  • 通过整合题干得到的信息，可用于所有题目（一拖N的第一价值）。
  • 有补充条件：从补充条件入手，结合已知条件推理，推完排除选项，不行再代入。
  • 通过问法判断是否适合代入：
    问法处理
    可能为真可以代入：代入选项，若能满足题目所有已知信息，可选
    不可能真可以代入：代入选项，若与题干已知确定信息冲突，可选
    一定为真 / 可以推出建议正推，不适合代入；如必须代入，注意是「一定真」还是「可能真」

秒解技巧 & 蒙猜技巧

⚡ 秒解

  • 关注选项信息异同：选项全面的（直接列出完整安排），直接排除/验证。
  • 最后 2 个题可能直接运用之前题目的结论。
  • 代入时优先代入能结合已知信息推理的选项。
  • 排序题：前有 N 个人，则不能在前 N；后有 N 个人，则不能在后 N。

🎲 蒙猜（时间不够用）

  • 问「可能」→ 优先选含有「题干限制信息中未提及的元素」的选项。
  • 问「不可能」→ 排除出现「同质元素」的选项。
  • 问 A 和 B 最多隔几排 → 优先验证选项中的最大数字。
  • 问 A 和 B 最少隔几排 → 优先验证选项中的最小数字。
例 · 排序型（2025 天津事业单位改编）
某边防哨卡每日必须有士兵站岗，每天从 A、B、C、D、E、F、G 七位士兵中选择一位站岗，每位士兵每周只站岗一次。已知：① B 必须在周二，E 必须在周四；② A 在 D 前面站岗，且中间恰好隔一位；③ F 和 G 在相邻两天站岗。问：C 排在周一，则以下哪项一定为真？
思路（程意式）：有补充条件（C 周一）→ 从补充条件入手。画 1-7 位置：周一C，周二B，周四E；A□D 占位 + F、G 相邻 → 逐步排除，推出结论。
例 · 代入判断（可能为真）
某次会议有 5 位代表，分别来自浙江、江苏、山东、广东、四川。已知：① 浙江代表不在第 1 位；② 江苏和山东代表相邻；③ 广东代表在四川代表之前且中间恰好隔一位。问：以下哪项可能是五位代表的正确顺序？
A. 浙江 江苏 山东 广东 四川　B. 山东 江苏 广东 四川 浙江　C. 四川 广东 江苏 山东 浙江
思路（程意式）：问「可能为真」→ 直接代入验证。A：浙在第 1 位，违反① ✗；B：苏鲁相邻 ✓、粤川中间隔一位 ✓、浙不在第 1 ✓ → 选 B；C：粤在川前但紧挨（没隔一位），违反③ ✗。注意「可能为真」只找一个能满足所有条件的即可，不必是唯一排列。

模块二 · 可能性推理（加强削弱）

POSSIBLE REASONING
特点：不考公式记忆，考「读题 → 理结构 → 预设答案 → 比选项」。基础能力（第7课）→ 因果类（第8课）→ 论证模型秒杀（第9课）→ 前提/解释/结论/评价（第10课）。

2.1 加强削弱 · 基础能力（第 7 次课）

标准化流程：读问题 → 理结构 → 预设思路

1
读问题，辨题型：是加强还是削弱？是「最能加强/削弱」还是「不能加强/削弱」？看清再动笔。
2
理清题干结构：找出结论（标注 ☆）和论据。问自己：论据是什么？结论是什么？中间缺了什么？
3
预设思路：先想「正确选项大概长什么样」——加强/削弱的力度从强到弱排好，再去选项里找对应表达。

常见迷惑选项（看见先警惕，往往不选）

🚫 与题干论证无关型

  • 对象不一致：偷换讨论对象/范围
  • 概念不一致：偷换核心概念
  • 时间不一致：时间点/段对不上
  • 选项与不相关事物做比较
  • 题干有趋势，选项无趋势
  • 诉诸无知（注意：不是完全无关，但力度弱）：「尚不清楚」「无法证明」
  • 表述不明确：说得很模糊，无法判断影响方向

🚫 因果类设错（题干讨论因果关系时）

  • 选项只有因 或 只有果（不完整，不构成削弱）
  • 因果关系错位：把因说成果、果说成因方向不对
  • 因导致其他果：承认因存在但指向别的结果
  • 果的果：在结果上再叠结果
  • 因的因：在原因前再找原因（≠另有他因，小心区分）

力度比较（选答案时的优先序，要记住）

✏️ 力度排序
本质 > 现象；全面 > 片面；确定 > 可能；量大 > 量小（无需背，理解即可）。
✏️ 常见加强方法
解释因果、有因有果、无因无果（加强三件套）。
例 · 力度比较与迷惑选项
某调查发现，坚持长期喝茶的老人更长寿。研究者据此认为：喝茶能延年益寿。以下哪项最能削弱上述结论？
A. 有些从不喝茶的老人也很长寿　B. 目前尚无法证明喝茶与长寿之间存在因果关系　C. 喜欢喝茶的老人大多注重饮食健康、经济条件也较好　D. 茶中含有茶多酚等有益物质
思路（程意式）：结论「喝茶 → 长寿」，削弱依次比较：A 是反例（有因无果的反面），但样本个别、力度弱；B 是诉诸无知（「尚无法证明」），力度弱；C 提出「注重饮食健康」这一另有他因，从本质上解释长寿另有原因，力度最强，选 C；D 在加强。口诀：本质 > 现象，确定 > 可能。

2.2 因果类题型（第 8 次课）

因果论证两大类题干形式，对应两套处理思路：

形式一：题干给事实 A、B，推测 A、B 之间有因果关系

1
普适性思路：把题干调整为一个实验，看哪个选项能成为实验的「变量」。
2
简便方法：① 正确选项的「因」常体现为与题干已给的因同主体；② 当题干论据以「同时发生」形式出现时，选项补充的「因」还要与论据中的 2 件事同时间。

形式二：题干给事实 A，推测原因是 B

1
关注题干的「果」是什么。
2
直接给果找他因即可（另有他因）。
  • 另有他因通用标准：选项补充的「因」，要与题干的「果」有一定的关系。
  • 另有他因的要求：引入的因可能影响结果（例：小郑跑步+游泳→瘦，A「小郑还常游泳，游泳能瘦」✓；B「小郑还常游泳」（没说能瘦）✗；C「小郑每天背5个单词」✗）。

常见削弱方法（因果类，按力度排列）

方法含义说明
因果倒置颠倒因果关系/颠倒时序力度强，出现直接选
另有共因题干：A导致B；选项：C导致A和B力度强，出现直接选
有因无果 / 无因有果有因却无果；无因却有果注意：无果 = 果的反面，无因 = 因的反面
否定此因原因不成立 / 原因不起作用力度强，出现直接选；若论据已明确「因」是事实，别选「原因不成立」
另有他因引入新原因，证明可能不是题干原因导致结果最常考；引入的因要可能与结果相关
⚠️ 另有他因的两类题干
  • 给事实 A、B，推测 A、B 之间有因果（易出难题）：小郑跑步→瘦，小华不跑步→不瘦，推测跑步使人瘦。削弱 A：小郑还常游泳（同主体补他因）；B：游泳也能使人瘦（不同主体也能削弱，力度弱于同主体）。
  • 给事实 A，推测原因是 B：小郑瘦了，推测因为跑步。削弱：他最近节食/生病等。
例 · 因果倒置（力度最强，出现直接选）
某调查发现，经常使用社交媒体的青少年更容易焦虑。研究者据此认为：使用社交媒体导致了青少年焦虑。以下哪项最能削弱上述结论？
A. 感到焦虑的青少年更倾向于通过刷社交媒体来缓解情绪　B. 使用社交媒体时间较少的青少年中也有焦虑者　C. 社交媒体上也有大量积极向上的内容　D. 该调查的样本主要集中在城市
思路（程意式）：题干：社交媒体 → 焦虑。A 说其实是「焦虑 → 沉迷社交媒体」，把因和果颠倒了，是因果倒置，力度最强，直接选；B 是反例但样本个别；C 无关；D 质疑样本，力度弱。口诀：因果倒置、另有共因，出现直接选。

2.3 八大论证模型秒杀技巧（第 9 次课）

核心思想：判断出模型 → 答案就已经预判出来了。题干长相固定，答案形式固定。读完题干先判断模型，再按模型预判答案，最后到选项中找对应表达。

模型 1 · 求异论证

根据两组实验对象的差异，得出 A 是 B 的原因。

  • 加强：两组实验对象的相关相同点；解释因果
  • 削弱：两组实验对象的相关不同点

模型 2 · 双观点

原观点：A 是 B 的原因；反对者：C 是 B 的原因。

  • 削弱反对者：A 是 C 的原因
  • 削弱原观点：C 是 B 的原因（即支持反对者）

模型 3 · 实践论证

采取方案 A，达到目的 B。

  • 加强：方案 A 可实现；采取方案 A 能达到目的 B
  • 削弱：方案 A 不可实现；采取方案 A 也达不到目的 B

模型 4 · 类比论证

由两个对象相似，推出某结论。

  • 加强：找根本相同属性
  • 削弱：找根本不同属性

模型 5 · 枚举归纳

由部分样本推出整体结论。

  • 加强：样本具有代表性
  • 削弱：样本不具有代表性

模型 6 · 缺桥论证（搭桥/拆桥）

论据说 B，结论说 C，中间缺桥。

  • 加强：建立 B 和 C 之间的联系（搭桥）
  • 削弱：切断 B 和 C 之间的联系（拆桥）

模型 7 · 数据论证

论据往往包含数字（分子部分）。

  • 通过找到数字的分母部分（基数/总量），从而加强或削弱

模型 8 · 结论有比较

结论涉及比较关系（谁比谁强/多/快）。

  • 优先选有比较的选项（选项也在做同类比较才扣题）
例 · 求异论证（经典题）
某研究将两组小鼠置于相同环境，实验组喂高脂饲料、对照组喂普通饲料，结果实验组更易肥胖。结论：高脂饲料导致肥胖。以下哪项最能削弱？
思路：求异论证 → 削弱找「两组实验对象的相关不同点」，如「实验组小鼠本身携带肥胖基因」。
例 · 双观点
原观点：全球变暖是二氧化碳排放导致。反对者：是太阳活动导致。以下哪项最能削弱反对者？
思路：双观点削弱反对者 = 「A 是 C 的原因」= 「二氧化碳排放是太阳活动的原因」。
例 · 实践论证（方案与目的）
某市为缓解市中心交通拥堵，计划向进入市中心的车辆征收拥堵费。以下哪项最能削弱该方案？
A. 征收拥堵费后，部分车主会改乘公共交通　B. 市中心公共交通运力严重不足，且该方案实施成本高昂　C. 其他城市征收拥堵费后，市民满意度有所下降　D. 拥堵费收入将用于改善公共交通
思路：实践论证 = 「方案 A → 目的 B」。削弱 = 方案不可实现 / 达不到目的。B 同时指出方案不可行（成本高）且达不到目的（运力不足，收钱也缓解不了），力度最强，选 B；A、D 在加强；C 是无关比较（满意度≠拥堵），且「其他城市」类比力度弱。
例 · 枚举归纳（样本代表性）
为了解全市市民对垃圾分类的看法，调查员只在某高档小区门口随机采访了 100 位居民，绝大多数表示支持。于是得出结论：全市市民普遍支持垃圾分类。以下哪项最能削弱该结论？
A. 高档小区居民的环保意识和收入水平较高　B. 支持者中年轻人居多　C. 采访时间都选在周末上午　D. 100 人的样本量偏小
思路：枚举归纳（样本 → 整体）。削弱 = 样本不具有代表性。A 指出样本集中在高档小区、不能代表全市，直接削弱，选 A；D 虽提及样本量小，但没有说明样本偏差，力度弱于 A。
例 · 数据论证（找分母）
某市去年共发生交通事故 5000 起，其中夜间发生的占 40%。据此有人认为：夜间行车比白天更危险。以下哪项最能削弱该结论？
A. 该市夜间通行的车辆约占全天总车流量的 40%　B. 夜间发生的多为轻微刮蹭事故　C. 白天事故数量为 3000 起　D. 夜间司机大多更加谨慎
思路：数据论证 → 找到数字背后的分母。分子：夜间事故占 40%；A 给出分母：夜间车流量也占 40% → 事故率（事故数/车流量）与白天持平，并无更危险，选 A。这就是程意说的「数据题找分母，分子孤零零没有说服力」。

2.4 前提 / 解释 / 结论 / 评价型（第 10 次课）

① 前提型（假设/前提）

  • 识别：问「上述论证基于以下哪项前提/假设」「需要补充哪项」。
  • 思路：找论据与结论之间的跳跃概念，答案 = 把两者连起来（搭桥）。
  • 验证法：把选项否定后代入，若题干论证坍塌，则该选项是必要前提。
  • 注意：前提必须保证题干论证成立；搭桥是前提型最常考答案。

② 解释型

  • 识别：题干给出一个看似矛盾的现象，问「以下哪项最能解释」。
  • 思路：找一个条件/原因，让两个矛盾现象同时成立、不再矛盾（补充条件式解释）。
  • 原则：解释要能同时兼顾矛盾双方，不能只解释一半；优先选客观原因。

③ 结论型（日常结论）

  • 识别：问「由此可以推出」「可以得出以下哪项」。
  • 思路：严格依据题干，能推出什么选什么，不推理过度。
  • 慎选：绝对化表述（一定/必然/所有）、无中生有、偷换概念、与题干相反的选项。
  • 优选：语气较弱的「可能」「有些」「未必」等从题干能推出的表述。

④ 评价型

  • 识别：问「以下哪项与题干论证方式/逻辑错误最为相似」。
  • 思路：只看论证形式，不看内容。把题干翻译成符号（如 A→B），找选项里形式一致或错误类型一致的。
  • 常见逻辑错误：偷换概念、以偏概全、诉诸权威、因果倒置、循环论证等。
例 · 前提型（搭桥）
某市号召市民多乘坐地铁，理由是：地铁能减少碳排放。要使该论证成立，必须基于以下哪项前提？
A. 市民愿意放弃私家车改乘地铁　B. 地铁运行本身产生的碳排放相对较低　C. 碳排放是导致气候变暖的主要原因　D. 私家车的碳排放高于公交车
思路（程意式）：论据「坐地铁」→ 结论「减排」，中间有跳跃：坐地铁为什么能减排？需要搭桥「地铁本身的碳排放低」→ 选 B。A 是方案可行性（成立还需要它，但不是最核心的跳跃点）；验证法：否定 B（地铁碳排放很高），论证立刻坍塌，说明 B 是必要前提。
例 · 解释型（兼顾矛盾双方）
某品牌牛奶今年的销量大幅增长，但该品牌的广告投放量却明显减少了。以下哪项最能解释这一看似矛盾的现象？
A. 该品牌口碑好，老顾客自发向亲友推荐　B. 广告减少后，该品牌节省了大量成本　C. 其他乳业品牌今年的销量普遍下滑　D. 该品牌今年更换了广告公司
思路：要解释「广告少了但销量涨了」两个事实同时成立。A 用「口碑推荐」说明不靠广告也能拉动销量，同时兼顾双方，选 A；B 只解释成本、没解释销量；C 与题干无关；D 换广告公司 ≠ 投放量减少，解释不了。
例 · 评价型（只看形式）
题干：所有爱看书的人都有耐心，小明很有耐心，因此，小明爱看书。以下哪项与题干的论证方式最为相似？
思路（程意式）：把题干翻译成符号：A → B，B（小明有耐心），推 A。这是典型的「肯后」错误形式。选项里找同样「A→B，B ⇒ A」结构的——如「所有参加过培训的人都能通过考试，小李通过了考试，因此小李参加过培训」✓。评价型只看形式不看内容，把每个选项符号化再比对。
三

模块三 · 图形推理（第 12-17 次课）

FIGURE REASONING
图推不考理解，考观察。核心逻辑：把规律背下来，做题时一个个套，总能套上。做到「一看就定位考点」，形成条件反射。单题控制在 40-50 秒。

3.1 总思维框架（刘义恒「图推命题思维」）

观察图形组成是否相同
→
有相同位置 / 样式 / 标记
→
无相同属性 → 数量 → 图形间关系
  • 元素组成相同 → 位置规律（平移/旋转/翻转）。
  • 元素组成相似（有重复元素）→ 样式规律（遍历/加减同异/黑白运算）。
  • 元素组成不同 → 先属性（对称性优先级最高），后数量；属性数量都不行 → 特殊规律/图形间关系。
✏️ 宏观思维（无相同）
① 先属性，后数量，且对称性优先级最高；② 背诵数量规律中的图形特征，直接定位考点；③ 极端情况，优先考虑「图形关系」。作图特点决定大方向：规则图形→对称；有曲线→曲直；生活化→开闭/面；被分割→面；线条杂乱→点线笔画。

3.2 位置规律（必考）

特征：图形长得一模一样，只是位置在变。

规律要点
平移方向（上下左右、斜对角线；绕圈顺/逆时针）＋ 步数（恒定/递增等差）。
宫格类看中间判方向：中间黑块数量相同→可能绕圈走；中间黑块数量不同→可能走直线（循环走/走直线）。
旋转方向（顺/逆时针）＋ 角度（30°、45°、60°、90°、180°）。旋转不改变手性（不会左右颠倒）。
翻转左右翻转：左右变、上下不变；上下翻转：上下变、左右不变。翻转改变手性（左变右）。
判别金钥匙：盯住一个不对称细节看它左右反没反。
✏️ 口诀
长得一样看位置，移转翻三选一。顺逆时针绕圈圈，角度变化是关键；横轴对称上下翻，竖轴对称左右转。翻转照镜子（手性反），旋转转圈圈（手性不变）。
例 · 平移（绕圈）
3×3 宫格中有一个黑色圆点，按顺时针沿外圈每次移动一格：第 1 幅图黑点在外圈左上角，第 2 幅图在外圈上边中间，第 3 幅图在外圈右上角。问：第 6 幅图黑点应在什么位置？
思路（程意式）：外圈 8 个位置顺时针编号：左上①→上中②→右上③→右中④→右下⑤→下中⑥→左下⑦→左中⑧→回到①。第 1 幅在①、第 2 幅在②、第 3 幅在③……第 6 幅在⑥下边中间。识别口诀：宫格题先看中间黑块数量——黑块数不变 → 绕圈走；变多/变少 → 可能走直线或看数量。
例 · 旋转（角度恒定）
图 1 是一个开口向右的「∠」形，图 2 开口向下，图 3 开口向左，图 4 开口向上。问：图 5 的开口方向？
思路：每个图形整体顺时针旋转 90°：右→下→左→上→右。图 5 开口应向右（回到图 1，形成周期）。旋转不改变手性——若题干图形有左右不对称细节（如「F」），旋转后仍是「正 F」，翻转才会变成「反 F」，以此区分旋转与翻转。

3.3 样式规律（高频）

特征：图形长得像，有重复元素。

规律要点
遍历每种样式都出现一次，「缺什么补什么」（元素遍历/样式遍历/位置遍历）。
加减同异前两幅图叠加 → 第三幅：直接叠加、去同存异、去异存同。
识别：前两幅有明显一样的线条 → 优先运算；没有一样的线条 → 优先位置。
黑白运算黑白块叠加有规律（黑+黑=白、黑+白=黑……）。
识别：黑块数量相同 → 优先位置；黑块数量不同 → 优先黑白运算。
✏️ 口诀
长得像看样式，遍历叠加和求异。元素重复要遍历，缺啥补啥不费力；线条重复找同异，颜色数量不同时，轮廓相同看运算。
例 · 加减同异（去同存异）
九宫格第一行：图 1 是「十」字形，图 2 是「一」字形（横线），图 3 是「丨」字形（竖线）。第二行：图 1 是「X」形，图 2 是「\」形（左上到右下的斜线），问：图 3 是什么？
思路（程意式）：第一行「十」与「一」去同存异（去掉共有的横线）→ 得「丨」✓，确认运算规则。第二行「X」（两斜线）与「\」（左下到右上方向的斜线）去同存异 → 留下另一条斜线「/」（右上到左下方向）。识别口诀：前两幅有明显一样的线条 → 优先想运算。
例 · 黑白运算（识别：黑块数量变）
两个 2×2 黑白块图形叠加，已知：黑+白=黑、白+黑=黑、黑+黑=白、白+白=白。图 1 左上黑、右下白；图 2 右上黑、左下白。问：叠加后 2×2 图形的黑白分布？
思路：逐格运算：左上（黑+白）=黑；右上（白+黑）=黑；左下（白+黑）=黑；右下（白+白）=白 → 结果是「左上、右上、左下黑，右下白」。识别口诀：黑块数量相同 → 优先位置；黑块数量不同 → 优先黑白运算。

3.4 属性规律（必考）

特征：元素组成不相同、不相似，但一眼能看出某种属性。

属性考点细化
对称性
（优先级最高）		① 轴对称（等腰/等边特征：沿轴对折重合）；② 中心对称（N/Z/S形、平行四边形：旋转180°重合）；③ 轴对称+中心对称（有两条垂直对称轴）；④ 对称轴的数量和方向；⑤ 对称轴与图形线（是否重合）、点（是否相交）、面（数量）的关系；⑥ 两个图形挨着/分开时，分别看两图对称轴（垂直、数量、方向）。
曲直性全直线（多边形、单一直线）；全曲线（圆、弧）；曲+直。
识别：出现明显的圆、弧等全曲线图。
开闭性全封闭（大门关门）、全开放（大门敞开）、半开半闭（别的不行才考虑）。
识别：生活化图形（汉字、字母、数字）常考开闭。
✏️ 口诀
一眼看去抓属性，对称曲直和开闭。N形、Z形、S形、平行四边形，原地旋转180度就是中心对称；有两条垂直对称轴的是轴对称+中心对称。单一线条看曲直，曲直共存别忘记；遇到开口看开闭，半开半闭最后想。
例 · 对称性（找不同）
下列四个图形中，与众不同的一个是：
A. 正方形　B. 圆形　C. 等边三角形　D. 平行四边形
思路（程意式）：对称性优先级最高，先看对称。A、B、C 都是轴对称（且正方形、圆形还是中心对称）；D 平行四边形只有中心对称、不是轴对称 → 选 D。延伸：若图形出现「N、Z、S、平行四边形」→ 直接想到中心对称；有两条垂直对称轴 → 轴对称+中心对称。

3.5 数量规律（常考，也最难）

特征：元素组成不同，且属性无规律时，就数数。数量题「没找到规律」，九成是「还没数到对的那一类」。可数对象六类：点、线、角、面、素、笔画。

✏️ 口诀
乱七八糟数数量，点线角面素挨个试。数列规律：等差、等比、周期、平方、奇偶，还有最易被忽略的「恒定」。

① 面数量【高频】

  • 什么是面：白色的封闭区域。黑色不是面
  • 出题者作图特征：图形被分割、封闭面明显、生活化（汉字/字母/数字）。
  • 基础考法：面的数量、面的运算（九宫格：一行相加/二行相加=三行等；如 2+3=5、2+3+5=10）。
  • 细化考法：
    • （1）所有面：分割后每一个面的形状（整体思想）——只有 2 种面时做三角形与四边形运算（相减/倍数/相加）；只数三角形（拆分思想，三角形-高频：单数、递增、运算）；「每个面的边长数相同」。
    • （2）大小面：最大面、最小面——难点在与形状、属性、面积的结合（形状：三角形/四边形；与外框关系：自己/邻居；属性：最大/小面对称性、曲直性；面积：占原图一半）。

② 线数量

  • 直线数（多边形、单一直线）、曲线数（圆、弧、单一曲线）、直曲线分别数。
  • 笔画数（重点）：图形笔画数 = 奇点数 ÷ 2（奇点：从某点出发的线段条数为奇数）。奇点数为 0 或 2 → 一笔画；每多 2 个奇点，多一笔。
  • 识别：线条杂乱、端点日田领着头、交圆切圆傍地走 → 想笔画。

③ 点数量

  • 交点（线条交叉明显）、切点（圆相切/相交多）、框上/框内交点（金钟罩外框）。
  • 注意：切点属于交点，端点不属于交点。
  • 图形有曲又有直 → 优先考虑曲直交点。

④ 角数量

  • 折线折出多个角，留了缺口别忘角；横平竖直多垂直 → 直角数量。
  • 考法：全部角数、直角数、锐角数、钝角数。

⑤ 素数量（元素）

  • 独立小图形：元素种类数、元素个数、相同元素（个数）、部分数。
  • 生活化/粗线条图形 → 常考部分数量。
  • 注意：形状一样颜色不一样算不同元素；数面时空白区域都算，不管大小。

实战思维

  • 背诵图形特征 → 直接定位考点；细化没规律 → 回到面。
  • 相邻比较：核心——相邻两幅图之间「有一样的部分」；易错——「不一样的部分」可以有规律，也可以没规律。
  • 立体考查平面 → 面、点；生活化 → 面；九宫格 → 面运算。
✏️ 数量口诀汇总
大树杈子多 → 数交点；曲直交叉明显 → 曲直点；圆与直线相切多 → 切点；横平竖直 → 分横竖数/数直角；线条乱 → 笔画（奇点法）；窟窿多 → 数面；面形状 → 三角形/四边形；明显大小面 → 看形状属性；小图形多 → 种类和数量；生活化粗线条 → 部分数。
例 · 笔画数（奇点法）
下列图形中，不能一笔画成的是：
A. 五角星　B. 「日」字（外框+中间一横）　C. 圆形　D. 直线与圆相切（一条直线恰好与圆相切）
思路（程意式）：笔画数 = 奇点数 ÷ 2。A 五角星：所有交点都连偶数条线，奇点 0 → 一笔 ✓；B「日」字：外框四个角各连 3 条线 → 4 个奇点 → 2 笔，不能一笔画；C 圆：0 奇点 → 一笔 ✓；D 相切图：切点连 2 条（偶），直线两端各 1 个奇点 → 2 个奇点 → 一笔 ✓（从一端画到另一端）。答案选 B。识别：线条杂乱、端点日田领着头 → 想笔画。
例 · 面数量（白色封闭区域）
汉字「日」有几个面？汉字「品」有几个面？汉字「田」有几个面？
思路（程意式）：面 = 白色封闭区域，黑色不是面。「日」：中间一横把口分成上下两块 → 2 个面；「品」：三个口互不相连 → 3 个面；「田」：横竖两线与外框交叉，形成 4 个小格 → 4 个面。识别：汉字/字母/数字、图形被分割、窟窿明显 → 数面；细化再看面的形状（三角形/四边形）、大小面。

3.6 特殊规律与空间类

① 特殊规律（偶尔考）

考点要点
功能元素图上有黑点、小三角形、小圆、箭头等标记 → 看点与线/面的关系、标记之间的位置关系（同侧/异侧）。
图形间关系只有两个图形：相交（相交部分相似、边数、面积大小）、相接（公共边、公共点）、相离；包含、外切内切。

② 空间重构（六面体）

  • 相对面法：一组相对面永远不相邻，排除含相对面相邻的选项。
  • 相对位置法（公共边/公共点）：通过公共边判断相邻面的位置关系。
  • 画边法：选定一个面，按同一方向标边，比对选项。
  • 口诀：复杂立体折叠，重点看选项相异部分边长是否对齐，不能对齐的就是错误选项。

③ 三视图 / 截面图 / 立体拼合

  • 三视图：正视图（从前往后）、侧视图（从左往右）、俯视图（从上往下）；注意遮挡关系、虚线表示不可见棱。
  • 截面图：判断截面形状时，先找平行/垂直切面，看切到的棱和面；正方体截面最多六边形。
  • 立体拼合：数小方块数量 + 分层比对（层数、每层形状），用「整体-已知=所求」。
例 · 截面图（正方体）
一个正方体被一个平面斜着切开，截面不可能是以下哪种形状？
A. 三角形　B. 四边形　C. 五边形　D. 七边形
思路（程意式）：正方体有 6 个面，一个平面最多与 6 个面相交 → 截面最多是六边形，七边形不可能 → 选 D。三角形（切一个角）、四边形（平行于棱切）、五边形、六边形（斜切穿过 6 个面）都可能。考场速记：正方体截面：三角到六边，多多益善看切法。
⚠️ 图推考场策略（程意建议）
  • 放在判断推理开头做：图推不费脑子，用来进入状态。
  • 30 秒看不出规律，先蒙一个并标记，做完回来再看，不恋战。
  • 不要反复检查，相信第一感觉（改错的概率比改对的大）。
  • 笔画数单独记：看到杂乱线条先想一笔画。

模块四 · 类比推理（第 18-19 次课）

ANALOGY
题目短小易读、做得快，但考点复杂（碎）且常结合常识考查，实际难度不低。要突破：① 明确做题核心原则；② 弱化主观性想法，强化常考考点的记忆和使用；③ 边做题边积累常识。

4.1 考查形式与核心原则

形式示例
两项式龋齿 : 嗜食甜品　→　运动 : 增强体质
三项式路由器 : 连接 : 网络　→　石英钟 : 显示 : 时间
括号式桌子 之于（ ）相当于 车轮 之于（ ）

三大核心原则

1
常态思维：用普遍认可的关系理解题干，不钻牛角尖、不用冷门角度。
2
先横后纵：先横向比较题干两个词的逻辑关系；横向无法区分时，再纵向比较选项与题干的相似性（字词结构、词性、感情色彩等）。
3
先整体后局部：如「声东:击西」整体是成语对成语（围魏:救赵），不要拆开看字义（说东:道西）。
例 · 三项式造句法
路由器 : 连接 : 网络 —— 以下哪项与题干逻辑关系最为相似？
A. 石英钟 : 显示 : 时间　B. 空调 : 制冷 : 房间　C. 铅笔 : 书写 : 汉字　D. 冰箱 : 保鲜 : 蔬菜
思路（程意式）：造句：「路由器用于连接网络」（工具 : 功能 : 作用对象）。套选项：A「石英钟用于显示时间」句式完全一致，且「连接/显示」是核心功能、「网络/时间」是抽象对象 → 选 A。B、C、D 也说得通，需纵向比较：题干功能词「连接」是设备的核心功能，对象「网络」是抽象概念，B、C、D 的对象（房间/汉字/蔬菜）偏具体，A 最贴。

4.2 逻辑关系（重点）

关系基础考点二级辨析
全同关系两个概念完全相同：麦克风:话筒；西红柿:番茄；纸鸢:风筝；南京:金陵；杜鹃花:映山红称谓（古今/雅俗/中英译）/范围
全异关系针对同一类事物的分类，两个概念没有交集：成年人:未成年人；香蕉:苹果矛盾全异（只有 2 种情况）：男:女、合法:非法、金属:非金属、曲:直、动:静；反对全异（有第 3 种情况）：少年:中年、小学生:大学生、手:足。其他：是否有顺序、是否紧密衔接、概念间存在内在转化（飞机:汽车）、不同层级全异（细菌:真菌）
种属关系A 是 B（的一种/个）：单人床:床；白兰地:烟酒；长白山:火山小概念为特指/泛指（常见特指：山名、河名、人名、名胜、地名、国名）；多层种属（劳动者:工人:瓦工）
交叉关系（金标准）两个概念有交集：布鞋:童鞋；女性:作家识别技巧：① 尾缀相同，但从不同角度描述（酒杯:玻璃杯）；② 从不同角度描述人的身份（编剧:博士）；③ 不是前 3 种关系 → 大概率交叉，需验证
因果关系原因与结果：下雨:地湿；缺铁:贫血；发炎:发烧连锁因果（饮酒:神志不清:车祸）；多个原因均能导致结果；多个原因共同导致结果（放养过密+饲喂不当→鱼病）；原因是人为/天然；结果是好的/坏的；结果是否必然发生；主体是否一致
条件关系充分条件 / 必要条件题干出现「则、就、必」→ 充分；「不…不…、才」→ 必要；俗语隐含条件（如「不经一事，不长一智」）；科学常识条件
目的关系行为方法与目的：治疗:康复；学习:掌握目的能否实现
顺承关系多个有顺序的行为：提交:审核:批准；学习菜谱:下厨烹饪:总结经验时间先后、主体是否一致、是否必然衔接
对应关系功能、工具、材料、特征、场所等对应注意词的意义：抽象/具体

属相:生肖｜刘彻:汉武帝｜朱棣:明成祖｜赵匡胤:宋太祖｜镇江:京口｜广州:羊城｜成都:蓉城｜合肥:庐州｜桂:广西｜牵牛花:喇叭花｜荷花:芙蕖/菡萏｜乞巧节:七夕节｜矮瓜:茄子｜犬子:儿子｜地瓜:甘薯｜考拉:树袋熊｜南京:金陵｜分母:除数｜银杏:公孙木｜马达:发动机｜引擎:发动机｜岳父:泰山｜夜宵:宵夜｜生日:生辰｜百分比:百分率｜牙婆:人贩子｜益母草:红花艾｜芝麻:脂麻

例 · 全同关系 + 二级辨析
纸鸢 : 风筝 —— 以下哪项与题干关系最为相似？
A. 杜鹃花 : 映山红　B. 成年 : 未成年　C. 汽车 : 飞机　D. 白天 : 黑夜
思路（程意式）：「纸鸢」与「风筝」是全同关系（同一事物的古今/雅俗两种叫法）。A「杜鹃花=映山红」同为全同 → 选 A；B、D 是矛盾全异（二选一）；C 是反对全异（还有轮船等）。二级辨析：题干是雅称/俗名（纸鸢偏雅），A 也符合「书面名/别名」的对应。
例 · 种属 vs 组成（易混淆）
玫瑰 : 花 —— 以下哪项与题干逻辑关系最为相似？
A. 树木 : 森林　B. 苹果 : 水果　C. 轮胎 : 汽车　D. 水 : 河
思路：「玫瑰是花的一种」= 种属关系（个体属于类别）。B「苹果是水果的一种」同构 → 选 B。易错：A「树木组成森林」、C「轮胎组成汽车」都是组成关系（整体与部分），与种属不同——种属可造句「A 是 B」；组成造句「A 是 B 的一部分」。

4.3 言语关系（词语、成语、俗语、诗句）

关系考点
近反义近义（漂亮:美丽）、反义（吝啬:大方）。二级辨析：感情色彩（褒/贬/中）——近义词注意语义轻重、语义着重、范围大小、使用对象；反义词注意绝对反义（真:假，动:静，互相排斥）与相对反义（春:秋，黑:白，对比鲜明但非矛盾）。
主谓结构主语+谓语：名+动（司机:驾驶）、名+形（阳光:灿烂）
动宾结构动词+宾语：动+名（观赏:风景）
偏正结构修饰+中心语：形+名（锦绣:山河）、副+动（认真:学习）
⚠️ 近义词细微差别（易错）
  • 意义：语义程度轻重（如「批评/批判」）、语义着重点不同、语义范围大小、使用对象不同。
  • 色彩：感情色彩（褒/贬/中）、语体色彩（书面语/口语）。
  • 用法：词语搭配、语法功能。
例 · 言语结构（主谓 / 动宾）
司机 : 驾驶 —— 以下哪项与题干逻辑关系最为相似？
A. 演员 : 表演　B. 观赏 : 风景　C. 老师 : 学生　D. 火车 : 轨道
思路（程意式）：「司机驾驶」= 主语 + 谓语（名+动，主谓结构）→ A「演员表演」同为主谓 → 选 A。易混：B「观赏风景」是动宾结构（动词+宾语），与题干主谓方向相反——判断时看词性与顺序：名词在前动词在后为主谓，动词在前名词在后为动宾。

4.4 造句法 & 常考常识积累

例 · 常识 + 顺承（节气）
白露 : 寒露 : 霜降 —— 以下哪项与题干逻辑关系最为相似？

思路（程意式）：题干三个节气同属秋季且时间顺承（白露→寒露→霜降）。A「立春、雨水、惊蛰」同属春季且顺承，结构完全一致 → 选 A。B 中「立夏」属于夏季，跨了季节 ✗；C 少了「夏至」（芒种→夏至→小暑→大暑，不连续）✗；D 中「秋分」在寒露之前，且处暑→秋分中间隔着白露 ✗。常考积累：二十四节气按季节分组背熟。

模块五 · 定义判断（第 20 次课）

DEFINITION
题干字数多、阅读量大。做题核心：「理解题干 + 对比选项」。三大突破点：① 学会不同情况下的读题方法；② 学习多定义题目做题方法；③ 明确选项分析原则。

5.1 底层能力 · 读懂定义，关注核心要点

要点含义提示词
主体行为或事件的发起者（一般在定义内容最前面）……的（机构/人/组织）
客体行为或事件的承受者对……；向……
目的行为目标和预期结果为了……；为达到……；确保……
方式/行为所采取的方法和具体行为以……为手段；采取……方法；通过……
条件限制性信息在……情况下；在……条件下；当……时
原因行为发生的原因由于……；因为……
结果行为造成的结果（结果比原因更常考、更重要）造成……；导致……；因而……
性质定义的本质属性（一般在句尾）……的（+名词）
✏️ 核心原则
① 先读问题，优先找与问题相关的定义，看清楚「属于/不属于」；② 对关键词敏感；③ 比较原则：优中选优——排除最不像的，剩下的比细节；④ 补充说明（括号里的）必须读，常常是考点；⑤ 「且/或」等和关系注意区分。
例 · 单定义（抓核心要点）
工作记忆是指个体在执行认知任务的过程中，对信息进行暂时性加工和存储的记忆系统。根据上述定义，下列属于工作记忆的是：
A. 小明能熟练背诵小学时学过的古诗　B. 小红记下服务台电话号码后立即拨打，拨完就忘了　C. 老李清楚地记得自己年轻时支边的经历　D. 小张能复述出昨天会议的主要内容
思路（程意式）：划关键词：执行任务过程中 + 暂时性加工和存储。A、C、D 都是长期记忆（永久存储），与「暂时性」矛盾 ✗；B「记下号码→立即拨打→拨完就忘」完全符合「暂时存储」→ 选 B。排除顺序：先排「长期记忆」这种明显违背性质的，再比对细节。

5.2 解题流程 & 多定义题目 & 选项分析

标准化流程

1
读问题：问的是「属于/不属于」「符合/不符合」，对应选项关注点不同。
2
读定义：划出主体、方式、目的、条件、结果、性质等关键词；括号补充信息必读。
3
对比选项：逐项与关键词比对，排除明显不符 → 剩两个比细节 → 优中选优。
4
不确定时：回到定义本身用「常识 + 被定义项」（定义词本身的意思）辅助判断。

题干设置的两种常见结构

  • 一个定义有限分类：定义给出后分了几个类别 → 选项与类别一一对应。
  • 一个定义后重点解释关键词：优先通过关键词排除，不必完全读懂定义。

多定义题目（题干给出 2 个及以上定义）

  • 先读问题，锁定问的那个定义，只读相关定义，其他定义可略读。
  • 两个定义常是「对立/包含」关系，可通过对比记忆（如「亲社会行为 vs 反社会行为」）。
  • 选项常「张冠李戴」：A 定义的行为套到 B 定义上，注意主体和行为匹配。

选项分析原则

  • 主体不符 → 一定不选（最优先排除）。
  • 方式/目的/结果不符 → 不选；只有个别细节不确定的，可以保留比较。
  • 两个选项都像时：哪个更全面地满足关键词，选哪个（优中选优）。
  • 不要因为选项「举的例子我没见过」就排除——比对的是结构不是内容。
例 · 多定义（先锁定问的定义）
亲社会行为是指个体做出的有利于他人和社会的行为；反社会行为是指危害他人和社会正常秩序的行为。根据上述定义，下列属于反社会行为的是：
A. 公交车上主动给老人让座　B. 在电影院里大声喧哗、随意走动　C. 同事生病时帮忙代班　D. 路见不平挺身而出
思路（程意式）：先读问题，锁定「反社会行为」= 危害他人和社会秩序。A、C、D 都是亲社会行为（利他）✗；B「大声喧哗、随意走动」扰乱公共秩序，符合危害性 → 选 B。多定义题技巧：两个定义常是对立关系，选项容易张冠李戴，注意「主体 + 行为」和定义严格对应。

真假判断
知真求假/知假求真，直接找矛盾：且↔或、或↔且（各加非）；A→B 的矛盾是 A 且非B；要么A要么B ↔ 要么A且B，要么非A且非B。
直言矛盾
所有↔有些，是↔非，某个不变：所有是 ↔ 有些非；所有非 ↔ 有些是；某个是 ↔ 某个非。上反对（所有是/所有非）不能同真；下反对（有些是/有些非）不能同假。
三段论
找中项（前提出现两次的桥）；「所有」和「否定」周延，「有的」和「肯定」不周延；两个否定前提无结论；前提有否定，结论必否定。
朴素逻辑
突破口：确定性 + 关联性。数独：排除 + 交集最多处入手；3+2：相同归大去排除；最多=加和、最少=取大（去包含）。
一拖N
有序画箭头（紧挨/不紧挨/隔1），无序看分组。可能真→代入可行可选；不可能真→代入冲突可选；一定真→正推。问最多验证最大数、问最少验证最小数。
加强削弱
读问题辨题型 → 理结构（结论☆论据）→ 预设答案。力度：本质>现象、全面>片面、确定>可能、量大>量小。因果削弱：因果倒置、另有共因、有因无果/无因有果、否定此因、另有他因。
论证模型
求异（削：不同点；加：相同点）→ 双观点（削反对者=A是C的原因）→ 实践论证（方案可不可实现）→ 类比（根本同/异）→ 枚举（代表性）→ 缺桥（搭桥/拆桥）→ 数据（找分母）→ 有比较（选有比较的）。
图推总纲
有相同 → 位置/样式/标记；无相同 → 属性（对称优先）→ 数量 → 图形间关系。长得一样看位置，长得像看样式，乱七八糟数数量（点线角面素笔画挨个试）。
图推数量
一笔画：奇点 0 或 2 即一笔，奇点÷2=笔画。面=白色封闭区域（黑色不是面）。切点属交点、端点不算交点。形状一样颜色不同算不同元素。
类比
常态思维、先横后纵、先整体后局部。全同→全异（矛盾/反对）→种属→交叉→因果→条件→目的→顺承；近反义看感情色彩和轻重；三项式用造句法。
定义判断
主体（发起者）、客体（承受者）、方式（手段）、目的（为了）、条件（限制）、结果（导致）、性质（句尾）。括号必读；先排主体不符；多定义先锁定问的定义；优中选优。

备考节奏建议

STUDY PLAN

三阶段推进（程意式学习法）

阶段任务目标
基础阶段跟课 + 背口诀 + 做课后作业；笔记当天整理（思维导图 + 题目解析 + 做题步骤）打扎实基础，重点在「学会」
专项提升按题型分类刷题（夸夸刷）：今天只刷图推位置，明天只刷样式……；错题记录，周末重做看到题就能判断考点（不背答案）
套题冲刺掐时间整套刷，复盘每道题的考点归属；用「知识点复习表 + 默写表」查缺补漏固化解题反射，控制时间预算

每日复习小贴士

  • 图推：每天 10-15 道，只判断「考哪类规律」，45 秒/道，练识别速度。
  • 逻辑：每天把翻译口诀默写一遍，直到不用想就写出来。
  • 类比：边做题边积累常识，整理自己的「常识小本」（时辰、节气、别称等）。
  • 定义：练习划关键词，训练「一眼抓住主体、方式、结果」。
  • 复盘：错题不是看答案，是回看「我应该用哪个考点/哪一步想错了」。
✏️ 程意寄语
「过程或许有点难，但结果会是好的。」母题二、三、四难，基础阶段学不会很正常——学会多少都是进步，刷题阶段会带你重点攻克。
